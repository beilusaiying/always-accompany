# API 設定詳細

各 AI サービスソースの [AI サービスソース](beilu:settings/api) パネルにおける設定フィールドの説明です。

## パネル操作

[AI サービスソース](beilu:settings/api)パネルでは以下の操作が可能です：

| コントロール | 説明 |
|------|------|
| サービスソースリスト | 左側に追加済みの API ソースが表示され、クリックで編集を切り替えます |
| 新規作成ボタン | 新しい API サービスソースを作成します |
| 削除ボタン | 現在選択されているサービスソースを削除します |
| 設定名 | テキスト入力。サービスソースの表示名です |
| チャンネルドロップダウン | 複数のチャンネルから選択可能（OpenAI / Claude / Gemini / Ollama など）。メッセージフォーマットの適合を決定します |
| URL | テキスト入力。API エンドポイントアドレスです |
| Key | テキスト入力。API キー（暗号化保存） |
| モデル | テキスト入力。モデル名の識別子です |
| モデルリスト取得 | ボタン。API から利用可能なモデルリストを取得して選択できます |
| Extended Thinking | スイッチ。拡張思考機能を有効にします（一部のモデルが対応） |
| Budget スライダー | 思考バジェットの制御（Extended Thinking が有効な場合に利用可能） |
| 保存ボタン | 現在の設定を保存します |
| 思考チェーン折りたたみ設定 | 思考チェーン内容の表示ラベルと折りたたみ動作を設定します |

## サービスソース設定テンプレート

各 AI サービスソースの設定には以下のフィールドが含まれます：

| フィールド | 説明 | 必須 | 例 |
|------|------|------|------|
| name | サービスソース名（表示用） | はい | `my-claude` |
| url | API エンドポイントアドレス | はい | `https://api.anthropic.com/v1/chat/completions` |
| model | 使用するモデル名 | はい | `claude-sonnet-4-20250514` |
| apikey | API キー | はい | `sk-ant-...` |
| provider | チャンネル識別子 | 推奨 | `claude` |
| use_stream | ストリーミングレスポンスを使用するか | いいえ | `true`（デフォルト） |
| custom_headers | カスタムリクエストヘッダー | いいえ | `{"X-Custom": "value"}` |

## フィールド詳細

### url（API エンドポイント）

API エンドポイントアドレスです。プロバイダーやジェネレーターによって異なるエンドポイント形式を使用します。

デフォルトエンドポイントは選択したチャンネルに基づいて自動的に入力されます。中継サービスやリバースプロキシを使用する場合は、対応するアドレスに置き換えてください。ジェネレーターによって対応するプロトコルが異なることに注意してください：

- **proxy ジェネレーター**：OpenAI Chat Completions 形式（`/v1/chat/completions`）
- **claude-api ジェネレーター**：Anthropic Messages 形式（`/v1/messages`）
- **gemini ジェネレーター**：Gemini ネイティブ形式
- **ollama ジェネレーター**：Ollama 形式（`/api/chat`）

### model（モデル名）

呼び出すモデルの識別子です。プロバイダーによってモデル名が異なります：

| プロバイダー | モデル名の例 |
|--------|-------------|
| OpenAI | `gpt-4o`, `o3-mini` |
| Claude | `claude-sonnet-4-20250514`, `claude-opus-4-20250514` |
| Gemini | `gemini-2.0-flash`, `gemini-2.5-pro` |
| DeepSeek | `deepseek-chat`, `deepseek-reasoner` |
| Qwen | `qwen-plus`, `qwen-max` |

モデル名はサブモードや実行時に `model_override` で上書きできます。

### apikey（API キー）

プロバイダーが発行した認証キーです。キーは設定内で暗号化保存され、ログに平文で表示されることはありません。

### provider（チャンネル）

always-accompany にどのプロバイダーの API であるかを伝え、メッセージフォーマットの適合戦略を決定します。詳しくは [対応 AI プロバイダー](providers.md) をご覧ください。

自動検出に頼らず、手動でチャンネルを選択することを強く推奨します。自動検出（空のまま、または「自動検出」を選択）は URL とモデル名から推測するため、誤判定により API 呼び出しが失敗する可能性があります。

### use_stream（ストリーミングレスポンス）

SSE ストリーミングレスポンスを使用するかどうかです。デフォルトで有効です。

- **有効**：AI の応答が1文字ずつ表示され、体験が向上します
- **無効**：完全な応答を待ってから一括表示します

以下のシーンではストリーミングの有効化が必須です：
- Qwen の enable_thinking 機能
- 一部のローカルエンジンの推論モード

### custom_headers（カスタムリクエストヘッダー）

JSON オブジェクトで、追加の HTTP リクエストヘッダーです。主に以下の用途で使用されます：

- OpenRouter の `HTTP-Referer` と `X-Title`
- 企業イントラネットの認証ヘッダー
- リバースプロキシのカスタム認証

### roleReminding（ロールリマインダー）

ブール値で、AI に送信するメッセージ内でロールリマインダー（role reminding）を有効にするかどうかです。有効にすると、システムが適切な位置にロールリマインダーテキストを挿入し、AI のキャラクター一貫性の維持を助けます。デフォルトで有効です。

### ignoreFiles（添付ファイルを無視）

ブール値で、会話に添付されたファイル内容を無視するかどうかです。一部のモデルがファイル/画像入力に対応していない場合、この項目を有効にすると API エラーを回避できます。

## 複数サービスソースの管理

### キャラクターレベルの紐付け

各キャラクターは独立した AI サービスソースを紐付けできます。キャラクター設定でサービスソースを指定すると、そのキャラクターとの会話は指定されたサービスソースを使用し、グローバル設定の影響を受けません。

### サブモード上書き

Code モードと Work モードの各サブモードは、モデル名とサンプリングパラメータを独立して上書きできます。これにより、同じサービスソースで異なる作業フェーズに異なるモデルを使用できます（例：シンプルなタスクには小型モデル、複雑な分析には大型モデル）。

## セキュリティに関する注意事項

- API キーは HTTPS で送信され、サーバー側で暗号化保存されます
- ローカルデプロイ（Ollama / LM Studio）では API キーは不要です
- マルチユーザー環境では、各ユーザーのサービスソース設定が独立して分離されます
