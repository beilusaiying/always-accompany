# 預設集與參數

預設集控制 AI 的行為方式——用什麼身分回覆、帶什麼指令、走什麼格式。

## 切換預設集

左欄預設集選擇器，下拉選一個。不同預設集適合不同情境：

| 預設集類型 | 作用 |
|---------|------|
| 聊天類 | 角色扮演、日常對話 |
| 程式類 | 程式碼產生、審查、除錯 |
| 工作類 | 任務管理、文件產生 |

切換後立刻生效，下次發訊息就用新的預設集。詳見 [預設集系統](beilu:wiki/presets/overview.md)。

## 調模型參數

左欄「取樣參數」摺疊組，包含以下控制項：

| 參數 | 控制項類型 | 範圍 | 建議 |
|------|---------|------|------|
| Temperature | 滑桿 | 0 ~ 2 | 聊天 0.7~1.0，程式 0.3~0.5 |
| Top P | 滑桿 | 0 ~ 1 | 一般 0.9~1.0 |
| Top K | 數字輸入 | 0 ~ 500 | 按模型支援設定 |
| Min P | 滑桿 | 0 ~ 1 | 按需微調 |
| Freq Penalty | 數字輸入 | -2 ~ 2 | 降低重複用詞 |
| Pres Penalty | 數字輸入 | -2 ~ 2 | 鼓勵話題多樣性 |
| Max Context | 數字輸入 | — | 按模型能力設定，越大記得越多 |
| Max Tokens | 數字輸入 | — | 按需求設定 |
| 串流輸出 | 開關 | — | 建議開啟 |
| 通用預填充 | 開關 | — | 按需開啟 |
| 尾部預填充 | 下拉 | 4 個選項 | 按情境選 |
| 後處理 | 下拉 | 4 個選項 | 按情境選 |

調整後點「儲存」生效。詳見 [模型參數](beilu:wiki/ai-service/model-params.md)。

## 角色卡編輯

點角色卡的編輯按鈕，開啟 [編輯介面](beilu:editor/persona-edit)，共 5 個 Tab：

- **Tab 1 預設集編輯**：分類篩選 + 預設集增刪改查 + 搜尋、左右分欄（左側條目列表可拖曳排序，右側條目詳情編輯）、9 個 Marker 插入位置
- **Tab 2 [世界書](beilu:wiki/memory/worldbook-overview.md)**：世界書增刪改查、左右分欄（搜尋 + 條目列表 / 條目編輯：標題、啟用開關、觸發模式、位置、深度、關鍵字、副關鍵字、正規表示式比對、動態開關、排序、角色綁定、內容）
- **Tab 3 使用者人設**：人設卡片列表（頭像 + 名稱 + 描述編輯 + 儲存 / 啟用 / 刪除）
- **Tab 4 [INJ 注入](beilu:wiki/memory/inj-overview.md)**：統計列 + 搜尋、左右分欄（條目列表 / 條目編輯：名稱、啟用、角色、深度、排序、注入模式、平台、內容）、新增 / 恢復預設
- **Tab 5 [正規表示式](beilu:wiki/presets/regex.md)**：三級作用範圍（全域 / 角色 / 預設集）、正規表示式編輯器（pattern / flags / replace 等）、即時測試面板、ReDoS 護欄

角色描述寫得越具體，AI 扮演得越準。

## 使用者人設

設定你自己的身分資訊（名字、性格、背景），AI 會據此調整互動方式。在編輯介面 Tab 3 或設定中管理。
