# 聊天模式 (Chat / AIRP)

## 進入聊天模式

| 方式 | 操作 |
|------|------|
| 頂部模式選擇器 | 點擊「Chat」標籤 |
| 鍵盤快捷鍵 | `Ctrl+2` 或 `Alt+2` |

進入後直接在中央對話區輸入訊息即可開始對話。

## 基本操作

- **日常對話**：直接輸入訊息，無需特殊設定
- **角色扮演**：從左欄選擇角色卡，選擇適合的預設集，然後開始對話
- **調參最佳化**：透過右欄的模型參數面板微調 AI 表現（如降低溫度獲得更穩定的回覆）

## 介面佈局

三欄佈局，左右欄均可摺疊：

- **左欄**：會話列表、角色卡選擇、會話管理（新建 / 刪除 / 歸檔）
- **中央區域**：對話主區，訊息輸入與顯示
- **右欄**：目前會話的設定面板（預設集、模型參數、正規表示式等）

## 你可以做的事

| 想做什麼 | 怎麼做 |
|---------|-------|
| 建立新會話 | 左欄點擊新建 |
| 切換歷史會話 | 左欄點擊會話列表 |
| 載入角色卡 | 左欄選擇角色卡 |
| 切換預設集 | 右欄預設集管理區選擇 |
| 調整模型參數 | 右欄模型參數面板 |
| 編輯/重新產生訊息 | 訊息氣泡上的操作按鈕 |
| 啟用聯網搜尋 | 對話中手動觸發或 AI 自主觸發 |
| 設定正規表示式處理器 | 右欄正規表示式規則區，可啟用/停用單條規則 |
| 設定 INJ 注入 | 右欄 INJ 設定區，設定自動注入的背景資訊 |
| 匯出對話記錄 | 會話管理中匯出 |

## 後端模式值

聊天模式對應後端模式值 `chat`。Bot 管理、Helper 等輔助檢視也複用 `chat` 作為後端模式值，但在前端展示不同的介面。
