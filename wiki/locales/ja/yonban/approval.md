# 承認と権限

YonBan のすべての書き込み操作は承認システムによって管理されます。権限レベルは AI が何をできるかを決定し、承認フローは承認の方法を決定します。

## 権限レベル

| レベル | 名称 | 許可される操作 |
|------|------|-----------|
| L0 | 読み取り専用 | read_file、list_files、search などの読み取り操作のみ |
| L1 | 読み取り | 読み取り操作 + 診断 + ナビゲーション |
| L2 | 読み書き（承認必要） | 読み取り + 書き込み操作（各書き込み操作はユーザーの個別承認が必要） |
| L3 | フル + コマンド | 読み書き + コマンド実行（run_command / run_script） |
| L4 | 信頼 | すべての操作が自動通過し、承認をスキップ |

コードモードのコントロールパネルにある権限レベルのドロップダウンメニューで切り替えます。[セキュリティセンター](beilu:settings/security)でグローバルセキュリティポリシーを確認できます。

## 承認フロー

書き込み操作が AI から発行されて実際に実行されるまで、以下のフローを経ます：

1. AI が書き込み操作リクエストを発行（write_file / run_command / git_commit など）
2. リクエストが承認キューに入る
3. フロントエンドの接続カードに承認プロンプトがポップアップ
4. ユーザーが**承認**または**拒否**を選択
5. 承認 → 操作を実行して結果を返す；拒否 → 拒否理由を返し、AI はそれを受けて戦略を調整

L4 信頼モードでは、ステップ 2-4 が自動的にスキップされます。

## 5 段階セキュリティゲート

承認システム内部は 5 段階のセキュリティゲートが直列に接続されており、いずれかのレベルでインターセプトされると実行が阻止されます：

| レベル | 名称 | 作用 |
|------|------|------|
| 1 | コマンドゲート | ブラックリストのコマンドは永久禁止（例：rm -rf /）；グレーリストのコマンドは承認が必要（各コマンドに L4 でも確認するかどうかを設定可能）；能力ホワイトリスト内のコマンドは権限レベルに応じて通過 |
| 2 | ルールセットエンジン | ユーザー定義ルール：deny（拒否）/ ask（承認必要）/ allow（通過）を優先度順にマッチング |
| 3 | 承認ゲート | システム強制承認（L2 の書き込み操作）/ ポリシー承認（ルールセットが ask にヒット）/ 信頼スキップ（L4） |
| 4 | 統一実行ゲート | fail-closed 設計——ゲート異常時はデフォルトで拒否し、漏らしません |
| 5 | 承認フィンガープリント紐付け | 承認通過後にリクエストの sha256 フィンガープリントを生成し、実行時にフィンガープリントの一致を検証——承認通過後にリクエストが改ざんされることを防ぎます |

## コマンドセキュリティ

コマンド実行（run_command / run_script）には追加のセキュリティ層があります：

| リスト | 説明 |
|------|------|
| ブラックリスト | 深刻な破壊を引き起こすコマンドは権限レベルに関係なく永久禁止（ディスクのフォーマット、再帰的削除、ディスク消去/ブート変更など）。各項目は個別に有効/無効/削除が可能で、権限パネルから追加削除できます |
| グレーリスト | 明示的な承認が必要なコマンドです。各項目に「L4 でも確認」スイッチがあります：オン = L4 完全信頼でも承認をポップアップ（shutdown、reg など）；オフ = 最大でも L3 に制限、L4 は承認不要（git rebase、npm uninstall など） |
| 能力ホワイトリスト | よく使われる安全なコマンド（ls、cat、git status など）は L3 以上で自動通過 |

## フロントエンドコントロールパネル

コードモードのアクティビティバーで control ボタンをクリックしてコントロールパネルを開き、以下の設定を集中管理します：

| コントロール | タイプ | 説明 |
|------|------|------|
| 権限レベル | ドロップダウンメニュー | L0 ~ L4、AI が実行できる操作範囲を制御 |
| 自動保存 | スイッチ | オンにするとファイル変更が自動的にディスクに保存されます |
| 自動継続 | スイッチ + 遅延設定 | AI が1ステップ完了後に自動的に次のステップへ進みます。待機遅延を設定可能 |
| 完了通知音 | スイッチ | AI がタスクを完了した時に通知音を再生します |
| クリーンアップモード | ドロップダウンメニュー | コードクリーンアップの戦略を選択 |
| 手動クリーンアップ | ボタン | クリーンアップを即座に1回実行します |
