# プリセットの分類と選択

## プリセットの切り替えとフィルタリング

### 使用シーンから選ぶ

| やりたいこと | 推奨分類 | 理由 |
|-----------|---------|------|
| ロールプレイ対話 | clone | キャラクターの行動ガイド、対話スタイル制御を含みます |
| 日常チャット | clone または汎用 | 軽量な指示で、自然な対話が可能です |
| コードを書く | code | コーディング規約、出力形式、ツール使用指示を含みます |
| タスク管理 / ドキュメント | work | タスク分解、フォーマット要件、承認フローを含みます |
| カスタムシーン | 独自プリセットを作成 | 要件に完全に合わせてカスタマイズできます |

### モードによる自動読み込み

モード設定でプリセットをバインドしている場合（詳しくは[プリセットとモードの連動](mode-binding.md)を参照）、モードを切り替えると対応するプリセットが自動的に読み込まれるため、通常は手動で選択する必要はありません。

### キャラクター/対話ごとの個別設定

各キャラクターと各対話ウィンドウにプリセットを個別にバインドできます。システムは **active_preset_map** で各対話が使用するプリセットを記録しており、互いに干渉しません：

- キャラクター A との会話にはプリセット X を使用
- キャラクター B との会話にはプリセット Y を使用
- 対話ウィンドウを切り替えると、プリセットが自動的に復元されます

## プリセットを管理する

### インストール済みプリセットの確認

プリセット管理パネルでインストール済みのすべてのプリセットを確認できます。bucket ごとにグループ表示されます。各プリセットには名前、説明、現在のステータスが表示されます。

### プリセットのインポート

SillyTavern 形式のプリセット JSON ファイルのインポートに対応しています。インポート時にシステムは以下の処理を行います：

1. プリセット JSON を解析し、条目とパラメータを抽出します
2. registry.json に登録します
3. bucket フィールドがある場合、対応する分類に振り分けます
4. model_params がある場合、モデルパラメータを保存します

### プリセットのエクスポート

現在のプリセットを SillyTavern 互換の JSON ファイルとしてエクスポートでき、共有やバックアップに便利です。[インポート / エクスポート](beilu:settings/import-export)パネルで一括操作も可能です。エクスポートにはすべての条目、ソート順、パラメータ、分類情報が含まれます。

### プリセットの削除

内蔵プリセットの削除は実際には「削除済み」マーク（config.json の deleted_builtins に記録）であり、いつでも復元できます。ユーザーが独自に作成したプリセットは削除後に再インポートが必要です。

## 分類ロジック

always-accompany は **bucket（分類バケット）** でプリセットを分類管理します。各プリセットは登録時に所属する bucket がマークされ、フロントエンドでは bucket ごとにグループ表示されます。

### 内蔵分類

| Bucket | 説明 | プリセット数 | 適用モード |
|--------|------|---------|---------|
| code | プログラミング支援系プリセット | 11+ | コードモード / IDE |
| work | ワークフロー系プリセット | 12+ | ワークモード |
| clone | ロールプレイ / クローン系プリセット | 5+ | チャットモード / AIRP |
| _(分類なし)_ | 汎用プリセット | 必要に応じて | すべてのモード |

### 分類のソース

プリセットの bucket 情報は **registry.json**（プリセットレジストリ）に記録されており、これが分類の単一権威ソースです。インポート時に JSON ファイルに bucket フィールドがあれば、自動的に対応する分類に登録されます。

bucket フィールドのないプリセットは、フロントエンドがプリセット名のキーワードに基づいてフォールバックマッチングを行い、適切なグループへの振り分けを試みます。

## プリセット選択の優先順位

現在の対話でどのプリセットを使用するかを決定する際、以下の優先順位に従います：

1. **対話レベルバインディング**：active_preset_map で chatId をキーとして記録されたプリセット
2. **モードレベルバインディング**：mode_preset_bindings でそのモードのデフォルトプリセット
3. **グローバルデフォルト**：active_preset（グローバル設定のデフォルトプリセット）
