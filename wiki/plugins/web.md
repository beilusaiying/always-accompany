# 联网搜索 (beilu-web)

beilu-web 让 AI 能够搜索互联网并浏览网页。当 AI 需要获取实时信息、查找资料或验证事实时，它可以通过 `<search>` 和 `<browse>` 标签发起联网请求。

## 搜索功能

### AI 发起搜索

AI 在回复中使用 `<search>` 标签发起搜索请求。beilu-web 解析标签，执行搜索，并将结果注入到下一轮对话中。

### 搜索结果

搜索结果包含三个字段：

| 字段 | 说明 |
|------|------|
| title | 网页标题 |
| url | 网页地址 |
| snippet | 内容摘要 |

AI 收到搜索结果后，可以选择直接回答（如果摘要信息足够），或者通过 `<browse>` 标签访问具体网页获取更详细的内容。

### 手动搜索

在 beilu-web 的配置面板中，你也可以手动输入搜索词进行搜索，查看搜索结果。

## 网页浏览

AI 使用 `<browse>` 标签访问指定 URL 的网页内容。beilu-web 会抓取网页正文并返回给 AI。

### 爬取能力探测

beilu-web 启动时会自动探测当前环境的网页爬取能力：

- 如果安装了 Playwright 浏览器，可以渲染 JavaScript 动态页面
- 如果没有安装，回退到简单的 HTTP 抓取（可能无法获取 SPA 页面内容）

可以通过 `ensureBrowsers` 安装 Playwright 浏览器，以支持动态（JavaScript 渲染）页面的爬取。

## 安全机制

联网请求通过 `safeFetch` 安全抓取函数发送，内置了：

- 超时保护
- 响应大小限制
- 恶意 URL 过滤

## 使用场景

| 场景 | 说明 |
|------|------|
| 查询实时信息 | 天气、新闻、汇率等需要最新数据的问题 |
| 技术文档查阅 | AI 查阅官方文档来回答技术问题 |
| 事实核查 | 验证 AI 不确定的信息 |
| 资料收集 | 汇总多个来源的信息 |

## 配置

在 beilu-web 的配置面板中可以调整搜索引擎和相关设置。联网功能需要网络连接才能正常工作。

## 与记忆系统的关系

beilu-web 的联网搜索也被[记忆系统](../memory/overview.md)的 P8 预设调用。当 AI 在对话过程中判断需要外部信息时，P8 管线会触发联网搜索，搜索结果自动整合到对话上下文中。
