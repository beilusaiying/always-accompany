# 記憶システムマクロ

beilu-memory プラグインが記憶プロンプトを構築する際に使用する専用プレースホルダーです。記憶インジェクション段階で自動的に実際の記憶データに置換されます。

> **注意**：記憶システムマクロは記憶システムが独自のリンク内で置換します（メイン会話のインジェクションチェーンと記憶サブ AI チェーンにそれぞれ置換ポイントがあります）。プリセットマクロエンジンには依存しません。一部のマクロ（例：`{{lastUserMessage}}`）はプリセットマクロエンジンのコンテキストでも同様に使用できます。

## 記憶データマクロ

| マクロ | 説明 | 内容ソース |
|----|------|----------|
| `{{tableData}}` | 現在のモードの記憶テーブルデータ | 記憶テーブル（構造化記憶） |
| `{{hotMemory}}` | ホットレイヤー記憶 | forever/appointments/user_profile 等の永続データ |
| `{{chat_history}}` | 直近 N 件のチャット履歴 | チャット履歴 |
| `{{lastUserMessage}}` | ユーザーの最後のメッセージ | 現在の会話 |
| `{{contextSummary}}` | コンテキスト圧縮サマリー | 記憶システムの自動サマリー |

### {{tableData}}

記憶テーブルは always-accompany 記憶システムの中核データ構造の1つです。異なる記憶モード（日常モード、冒険モードなど）にはそれぞれ異なるテーブル列の定義があります。`{{tableData}}` は現在のモードに対応するテーブル内容に置換されます。

### {{hotMemory}}

ホットレイヤー記憶には複数の種類の永続化記憶データが含まれます：

- **forever**：永久記憶エントリー
- **appointments**：スケジュール/約束
- **user_profile**：ユーザープロフィール情報
- その他、記憶システムが管理するホットレイヤーデータ

### {{chat_history}}

直近 N 件のチャットメッセージを注入し、記憶 AI に現在の会話のコンテキストを把握させます。具体的な件数は記憶システムの設定によって決まります。

### {{lastUserMessage}}

ユーザーが現在の会話で送信した最後のメッセージです。記憶 AI はこれを使って、どの記憶を更新する必要があるかを判断します。

### {{contextSummary}}

会話が長くなった場合、記憶システムがコンテキスト圧縮サマリーを生成します。このマクロはそのサマリー内容を参照します。

## 補助情報マクロ

| マクロ | 説明 |
|----|------|
| `{{presetList}}` | 記憶 AI が選択可能なプリセットリスト |
| `{{current_date}}` | 現在の日付（記憶システム内部使用） |

### {{presetList}}

記憶 AI が選択できるプリセットの一覧を表示します。記憶システムは一部のシナリオで、どのプリセットが利用可能かを知る必要があります。

### {{current_date}}

記憶 AI に現在の日付情報を提供し、時間に関連する記憶（スケジュール、タイムラインイベントなど）を正しく処理できるようにします。

## 実行リンク

記憶システムマクロの置換フローは以下の通りです：

```
ユーザーがメッセージを送信
  -> beilu-memory プラグインが起動
  -> 記憶プロンプトテンプレート（マクロプレースホルダーを含む）を読み込み
  -> 記憶ストレージからデータを抽出
  -> {{tableData}}、{{hotMemory}} などを実際のデータに置換
  -> 記憶プロンプトの組み立てを完了
  -> メインプロンプトに注入して AI に送信
```

このプロセスはメインマクロエンジンと**独立して並行**動作します——記憶システムは自身のマクロを独自に処理し、処理済みの結果が1つのまとまりとしてメインプロンプトに注入されます。

## 使用シーン

記憶システムマクロは主に以下のシーンで使用されます：

| シーン | 関連マクロ | 説明 |
|------|--------|------|
| 記憶整理プロンプト | `{{tableData}}` `{{hotMemory}}` `{{chat_history}}` `{{lastUserMessage}}` | 記憶 AI に現在どの記憶があるか、会話で何が話されたかを伝えます |
| コンテキスト圧縮 | `{{contextSummary}}` | 記憶 AI に長い会話のサマリーを提供します |
| 記憶フォーマット説明 | `{{presetList}}` `{{current_date}}` | 補助情報 |

## 注意事項

- 記憶システムマクロは通常のプリセットやキャラクターカードでは**使用できません**——beilu-memory の内部テンプレートでのみ機能します
- これらのマクロは beilu-memory プラグインが**独立して置換**し、バックエンドのコアマクロエンジンは経由しません
- プリセット内で記憶データを参照する必要がある場合は、記憶システムのインジェクション機構を通じて行い、記憶マクロを直接書くのではなく使用します
