# 预设与参数

预设控制 AI 的行为方式——用什么身份回复、带什么指令、走什么格式。

## 切换预设

左栏预设选择器，下拉选一个。不同预设适合不同场景：

| 预设类型 | 作用 |
|---------|------|
| 聊天类 | 角色扮演、日常对话 |
| 编程类 | 代码生成、审查、调试 |
| 工作类 | 任务管理、文档生成 |

切换后立刻生效，下次发消息就用新预设。详见 [预设系统](beilu:wiki/presets/overview.md)。

## 调模型参数

左栏「采样参数」折叠组，包含以下控件：

| 参数 | 控件类型 | 范围 | 建议 |
|------|---------|------|------|
| Temperature | 滑块 | 0 ~ 2 | 聊天 0.7~1.0，编程 0.3~0.5 |
| Top P | 滑块 | 0 ~ 1 | 一般 0.9~1.0 |
| Top K | 数字输入 | 0 ~ 500 | 按模型支持设 |
| Min P | 滑块 | 0 ~ 1 | 按需微调 |
| Freq Penalty | 数字输入 | -2 ~ 2 | 降低重复用词 |
| Pres Penalty | 数字输入 | -2 ~ 2 | 鼓励话题多样性 |
| Max Context | 数字输入 | — | 按模型能力设，越大记得越多 |
| Max Tokens | 数字输入 | — | 按需求设 |
| 流式输出 | 开关 | — | 建议开启 |
| 通用预填充 | 开关 | — | 按需开启 |
| 尾部预填充 | 下拉 | 4 个选项 | 按场景选 |
| 后处理 | 下拉 | 4 个选项 | 按场景选 |

调整后点「保存」生效。详见 [模型参数](beilu:wiki/ai-service/model-params.md)。

## 角色卡编辑

点角色卡的编辑按钮，打开 [编辑界面](beilu:editor/persona-edit)，共 5 个 Tab：

- **Tab 1 预设编辑**：分类筛选 + 预设增删改查 + 搜索、左右分栏（左侧条目列表可拖拽排序，右侧条目详情编辑）、9 个 Marker 插入位置
- **Tab 2 [世界书](beilu:wiki/memory/worldbook-overview.md)**：世界书增删改查、左右分栏（搜索 + 条目列表 / 条目编辑：标题、启用开关、激活模式、位置、深度、关键词、副关键词、正则匹配、动态开关、排序、角色绑定、内容）
- **Tab 3 用户人设**：人设卡片列表（头像 + 名称 + 描述编辑 + 保存 / 激活 / 删除）
- **Tab 4 [INJ 注入](beilu:wiki/memory/inj-overview.md)**：统计行 + 搜索、左右分栏（条目列表 / 条目编辑：名称、启用、角色、深度、排序、注入模式、平台、内容）、新增 / 恢复默认
- **Tab 5 [正则](beilu:wiki/presets/regex.md)**：三级作用域（全局 / 角色 / 预设）、正则编辑器（pattern / flags / replace 等）、实时测试面板、ReDoS 护栏

角色描述写得越具体，AI 扮演得越准。

## 用户人设

设定你自己的身份信息（名字、性格、背景），AI 会据此调整交互方式。在编辑界面 Tab 3 或设置中管理。
