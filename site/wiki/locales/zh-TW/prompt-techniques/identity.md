# 身份設定技巧

身份設定是提示詞的起點。AI 需要知道「我是誰」，才能決定「我該怎麼說話、怎麼做事」。一個好的身份設定，能讓 AI 的整體表現方向對、風格穩。

## 具體的複合型身份

### 為什麼不能籠統

「你是一個作家」——這太模糊了。AI 會套用它訓練資料中「作家」的平均表現，結果就是毫無特色的通用輸出。

身份設定要**具體**，最好是**複合型**的，用多個限定詞疊加出一個精確的畫像。

### 正確 vs 錯誤範例

```
錯誤：你是一個小說作家。

正確：你是一個非傳統中國現代輕小說作家。
```

拆解這個複合身份：
- **非傳統** —— 告訴 AI 不要走套路，避免範本化的「AI 味」寫作
- **中國現代** —— 限定文化語境和時代背景
- **輕小說** —— 限定體裁風格，輕小說有自己的敘事節奏和對話密度

每多一個限定詞，AI 的輸出就更聚焦一層。

### 更多複合身份範例

| 情境 | 籠統身份 | 複合身份 |
|------|---------|---------|
| 角色扮演 | 你是一個 AI 助手 | 你是一個經歷過戰爭的退役軍醫，性格沉穩但偶爾流露黑色幽默 |
| 寫作輔助 | 你是一個編輯 | 你是一個專注於網文節奏把控的責任編輯，擅長砍掉拖沓段落 |
| 程式碼助手 | 你是一個程式設計師 | 你是一個偏好函式型程式設計、注重程式碼可讀性的後端工程師 |

### 「非傳統」的妙用

在創作類情境中，加上「非傳統」或類似的反套路限定詞，可以有效減少 AI 的範本化傾向。AI 被訓練了大量「傳統」寫法，如果不加限定，它會預設輸出最「安全」的風格——而這往往就是最沒有特色的。

```
效果對比：

「你是一個言情小說作家」
→ AI 傾向於：華麗辭藻、大量心理描寫、套路化情節

「你是一個非傳統現代言情作家」
→ AI 傾向於：更克制的表達、更日常化的對話、更意外的情節走向
```

## 功能模組化：AIRP 結構

當身份設定變複雜時，不要把所有內容擠在一段話裡。用模組化的方式組織，每個模組負責一個方面。

### AIRP 結構

一套經過驗證的提示詞組織結構，適用於角色扮演和創作情境：

| 模組 | 內容 | 作用 |
|------|------|------|
| **A - 身份 (Actor)** | 角色的身份定義 | 告訴 AI「我是誰」 |
| **I - 任務 (Instruction)** | 目前要做什麼 | 告訴 AI「我該做什麼」 |
| **R - 使用者畫像 (Reader)** | 使用者的偏好和特徵 | 告訴 AI「我在和誰交流」 |
| **P - 避免事項 (Pitfalls)** | 需要規避的表現 | 告訴 AI「什麼不該做」 |

在角色扮演情境中，還可以擴充更多模組：

| 擴充模組 | 內容 |
|---------|------|
| 角色扮演指導 | 角色的行為模式、說話習慣 |
| 敘事風格 | 第幾人稱、時態、節奏 |
| 戲劇風格 | 衝突處理、情緒表達方式 |
| 寫作風格 | 用詞偏好、修辭手法 |
| POV（視角） | 誰的視角敘述 |

### 模組化範例

```
錯誤：一段式堆砌
────────────────
你是一個非傳統輕小說作家，要寫校園日常故事，
使用者喜歡輕鬆搞笑的風格，不要用太多比喻，
對話要自然，用第一人稱，注意節奏不要拖沓，
角色說話要有口癖......
```

```
正確：模組化組織
────────────────
## 身份
你是一個非傳統中國現代輕小說作家。

## 任務
圍繞校園日常場景展開敘事，以對話推動情節。

## 使用者畫像
偏好輕鬆幽默的基調，喜歡角色之間的自然互動。

## 避免事項
避免大段心理獨白和過度修辭。

## 敘事風格
第一人稱，現在時態，節奏明快，場景切換乾脆。

## 寫作風格
以白描和對話為主，用詞日常化，角色語言體現各自口癖。
```

模組化的好處：
- **易於維護**：哪裡效果不好，改對應模組就行，不用通篇重寫
- **層次清晰**：AI 能更準確地理解每個維度的要求
- **可複用**：好用的模組可以跨角色、跨情境複用

## 在 beilu 中的應用

beilu 的[預設集系統](../presets/overview.md)本身就是模組化的——每個預設集條目就是一個獨立模組，可以自由組合。你在寫角色卡或自訂預設集時，可以直接參考 AIRP 結構來組織內容，把不同維度的指引放在不同的預設集條目中。角色卡可在[編輯介面](beilu:editor/persona-edit)中編輯。
