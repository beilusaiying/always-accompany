# YonBan

拡張機能マーケットプレイスから YonBan をインストールすると、AI が直接あなたの IDE を操作できるようになります——ファイルの読み書き、コマンド実行、Git 操作など、30 以上のツールがすべて承認システムで管理されます。

## インストール

VSCode または Cursor の拡張機能マーケットプレイスで **always-accompany** と検索し、YonBan 拡張をインストールします。

## always-accompany への接続

| ステップ | 操作 |
|------|------|
| 1 | 拡張をインストールすると、YonBan は自動的に always-accompany バックエンドに接続します（デフォルトポート 8931） |
| 2 | 拡張が自動的に認証トークンを生成し、`~/.beilu/ide_ws_token` に書き込みます。バックエンドがそれを読み取って WebSocket ハンドシェイクが完了します |
| 3 | 接続が確立されたら、フロントエンドで[コードモード](beilu:mode/files)に入ると全 IDE ツールが使用できます |

切断時の自動再接続に対応しています。

## フロントエンド接続パネル

コードモードのアクティビティバーで connections ボタンをクリックして接続パネルを開きます。

**接続カード**：パネルには VSCode と Cursor の2枚のカードが表示され、それぞれ以下の情報を含みます：

- ステータスランプ（緑 = 接続済み / グレー = 切断）
- エディタのバージョン番号
- WebSocket アドレス
- 現在のセッション時間

**操作ボタン**：

- 再接続 — 切断後に手動で再接続
- 切断 — 現在の接続を能動的に切断
- 接続 — 新しいエディタインスタンスに接続
- ガイド — 拡張のインストールと設定チュートリアルを表示

**接続設定**：

| 設定 | 説明 |
|------|------|
| 自動再接続 | スイッチ。切断後に自動的に再接続を試みます |
| ポート番号 | WebSocket ポートの設定（デフォルト 8931） |
| タイムアウト | 接続タイムアウトのしきい値 |

**手動ツール呼び出し**：パネル下部からエディタに手動でツール呼び出しを送信でき、デバッグやテストに使用します——ターゲット IDE を選択、ツールを選択、パラメータ JSON を入力、送信して結果を確認します。
