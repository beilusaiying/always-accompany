# P1 自驱动发散召回系统：设计、算法与实验（合集）

## 摘要

本合集系统性地描述 always-accompany 项目中的 P1 自驱动子系统——一条**外置的发散思维链**。其出发点是设计者的一个基本判断：大语言模型（LLM）在结构上是"收拢机器"，其注意力机制与生成过程天然趋向汇聚，而不具备主动发散能力；因此发散必须以模型外置节点的方式实现。P1 在模型之外构建了一条不依赖 LLM 的处理管线：以记忆召回与对话上下文为锚点（收缩），经联想网络与六条学科轴（心理、信息、社会、逻辑、语言、认知）并行发散，在共享候选池中以空间加性投票与多对一收拢产出方向词（再收缩），最终以提示词注入的方式为模型的生成提供方向性框架。

合集共六章：第1章给出设计理念与概念体系；第2章给出系统架构与逐节点处理流程；第3章给出全部算法的形式化描述、评分框架与相关工作对照；第4章描述与之配套的记忆系统（数据层、处理管线、双线召回与注入机制）；第5章记录系统的演进史、评估体系与实验结果（含典型失败案例分析与失败方案汇编）；第6章描述语言资源体系与词库设计，并附术语表与系统现状。

## 阅读约定（全书统一）

1. **数值来源分级**。文中数值一律标注来源级别：**经实验校准的定档值**（由可复查的实验锁定）或**初始默认值（未经系统性调优）**。形状级公式（结构）为规格描述；具体权重、系数与阈值以实现为准。
2. **运行态声明**。本书所描述的自驱动发散管线与记忆本体召回，当前均处于**组件态**：算法与组件已实现并通过实验收口，是储备能力，当前默认休眠（各运行模式声明 `selfDriven: false`）。生产环境的现役检索机制是"AI P1"——每条消息由一个检索 AI（P1 预设）主观判定要调哪些记忆。全书描述的是这套已实现、待接回的组件库。
3. **引文**。除极少数标注"设计者原话"的引文外，全书均为对设计意图与实现的规范转述。
4. **相关工作分档**。第3章对每项算法给出 prior-art 对照，分档口径：A＝机制高度相似且公开时间早于本系统设计（可能撞车）；B＝部分相似（组件重叠、整体机制不同）；C＝仅概念词相近；D＝未找到相似公开工作。核查结论为 A＝0。
5. **术语**。各章在术语首次出现处给出定义；全书术语表见第6章附录A。
