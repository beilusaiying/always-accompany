# 螢幕感知 (beilu-eye)

beilu-eye 提供兩個獨立功能：

1. **桌面截圖感知**：自動截取螢幕內容，讓 AI 能「看到」你正在做什麼
2. **Electron 桌寵**：在桌面上顯示一個 AI 角色的虛擬形象

## 桌面截圖感知

### 工作原理

beilu-eye 透過一個 Python 腳本在後台定期截取桌面畫面：

```
Python 腳本截取螢幕
    ↓
透過 HTTP POST 發送截圖到 always-accompany 後端
    ↓
後端存入臨時注入狀態（injection_state）
    ↓
前端輪詢偵測到新截圖
    ↓
作為檔案附件隨訊息發送給 AI
    ↓
AI 看到截圖並給出回饋
    ↓
截圖自動清除，不留在後續上下文中
```

### 特點

- **一次性注入**：截圖在 AI 看到一次後自動清除，不會佔用後續對話的上下文空間
- **按需觸發**：截圖不是每輪都發，而是在有新截圖時才注入
- **令牌鑑權**：Python 腳本與後端之間透過 pet-token 令牌認證，防止未授權注入

### 使用情境

| 情境 | 說明 |
|------|------|
| 程式碼輔助 | AI 看到你的 IDE 畫面，了解目前程式碼上下文 |
| 遊戲陪伴 | AI 看到遊戲畫面，提供即時攻略建議 |
| 教學輔導 | AI 看到你的操作介面，及時糾正或指導 |
| 工作協助 | AI 看到你正在處理的文件/表格 |

## Electron 桌寵

### 功能

桌寵是一個懸浮在桌面上的 AI 角色虛擬形象視窗。它獨立於瀏覽器運行，始終顯示在桌面上。

### 啟用方式

在設定中心找到桌寵選項，點擊啟用。always-accompany 會自動啟動 Electron 桌寵程序。

### 程序管理

桌寵程序由 always-accompany 後端統一管理：

- **4 秒對帳週期**：每 4 秒檢查一次桌寵程序狀態（reconcile）
- **自動重啟**：如果桌寵程序意外退出，會自動重新啟動
- **優雅降級**：如果 Electron 二進位檔不存在（未安裝），會提示使用者安裝而非崩潰

### 前提條件

桌寵功能需要安裝 Electron 相依套件。在 `desktop-eye` 目錄下執行 `npm install` 即可。

## 安全機制

### pet-token 令牌閘

Python 截圖腳本向後端發送資料時，必須攜帶有效的 pet-token。這個令牌在桌寵/截圖程序啟動時由後端產生，程序關閉時撤銷。未授權的請求會被攔截。

### 黑白名單

可以設定視窗黑白名單，控制 AI 能看到哪些應用程式的截圖、不能看到哪些。

## 設定項

| 設定 | 說明 | 預設 |
|------|------|------|
| 截圖間隔 | Python 腳本截圖的時間間隔 | 3 秒 |
| 桌寵開關 | 是否啟用 Electron 桌寵 | 關閉 |
| 視窗黑名單 | 不截取的視窗清單 | - |
| 視窗白名單 | 只截取的視窗清單 | - |
