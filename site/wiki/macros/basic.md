# 基础宏

名称插入、时间日期、格式控制。无需参数，写上即用。

## 名称宏

插入用户名或角色名。

| 宏 | 别名 | 说明 | 示例输出 |
|----|------|------|----------|
| `{{user}}` | `<user>` | 当前用户的显示名 | `小明` |
| `{{char}}` | `<bot>` `<char>` | 当前角色的显示名 | `贝露` |

### 使用示例

在角色卡描述中：
```
{{char}}是一个温柔的少女，她总是关心{{user}}的感受。
```
替换后：
```
贝露是一个温柔的少女，她总是关心小明的感受。
```

在首条消息中：
```
"{{user}}，你今天看起来很开心呢！"{{char}}微笑着说。
```
替换后：
```
"小明，你今天看起来很开心呢！"贝露微笑着说。
```

> **提示**：`{{char}}` 和 `{{user}}` 是唯一会在前端（AI 回复显示时）也被替换的宏。其他宏只在后端（发送给 AI 前）替换。

## 时间日期宏

插入当前时间和日期，让 AI 感知"现在"。

| 宏 | 说明 | 示例输出 |
|----|------|----------|
| `{{time}}` | 当前时间（本地化短格式） | `14:30` |
| `{{date}}` | 当前日期（本地化长格式） | `2026年7月14日` |
| `{{weekday}}` | 当前星期几 | `星期一` |
| `{{isotime}}` | 24 小时制时间 | `14:30` |
| `{{isodate}}` | ISO 格式日期 | `2026-07-14` |

### 使用示例

在系统提示中提供时间感知：
```
当前时间：{{time}}
当前日期：{{date}}（{{weekday}}）
```
替换后：
```
当前时间：14:30
当前日期：2026年7月14日（星期一）
```

## 消息时间宏

获取聊天中最后一条消息的时间信息。

| 宏 | 说明 | 示例输出 |
|----|------|----------|
| `{{lasttime}}` | 最后一条消息的时间 | `14:25` |
| `{{lastdate}}` | 最后一条消息的日期 | `2026年7月14日` |
| `{{idle_duration}}` | 距离上次消息过了多久 | `5 minutes` |

### 使用示例

让 AI 感知对话间隔：
```
距离上次对话已经过了 {{idle_duration}}。
```
替换后：
```
距离上次对话已经过了 2 hours。
```

## 格式控制宏

控制提示词文本格式，不产生可见内容。

| 宏 | 说明 |
|----|------|
| `{{newline}}` | 插入一个换行符 |
| `{{trim}}` | 移除宏所在位置前后的空行 |
| `{{noop}}` | 空操作，替换为空字符串 |

### 使用示例

`{{trim}}` 常用于消除模板拼接时产生的多余空行：

```
这是第一段。
{{trim}}
这是第二段。
```

如果没有 `{{trim}}`，拼接时可能出现多余空行。加上后，空行会被清理掉，输出紧凑整洁。

`{{noop}}` 可以用来"占位"——在模板里标记一个位置，但不产生任何输出。
