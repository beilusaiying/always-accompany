# クイックスタート

## ステップ 1：AI サービスソースを追加する

[設定 → AIサービスソース](beilu:settings/api) → 追加：

| 項目 | 入力内容 |
|------|--------|
| 名称 | 任意の名前（ソースを区別するため） |
| サービスアドレス | API アドレス（例：`https://api.openai.com/v1/chat/completions`） |
| API Key | サービスプロバイダから取得したキー |
| チャンネル | 対応するプロバイダを選択（OpenAI / Claude / Gemini など） |
| モデル | 利用可能なモデルを選択 |

保存後、左カラムのモデルセレクタで該当ソースが選択されていることを確認してください。詳しくは [AI サービスソースの設定](install.md) をご覧ください。

## ステップ 2：キャラクターを選んで会話を始める

左サイドバーでキャラクターカードをクリックし、下部の入力欄からメッセージを送信すると、AI が返答します。

キャラクターがない場合は、キャラクターリスト上部の「+」をクリックして作成し、名前を入力するだけで構いません。

## ステップ 3：用途に合わせてモードを切り替える

上部の 4 つのボタンでモードを切り替えます：

| モード | ショートカット | 用途 |
|------|--------|---------|
| スマートモード | Ctrl+1 | タスクボード + 承認 |
| AIRP | Ctrl+2 | キャラクター会話（デフォルト） |
| IDE | Ctrl+3 | AI コーディング + ファイル操作 |
| ワークモード | Ctrl+4 | ワークフロー + スケジュールタスク |

詳しくは [モードシステム](beilu:wiki/modes/overview.md) をご覧ください。

## 次のステップ

- AI の返答スタイルを調整 → プリセットを変更、詳しくは [プリセットとパラメータ](first-chat.md)
- AI に情報を記憶させる → [記憶システム](beilu:wiki/memory/overview.md)が自動で動作、手動管理も可能
- 世界観設定を追加 → [編集画面 Tab2](beilu:editor/worldbook) でワールドブックを作成
- パラメータ調整 → 左カラムのモデルパラメータパネル（temperature / top_p など）
- マクロを使う → [マクロシステム](beilu:wiki/macros/overview.md)でプリセットに動的コンテンツを挿入
