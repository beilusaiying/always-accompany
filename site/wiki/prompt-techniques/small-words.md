# 小词汇大作用

一个精准的专业术语，可能比一整段描述更有效。这是因为 AI 的训练数据中，专业术语关联着大量的专业知识——你用一个词，就能"激活"AI 对应的整个知识网络。

## 原理

AI 的语言模型中，每个词都不是孤立的，它和大量相关概念形成了网络。普通词汇的关联网络较小，专业术语的关联网络则丰富得多。

```
普通词汇："情感"
  → AI 关联到：开心、难过、生气......（笼统）

专业术语："普拉特克情绪模型"
  → AI 关联到：8 种基本情绪、情绪轮、
    情绪的强度层级、混合情绪的组合方式......（精准且丰富）
```

一个专业术语就像一把钥匙，能打开 AI 知识库中对应的那扇门。

## 实际示例

### 写作场景

| 长段描述（效果一般） | 小词汇（效果更好） |
|-------------------|------------------|
| "角色的情感应该有多个层次，不只是单一的开心或难过，要展现复杂的、混合的情绪状态" | "角色情感参照普拉特克情绪模型，展现复合情绪" |
| "论述时先提出一个大前提，再提出一个小前提，最后得出结论" | "使用三段论结构" |
| "不要让角色用太专业的方式解释简单概念，要像普通人那样自然地聊天" | "注意知识遮蔽效应，角色用日常视角表达" |

### 开发者场景

| 长段描述 | 小词汇 |
|---------|--------|
| "代码里每个函数只做一件事，不要把多个功能塞在一个函数里" | "遵循单一职责原则" |
| "写错误处理时考虑所有可能出错的情况，并且出错后系统应该能继续运行" | "防御式编程，确保优雅降级" |
| "设计接口时让使用者不容易用错" | "遵循最小惊讶原则" |

## 使用技巧

### 1. 选对术语

不是随便丢一个专业名词就有效。术语必须是 AI 训练数据中有充分覆盖的——也就是说，是学术界或行业里真正广泛使用的概念。

```
有效术语（AI 知识库中有充分覆盖）：
- 普拉特克情绪模型（心理学）
- 三段论（逻辑学）
- 知识遮蔽 / 知识的诅咒（认知心理学）
- 英雄之旅（叙事学）
- 冰山理论（写作技法）
- 契诃夫之枪（戏剧理论）

效果存疑的术语（太小众或太新）：
- 某个小圈子的自造术语
- 未被广泛采用的新理论
```

### 2. 不要堆砌

小词汇的价值在于精准激活，堆砌反而会造成信号冲突。

```
错误：
使用三段论、苏格拉底反诘法、归谬法、
黑格尔辩证法来组织角色的对话逻辑。

正确：
角色的论述使用三段论结构，必要时以反问推进。
```

一两个精准的术语就够了。太多术语，AI 会试图同时满足所有，结果哪个都做不好。

### 3. 可以附带简要说明

如果你不确定 AI 是否能准确理解某个术语在当前语境下的含义，可以加一句简要说明：

```
角色情感参照普拉特克情绪模型——同一场景中可能
同时感受到几种不同的情绪，而非只有单一情感反应。
```

这样既激活了术语的知识网络，又限定了你想要的那个方面。

### 4. 搭配具体指引

小词汇负责"调出知识"，具体指引负责"应用知识"。两者配合效果最好。

```
只有小词汇（方向对但不够精确）：
使用冰山理论。

小词汇 + 具体指引（精准）：
使用冰山理论：角色的真实想法通过动作和细节暗示，
不通过内心独白直接说出。对话的潜台词比字面意思更重要。
```

## 常用小词汇速查

| 领域 | 术语 | 激活的知识 |
|------|------|-----------|
| 情感描写 | 普拉特克情绪模型 | 8 种基本情绪、复合情绪、强度层级 |
| 逻辑表达 | 三段论 | 大前提 → 小前提 → 结论的论证结构 |
| 角色对话 | 知识遮蔽(知识的诅咒) | 角色不会用超出自身认知的方式说话 |
| 叙事结构 | 英雄之旅 | 日常→召唤→考验→蜕变→回归 |
| 写作技法 | 冰山理论 | 表面只露一角，深层含义靠暗示 |
| 戏剧张力 | 契诃夫之枪 | 出现的细节都有叙事用途 |
| 悬念节奏 | 延迟满足 | 不急着揭示答案，逐步释放信息 |
| 代码设计 | 单一职责原则 | 一个模块只做一件事 |
| 接口设计 | 最小惊讶原则 | 行为符合使用者的直觉预期 |

## 小结

- 精准的专业术语能激活 AI 的知识网络，效果远超长段描述
- 选择 AI 训练数据中覆盖充分的术语
- 不要堆砌，一两个精准的就够
- 搭配具体指引使用，既激活知识又限定方向
