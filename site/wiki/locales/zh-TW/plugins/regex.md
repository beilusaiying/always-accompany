# 正規表示式增強 (beilu-regex)

beilu-regex 是一個正規表示式腳本引擎，用於在 AI 回覆到達使用者之前和之後對文字進行比對和替換。相容 SillyTavern 的正規表示式腳本格式，可以匯入 ST 社群的正規表示式腳本。

## 工作原理

beilu-regex 在訊息管線的兩個階段工作：

### TweakPrompt 階段（發送前）

在 TweakPrompt 的 dl=0 輪（最後一輪），beilu-regex 可以對即將發送給 AI 的訊息進行正規表示式處理。

### ReplyHandler 階段（回覆後）

AI 回覆到達後，beilu-regex 對回覆文字執行正規表示式規則，進行比對、替換、過濾等操作。

## 規則結構

每條正規表示式規則包含：

| 欄位 | 說明 |
|------|------|
| 名稱 | 規則的顯示名稱 |
| 比對模式 | 正規表示式（支援標準正規表示式語法） |
| 替換文字 | 比對成功時替換為的內容 |
| 作用範圍 | 應用於 AI 回覆 / 使用者輸入 / 兩者 |
| 啟用狀態 | 是否啟動此規則 |
| 適用預設集 | 規則與哪些預設集綁定 |

## 規則管理

### CRUD 操作

透過 SetData 介面的不同 `_action` 值進行規則的增刪改查：

- 建立規則
- 編輯規則
- 刪除規則
- 啟用/停用規則
- 調整規則順序

### 從 SillyTavern 匯入

beilu-regex 提供 `importFromSTFormat` 函式，可以直接匯入 SillyTavern 格式的正規表示式腳本。匯入時會自動轉換欄位格式。

匯入角色卡時，如果卡中包含正規表示式腳本，也會自動匯入並註冊到 beilu-regex。

## 正規表示式防護（ReDoS 防護）

beilu-regex 內建了 regexGuard 安全機制，防止惡意或意外的正規表示式導致 ReDoS（正規表示式拒絕服務）攻擊：

- 偵測潛在的災難性回溯模式
- 執行逾時保護
- 安全開關 `regexGuard.enabled` 受 owner 權限保護

## 預設集綁定

正規表示式規則可以與特定預設集綁定。切換預設集時，只有與目前預設集關聯的規則會生效。這使得不同角色/情境可以使用不同的正規表示式處理規則。

預設集切換時，beilu-preset 會調用 `_resyncPresetRegex` 同步正規表示式規則的啟動狀態。

## 典型用途

| 用途 | 說明 |
|------|------|
| 格式清理 | 去除 AI 回覆中的多餘空行、特殊標記 |
| 內容過濾 | 過濾不需要的回覆片段 |
| 標籤轉換 | 將 AI 的自訂標籤轉換為 HTML 或其他格式 |
| 角色名替換 | 在顯示前替換角色名的變體寫法 |
| 思維鏈隱藏 | 隱藏 AI 回覆中的推理過程標籤 |

## 資料儲存

規則資料儲存在外掛目錄的 `config_data.json` 中（資料不隨程式碼遷移，留在原位）。
