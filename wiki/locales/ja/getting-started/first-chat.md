# プリセットとパラメータ

プリセットは AI の振る舞いを制御します――どのような身分で返答するか、どのような指示を含めるか、どのようなフォーマットで出力するかを決定します。

## プリセットの切り替え

左カラムのプリセットセレクタからドロップダウンで選択します。プリセットの種類によって適した場面が異なります：

| プリセットの種類 | 用途 |
|---------|------|
| チャット系 | ロールプレイ、日常会話 |
| コーディング系 | コード生成、レビュー、デバッグ |
| ワーク系 | タスク管理、ドキュメント生成 |

切り替えると即座に反映され、次のメッセージから新しいプリセットが使用されます。詳しくは [プリセットシステム](beilu:wiki/presets/overview.md) をご覧ください。

## モデルパラメータの調整

左カラムの「サンプリングパラメータ」折りたたみグループに、以下のコントロールがあります：

| パラメータ | コントロールタイプ | 範囲 | 推奨値 |
|------|---------|------|------|
| Temperature | スライダー | 0 ~ 2 | チャット 0.7~1.0、コーディング 0.3~0.5 |
| Top P | スライダー | 0 ~ 1 | 通常 0.9~1.0 |
| Top K | 数値入力 | 0 ~ 500 | モデルのサポート状況に応じて設定 |
| Min P | スライダー | 0 ~ 1 | 必要に応じて微調整 |
| Freq Penalty | 数値入力 | -2 ~ 2 | 単語の繰り返しを抑制 |
| Pres Penalty | 数値入力 | -2 ~ 2 | 話題の多様性を促進 |
| Max Context | 数値入力 | — | モデルの性能に応じて設定（大きいほど記憶量が増加） |
| Max Tokens | 数値入力 | — | 必要に応じて設定 |
| ストリーミング出力 | スイッチ | — | オンを推奨 |
| 汎用プレフィル | スイッチ | — | 必要に応じてオン |
| 末尾プレフィル | ドロップダウン | 4 つの選択肢 | 場面に応じて選択 |
| 後処理 | ドロップダウン | 4 つの選択肢 | 場面に応じて選択 |

調整後「保存」をクリックして反映します。詳しくは [モデルパラメータ](beilu:wiki/ai-service/model-params.md) をご覧ください。

## キャラクターカードの編集

キャラクターカードの編集ボタンをクリックすると、[編集画面](beilu:editor/persona-edit)が開きます。5 つの Tab があります：

- **Tab 1 プリセット編集**：カテゴリフィルタ + プリセットの CRUD + 検索、左右分割レイアウト（左側：ドラッグ＆ドロップで並べ替え可能な条目リスト、右側：条目詳細の編集）、9 つの Marker 挿入位置
- **Tab 2 [ワールドブック](beilu:wiki/memory/worldbook-overview.md)**：ワールドブックの CRUD、左右分割レイアウト（検索 + 条目リスト / 条目編集：タイトル、有効スイッチ、起動モード、位置、深度、キーワード、サブキーワード、正規表現マッチ、動的スイッチ、ソート、キャラクターバインド、コンテンツ）
- **Tab 3 ユーザーペルソナ**：ペルソナカードリスト（アバター + 名前 + 説明の編集 + 保存 / 有効化 / 削除）
- **Tab 4 [INJ インジェクション](beilu:wiki/memory/inj-overview.md)**：統計行 + 検索、左右分割レイアウト（条目リスト / 条目編集：名前、有効、ロール、深度、ソート、インジェクションモード、プラットフォーム、コンテンツ）、新規追加 / デフォルトに復元
- **Tab 5 [正規表現](beilu:wiki/presets/regex.md)**：3 段階のスコープ（グローバル / キャラクター / プリセット）、正規表現エディタ（pattern / flags / replace など）、リアルタイムテストパネル、ReDoS ガード

キャラクターの説明が具体的であるほど、AI のロールプレイ精度が向上します。

## ユーザーペルソナ

ご自身の身分情報（名前、性格、背景）を設定すると、AI がそれに基づいてインタラクション方式を調整します。編集画面の Tab 3 または設定画面で管理できます。
