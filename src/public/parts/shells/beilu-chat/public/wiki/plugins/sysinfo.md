# 系统信息：让 AI 知道“现在在哪”，但由你决定是否注入

beilu-sysinfo 收集当前时间、时区和运行环境信息，并可选择加入操作系统、主机名、用户名、进程内存和自定义字段。

它适合需要时间判断、跨系统路径建议或环境差异提示的任务。普通角色聊天不需要这些信息时，可以不注入。

## 两个开关不要混淆

- 插件配置里的 `enabled` 默认开启，表示系统信息能力可用；
- 真正进入提示词的 `INJ-plugin-sysinfo` 注入条目当前默认关闭；
- 插件自己的 GetPrompt 当前不直接注入内容。

因此“插件已加载”不等于“每轮都把系统信息发给 AI”。需要时在 INJ 面板启用对应条目，并检查预览。

## 可提供的信息

| 信息 | 默认 | 说明 |
|---|---|---|
| 本地日期、时间、时区 | 开 | 适合日程、时效和问候 |
| 操作系统与架构 | 开 | 适合命令和路径差异 |
| 主机名与用户名 | 随 OS 信息 | 可能具有隐私含义 |
| 进程内存用量 | 关 | 是贝露运行进程的内存，不是整机监控仪表盘 |
| 自定义字段 | 空 | 由用户添加固定环境说明 |
| 刷新间隔 | 每次刷新 | 可改为缓存若干秒 |

## 完整链路

```text
系统运行环境
  → sysinfo 收集并按配置格式化
  → 设置页预览
  → INJ-plugin-sysinfo 决定是否进入当前模式提示词
  → 主 AI 服务
```

显示文案由可编辑的注入文本管理；代码只负责字段和开关，不把不可见的硬编码说明偷偷塞进请求。

## 数据和隐私

配置保存在项目数据目录的全局设置文件中，不按用户分桶。启用注入后，被选中的系统信息会成为最终提示词的一部分，并发送给当前 AI 服务源。

如果你在共享服务器上使用，建议只保留时间和必要的 OS 信息，关闭主机名、用户名、内存与敏感自定义字段。

## 什么时候不要开

- 角色聊天与当前系统无关；
- 提示词预算很紧；
- 服务源不应看到主机名、用户名或内部环境名；
- 你只需要工具后端知道工作区，而不需要模型知道系统详情。
