# 工作模式 (Work)

## 進入工作模式

| 方式 | 操作 |
|------|------|
| 頂部模式選擇器 | 點擊「Work」標籤 |
| 鍵盤快捷鍵 | `Ctrl+4` 或 `Alt+4` |

切入工作模式時，系統會自動啟動 scheduler（定時任務排程器）。進入後預設為全寬 AI 對話區。

## 按任務情境操作

### 管理任務

點擊活動欄的 **overview** 按鈕開啟任務台。

- **任務列表** — 按狀態分為進行中/待辦/已完成三組，每組顯示計數和進度條
- **工作檔案管理** — 建立、檢視、編輯、刪除工作檔案（CRUD），檔案與任務關聯

### 調整 AI 權限

點擊活動欄的 **toolkit** 按鈕開啟工具箱。

- **權限快速預設** — 一鍵切換：完整（全部權限）/ 最小（基本權限）/ 唯讀
- **逐條權限開關** — 對 11 項工具權限逐一設定
- **路徑白名單/黑名單** — 指定 AI 可存取或禁止存取的檔案路徑
- **命令分類授權** — 按命令類別批次授權或禁止

### 委派任務給 AI

- 將任務委派給 AI 獨立執行，AI 在獨立執行緒中完成，不阻塞主對話
- 可查看委派進度和結果

### 設定定時任務

- 設定定時觸發的任務（cron 式排程）
- 自動執行預設的工作流程
- 切入工作模式時 scheduler 自動啟動

### 編排流水線

- **Skill 組卡片** — 每張卡片顯示組名和步驟數，點擊啟動按鈕（▶）開始執行
- **新建組** — 點擊新建按鈕彈出對話方塊，填寫組名並勾選要包含的子模式及其順序，執行時按順序自動切換子模式推進

### 連接 MCP 服務

點擊活動欄的 **mcp** 按鈕。

- 連接 MCP（Model Context Protocol）服務，擴展 AI 可呼叫的工具集
- 支援自訂 MCP 伺服端設定

### 監控執行狀態

點擊活動欄的 **operations** 按鈕開啟監控面板，檢視執行狀態與日誌。

### 管理並行任務

點擊活動欄的 **groups** 按鈕，管理並行任務組。

## 活動欄按鈕一覽

| 按鈕 | 名稱 | 開啟的側邊欄面板 |
|------|------|-----------------|
| chat | 預設對話 | 全寬 AI 對話（預設檢視） |
| overview | 任務台 | 任務列表、工作檔案管理 |
| history | 對話歷史 | 歷史對話列表與切換 |
| toolkit | 工具箱 | 權限、工具、命令授權 |
| mcp | MCP | MCP 服務連接與管理 |
| operations | 監控 | 執行狀態與日誌監控 |
| groups | 並行組 | 並行任務組管理 |
| submodes | 子模式 | 子模式列表（動態注入） |

## 子模式（11 個）

工作模式內建 11 個子模式，涵蓋工作流全流程：

| 子模式 | 用途 |
|--------|------|
| 任務確認師 | 理解需求，核對理解，建立任務檔案 |
| 任務設計 | 讀取任務 MD，反推設計執行流程 |
| 流程最佳化 | 最佳化流程，減少 token 消耗，精簡步驟 |
| 框架審查 | 審查流程設計錯誤，只最佳化不打回 |
| 提示詞設計 | 為任務設計所需的提示詞 |
| 提示詞+預設集設計 | 設計 always-accompany 提示詞與預設集本身 |
| Skill/腳本製作 | 製作腳本、skill、MCP 接入 |
| 流程組裝 | 將提示詞、skill、腳本組裝為流程組 |
| 執行流程組 | 執行流程組，按順序執行並記錄日誌 |
| 驗證 | 使用者驗證或自動驗證執行結果 |
| 收尾歸檔 | 歸檔任務 MD，更新索引，產生完成報告 |

每個子模式可獨立綁定預設集、API 源、模型和採樣參數。詳見 [子模式與切換](beilu:wiki/modes/submodes.md)。

子模式選擇欄位於輸入框上方，點擊彈出浮層列表供切換。在子模式管理面板中可設定 ID、圖示、名稱、描述、預設集綁定、API 源選擇、後處理規則、預填充內容和啟用/停用開關。

## 後端模式值

工作模式對應後端模式值 `work`，前端 Tab 為 `work`。
