# 少樣本提示

少樣本提示（Few-Shot Prompting）是在提示詞中給出 1-3 個範例，讓 AI 從範例中學習你期望的輸出風格和格式。這是最直觀也最有效的技巧之一。

## 什麼是少樣本提示

- **Zero-Shot**：不給範例，只給指令 —— 「寫一段角色對話」
- **Few-Shot**：給 1-3 個範例 + 指令 —— 「這是幾個對話範例，請按照類似的風格寫」
- **Many-Shot**：給大量範例 —— 通常不推薦，容易過擬合

Few-Shot 的核心思路是：**示範比描述更有效**。你很難用文字精確描述「自然的對話節奏」，但給兩段範例，AI 一看就明白。

## 為什麼有效

AI 的學習能力不只體現在訓練階段。在推理時，AI 也會從上下文中的範例裡提取模式。給它看幾個範例，它會自動學習到：

- 輸出的**格式**（長度、結構、排版）
- 輸出的**風格**（用詞、句式、語氣）
- 輸出的**內容邊界**（該包含什麼、不該包含什麼）

## 使用方法

### 基本結構

```
[指令說明]
這是你的任務描述......

[範例 1]
輸入：......
輸出：......

[範例 2]
輸入：......
輸出：......

[目前任務]
輸入：......
```

### 範例：角色對話風格

假設你希望角色對話簡短、口語化、有個人特色。

```
角色對話應當簡短有力，體現個人說話習慣。以下是範例：

範例 1：
場景：朋友邀請出門
角色回應：「去哪......算了，反正我也沒事。走吧。」

範例 2：
場景：被問到心情如何
角色回應：「嗯？還行吧。——別那樣看我，真還行。」

現在請按照上面的風格，回應目前場景。
```

AI 從這兩個範例中能學到：
- 角色話少，用省略號和破折號
- 會在回答後追加一句補充
- 語氣不冷不熱，表面隨意但有暗示

這些如果用文字描述，可能需要一整段話，效果還不如兩個範例直觀。

### 範例：輸出格式

```
回覆格式如下：

範例：
**場景**：教室午休
**角色動作**：靠在椅背上，單手撐著下巴望向窗外。
**角色台詞**：「又是這種天氣啊......」
**旁白**：陽光從窗簾縫隙裡漏進來，在桌面上切出一條光線。

請按照這個格式回覆。
```

## 範例數量

| 數量 | 效果 | 適用情境 |
|------|------|---------|
| 1 個 | 基本有效，但 AI 可能過度模仿這唯一的範例 | 格式簡單、風格要求明確 |
| 2-3 個 | 最佳平衡，AI 能從多個範例中提取共性 | 大多數情境 |
| 4+ 個 | 過擬合風險增大，AI 可能變成「複述範例」 | 一般不推薦 |

推薦給 **2-3 個範例**。多個範例之間應該有差異——不同的場景、不同的情緒基調，但保持同一種風格。這樣 AI 學到的是「風格」，而非「這個特定場景的回答」。

## 過擬合風險

### 什麼是過擬合

AI 不是「學到了你的風格」，而是「記住了你的範例」，然後在輸出中反覆使用範例中的具體詞句、句式、甚至情節模式。

### 過擬合的訊號

- AI 的輸出和範例的用詞高度重合
- AI 在不同場景中都用類似的句式結構
- AI 的輸出缺乏變化，好像在套範本

### 如何避免

**1. 範例之間保持差異性**

```
錯誤（範例太相似）：
範例 1：「切......誰要去啊。」 ← 傲嬌回避
範例 2：「哼，我才沒有在意。」 ← 傲嬌回避
範例 3：「別、別誤會了！」 ← 傲嬌回避

→ AI 學到的結論：這個角色每次都要傲嬌回避
→ 過擬合：所有場景都變成傲嬌範本
```

```
正確（範例有差異）：
範例 1：「切......誰要去啊。」（日常，回避）
範例 2：「......你沒事吧。」（關心，但表達克制）
範例 3：「給你的。不用謝。」（行動多於言語）

→ AI 學到的結論：角色表達克制，但方式多樣
→ 不會過擬合到單一模式
```

**2. 指令和範例搭配使用**

不要只給範例不給指令。指令說明「要什麼」，範例展示「長什麼樣」，兩者配合才最有效。

```
只有範例（風險高）：
（三個範例，沒有任何說明文字）
→ AI 可能過度模仿範例的具體內容

範例 + 指令（更好）：
角色表達克制、行動多於言語。
口癖中會用省略號代替完整句子。
以下是幾個範例供參考風格：
（範例）
```

**3. 控制範例長度**

範例不要太長。短範例讓 AI 學風格，長範例讓 AI 記內容。

## 在 beilu 中的應用

beilu 的[預設集條目](../presets/structure.md)和[世界書條目](../memory/worldbook-entries.md)中都可以嵌入少樣本範例。適合使用 Few-Shot 的情境：

- **角色卡**中給出角色的對話風格範例
- **寫作預設集**中展示期望的輸出格式
- **世界書條目**中給出特定場景的回應模式

> 注意：範例會佔用 token。在 token 緊張的情境中，1 個精選範例就足夠了。

## 小結

- 少樣本提示是透過範例直接展示期望輸出的技巧
- 給 2-3 個有差異的範例效果最好
- 注意過擬合風險：範例要有差異性，搭配指令使用，控制長度
- 範例讓 AI 學「風格」，不是讓 AI 記「內容」
