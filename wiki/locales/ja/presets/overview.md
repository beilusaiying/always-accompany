# プリセットシステム

左カラムのドロップダウンからプリセットを選ぶと、AI の動作が即座に切り替わります。チャットモードにはチャットプリセット、コードモードにはコードプリセットを使用し、切り替えるだけで反映されます。

## プリセットを切り替える

対話画面のプリセットセレクターで、クリックするだけで現在のプリセットを切り替えられます。切り替え後すぐに反映され、次のメッセージから新しいプリセットが使用されます。

## 条目を有効/無効にする

beilu-toggle プラグインを使って、プリセットパネルで個々の条目をチェック/チェック解除し、AI が受け取る指示をリアルタイムで調整できます。

## プリセットをインポートする

プリセット管理パネルでインポートをクリックし、SillyTavern 形式の JSON ファイルを選択します。always-accompany は SillyTavern プリセット形式と完全互換であり、ゼロから独自に作成することもできます。

## プリセットの分類

always-accompany のプリセットは用途別に分類されています（bucket と呼びます）：

| 分類 | 用途 | 典型的なプリセット |
|------|------|---------|
| Code | プログラミング支援 | コードレビュー、プログラミングアシスタント、IDE 指示 |
| Work | ワークフロー | タスク管理、ドキュメント作成、データ分析 |
| Clone | ロールプレイ | キャラクターカード適応、対話スタイル |
| 汎用 | シーン不問 | カスタムプリセット |

詳しくは[プリセットの分類と選択](categories.md)をご覧ください。

## プリセットとモードの連動

各モード（[チャットモード](beilu:mode/chat) / Code / [ワークモード](beilu:mode/work) / [Bot管理](beilu:mode/bot)）には異なるプリセットをバインドできます。モードを切り替えると、システムがそのモードにバインドされたプリセットを自動的に読み込みます：

- チャットモードにチャットプリセットを使用 → AI がコンパニオンキャラクターとして振る舞います
- コードモードにコードプリセットを使用 → AI がプログラミングアシスタントとして振る舞います
- ワークモードにワークプリセットを使用 → AI がワークパートナーとして振る舞います

詳しくは[プリセットとモードの連動](mode-binding.md)をご覧ください。

## 詳細

### プリセットの構成

1つのプリセットは複数の**条目（Prompt Entry）**で構成されます。各条目はテキストと制御属性のセットです：

| 構成要素 | 説明 |
|---------|------|
| 条目の内容 | AI に送信される実際のテキスト（システムプロンプト、キャラクター指示、スタイル要件など） |
| 並び順 | プロンプト内での条目の前後位置（前にあるほど AI が優先的に注目します） |
| 有効状態 | 各条目を個別にオン/オフできます。不要なものは一時的にオフにできます |
| インジェクション深度 | チャット履歴内での条目の挿入位置（深度 0 = 最下部、深度 4 = 下から4番目のメッセージの位置） |
| ロールマーク | 条目がどの身分で送信されるか（system / user / assistant） |

### プリセットが行うこと

メッセージを送信するとき、always-accompany はメッセージをそのまま AI に渡すわけではありません。裏側で、プリセットエンジンがキャラクター設定、システム指示、ワールドブック、チャット履歴、プラグインプロンプトなどのコンテンツを、プリセットで定義された条目の順序に従って完全なプロンプトに組み立ててから AI に送信します。

### プリセットとモデルパラメータ

プリセットにはプロンプト条目だけでなく、モデルパラメータ（temperature、top_p など）も含めることができます。プリセットの読み込み時にこれらのパラメータも一緒に反映され、各プリセットが独自の生成スタイルを持てるようになります。

パラメータの優先順位：プリセットのパラメータ < ランタイムパラメータパネル < 拡張レイヤーのモデルパラメータオーバーライド

詳しくは[モデルパラメータ](../ai-service/model-params.md)をご覧ください。[AIサービスソース](beilu:settings/api)パネルでもパラメータを調整できます。
