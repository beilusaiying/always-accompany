# 正規表現とレンダリングエントリ

ワールドブックエントリにおける正規表現マッチングと GENERATE/RENDER マーカーの使い方について説明します。

## 正規表現マッチング

エントリで `useRegex: true` を設定すると、key と keysecondary 内のキーワードは正規表現としてマッチングされます。

### 基本的な使い方

| 用途 | 正規表現の書き方 | マッチング例 |
|------|----------|----------|
| 完全一致の語 | `魔法` | 「魔法師」、「学魔法」 |
| 語境界 | `\b魔法\b` | 独立した「魔法」のみマッチ |
| 複数候補 | `魔法\|法術\|咒語` | いずれかの語が出現すればマッチ |
| オプション部分 | `魔法(師)?` | 「魔法」または「魔法師」 |
| ワイルドカード | `魔.*師` | 「魔法師」、「魔導師」 |

### selective との併用

`selective: true` の場合、key と keysecondary の両方が正規表現マッチングを使用し、両方が同時にヒットしなければトリガーしません。

**例**：
- key: `森林|丛林|树林`
- keysecondary: `夜晚|深夜|黑暗`
- 効果：会話中に「森林系」と「夜系」の語が同時に言及された時のみ、「夜の森」に関する設定をインジェクション

### 注意事項

- 正規表現の特殊文字（`.` `*` `+` `?` `(` `)` `[` `]` `{` `}` `\` `^` `$` `|`）をリテラル文字としてマッチングする場合はバックスラッシュでエスケープが必要です
- マッチング範囲にはユーザーメッセージと AI 返信の直近の内容が含まれます（具体的なスキャン深度は設定に依存）
- 正規表現マッチングは大文字小文字を区別します。区別しない場合は `(?i)` フラグを使用してください

## GENERATE と RENDER マーカー

ワールドブックエントリの content 内で 2 種類の特殊マーカーを使用して、情報の閲覧対象を区別できます。

### [GENERATE:*] — AI のみ閲覧可能

```
[GENERATE:角色内心活动指引]
当角色在森林中时，描写环境时应包含以下感官细节：
- 听觉：鸟鸣、风声、树叶沙沙
- 嗅觉：泥土、花香、腐叶
- 触觉：潮湿的空气、脚下的落叶
[/GENERATE]
```

`[GENERATE:*]` で囲まれた内容は AI に送信されるコンテキスト内にのみ表示され、ユーザーインターフェースには表示されません。以下に適しています：

- AI への執筆ガイダンス
- キャラクターの行動ルール
- 内部ロジックの説明
- ユーザーに直接見せたくないメタ指示

### [RENDER:*] — ユーザーのみ閲覧可能

```
[RENDER:场景气氛文字]
--- 阴暗的森林，月光穿过树冠洒下斑驳的光影 ---
[/RENDER]
```

`[RENDER:*]` で囲まれた内容はユーザーインターフェースにのみ表示され、AI には送信されません。以下に適しています：

- シーンの雰囲気描写（装飾的テキスト）
- UI のヒント情報
- ユーザーへの説明文
- AI が処理する必要はないがユーザーに見せたい内容

### 混合使用

1 つのエントリに通常のコンテンツ、GENERATE コンテンツ、RENDER コンテンツを同時に含めることができます：

```
这是森林区域的设定。

[GENERATE:AI写作指导]
描写森林时注意季节变化对环境的影响。
[/GENERATE]

[RENDER:用户提示]
提示：你当前位于古老森林的深处。
[/RENDER]
```

この例では：
- 「这是森林区域的设定。」—— AI とユーザーの両方が閲覧可能
- GENERATE 部分 —— AI のみ閲覧可能
- RENDER 部分 —— ユーザーのみ閲覧可能

### 動作チェーン

```
ワールドブックエントリがトリガーされ、content がインジェクションフローに入る
    ↓
content 内のマーカーを解析：
  - [GENERATE:*]...[/GENERATE] ブロックを検出
  - [RENDER:*]...[/RENDER] ブロックを検出
  - 残りの部分は通常コンテンツ
    ↓
AI コンテキスト構築時：
  - 通常コンテンツを含む
  - GENERATE ブロックの内容を含む
  - RENDER ブロックの内容を除外
    ↓
ユーザー表示構築時：
  - 通常コンテンツを含む
  - GENERATE ブロックの内容を除外
  - RENDER ブロックの内容を含む
```

## 開発者向け注意事項

- マーカーの構文は `[GENERATE:名前]` と `[/GENERATE]` のペアで、名前部分は識別用ですがロジックには影響しません
- マーカーはネストできません（GENERATE ブロック内に RENDER ブロックを入れることはできません）
- 解析はインジェクション時に行われ、解析失敗時（閉じタグの欠落など）は content 全体が通常コンテンツとして処理されます
- 正規表現マッチングのスキャン範囲（何ターン前まで遡るか）はトリガーの感度に影響します。範囲が大きすぎると誤トリガーが増え、小さすぎるとトリガー漏れが発生します
