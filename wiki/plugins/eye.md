# 屏幕感知 (beilu-eye)

beilu-eye 提供两个独立功能：

1. **桌面截图感知**：自动截取屏幕内容，让 AI 能"看到"你正在做什么
2. **Electron 桌宠**：在桌面上显示一个 AI 角色的虚拟形象

## 桌面截图感知

### 工作原理

beilu-eye 通过一个 Python 脚本在后台定期截取桌面画面：

```
Python 脚本截取屏幕
    ↓
通过 HTTP POST 发送截图到 always-accompany 后端
    ↓
后端存入临时注入状态（injection_state）
    ↓
前端轮询检测到新截图
    ↓
作为文件附件随消息发送给 AI
    ↓
AI 看到截图并给出反馈
    ↓
截图自动清除，不留在后续上下文中
```

### 特点

- **一次性注入**：截图在 AI 看到一次后自动清除，不会占用后续对话的上下文空间
- **按需触发**：截图不是每轮都发，而是在有新截图时才注入
- **令牌鉴权**：Python 脚本与后端之间通过 pet-token 令牌认证，防止未授权注入

### 使用场景

| 场景 | 说明 |
|------|------|
| 编程辅助 | AI 看到你的 IDE 画面，了解当前代码上下文 |
| 游戏陪伴 | AI 看到游戏画面，提供实时攻略建议 |
| 教学辅导 | AI 看到你的操作界面，及时纠正或指导 |
| 工作协助 | AI 看到你正在处理的文档/表格 |

## Electron 桌宠

### 功能

桌宠是一个悬浮在桌面上的 AI 角色虚拟形象窗口。它独立于浏览器运行，始终显示在桌面上。

### 启用方式

在设置中心找到桌宠选项，点击启用。always-accompany 会自动启动 Electron 桌宠进程。

### 进程管理

桌宠进程由 always-accompany 后端统一管理：

- **4 秒对账周期**：每 4 秒检查一次桌宠进程状态（reconcile）
- **自动重启**：如果桌宠进程意外退出，会自动重新启动
- **优雅降级**：如果 Electron 二进制不存在（未安装），会提示用户安装而非崩溃

### 前提条件

桌宠功能需要安装 Electron 依赖。在 `desktop-eye` 目录下执行 `npm install` 即可。

## 安全机制

### pet-token 令牌闸

Python 截图脚本向后端发送数据时，必须携带有效的 pet-token。这个令牌在桌宠/截图进程启动时由后端生成，进程关闭时撤销。未授权的请求会被拦截。

### 黑白名单

可以配置窗口黑白名单，控制 AI 能看到哪些应用的截图、不能看到哪些。

## 配置项

| 配置 | 说明 | 默认 |
|------|------|------|
| 截图间隔 | Python 脚本截图的时间间隔 | 3 秒 |
| 桌宠开关 | 是否启用 Electron 桌宠 | 关闭 |
| 窗口黑名单 | 不截取的窗口列表 | - |
| 窗口白名单 | 只截取的窗口列表 | - |
