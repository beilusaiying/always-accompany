# スクリプトエンジン

always-accompany は EJS テンプレートレンダリング機能（beilu-ejs プラグイン）を提供しており、プリセットエントリやキャラクターカード内で EJS テンプレート構文を使って動的コンテンツを記述できます。これは単純なマクロ置換より強力で、条件分岐、ループ、複雑な計算などのロジックを実装できます。

## EJS テンプレートエンジン (beilu-ejs)

### 基本構文

EJS（Embedded JavaScript）はテキスト内に JavaScript コードを埋め込むことができます：

| タグ | 説明 | 例 |
|------|------|------|
| `<% %>` | JS コードを実行（出力なし） | `<% if (x > 5) { %>` |
| `<%= %>` | 式の結果を出力（HTML エスケープ） | `<%= user %>` |
| `<%- %>` | 式の結果を出力（エスケープなし） | `<%- rawHtml %>` |

### 利用可能なテンプレート変数

EJS テンプレートは実行時にマクロ環境の変数にアクセスできます：

- `char` — キャラクター名
- `user` — ユーザー名
- カスタム変数（beilu-mvu で設定した変数）
- その他のマクロ環境内の値

### サンドボックスセキュリティ

beilu-ejs はデフォルトでサンドボックス内で EJS テンプレートを実行し、アクセス可能なグローバルオブジェクトや API を制限して、悪意のあるコード実行を防止します。

**sandboxOptOut** はセキュリティ上重要なスイッチです：サンドボックスをオフにすると EJS は完全な Node.js 環境（ファイルシステム、ネットワークなどを含む）にアクセスでき、マルチユーザー環境では深刻なセキュリティリスクがあります。そのため sandboxOptOut の変更にはインスタンス owner 権限が必要です。

### 使用シーン

| シーン | 説明 |
|------|------|
| 条件付き指示 | モード/変数値に応じて異なるシステムプロンプトを切替 |
| 動的リスト | キャラクター関係データに基づいて人物リストを生成 |
| 複雑なフォーマッティング | 構造化データを AI フレンドリーなテキストにレンダリング |
| 計算・統計 | プリセット内で数値計算を実行 |

## ユーザープラグインスクリプト (beilu-plugin-host)

### 概要

beilu-plugin-host はユーザーがカスタム JavaScript プラグインスクリプトを作成・ロードできるようにします。ユーザープラグインは組み込みプラグインと同等のインターフェース機能（GetPrompt / TweakPrompt / ReplyHandler など）を持ちます。

### セキュリティ制約

ユーザープラグインスクリプトの実行も同様にセキュリティポリシーの管理下にあります。サーバーデプロイモードでは、ユーザープラグインのサブプロセス spawn に owner の明示的な認可が必要です。

## change-prompt ジェネレーター

change-prompt は特殊なサービスジェネレーターで、プリセットエントリ内で `${}` 構文を使用したテンプレート評価を可能にします。これも deployGatedAllow ゲートで保護されています。

## スクリプトの実行タイミング

| エンジン | 実行フェーズ | 説明 |
|------|---------|------|
| EJS (beilu-ejs) | マクロ置換フェーズ | evaluateMacros プロセス中に実行 |
| 正規表現 (beilu-regex) | TweakPrompt / ReplyHandler | メッセージ送信前/返信後に実行 |
| ユーザープラグイン (plugin-host) | GetPrompt / TweakPrompt / ReplyHandler | 組み込みプラグインと同じタイミング |
