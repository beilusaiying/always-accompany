# 聊天模式 (Chat / AIRP)

## 进入聊天模式

| 方式 | 操作 |
|------|------|
| 顶部模式选择器 | 点击「Chat」标签 |
| 键盘快捷键 | `Ctrl+2` 或 `Alt+2` |

进入后直接在中央对话区输入消息即可开始对话。

## 基本操作

- **日常对话**：直接输入消息，无需特殊配置
- **角色扮演**：从左栏选择角色卡，选择适合的预设，然后开始对话
- **调参优化**：通过右栏的模型参数面板微调 AI 表现（如降低温度获得更稳定的回复）

## 界面布局

三栏布局，左右栏均可折叠：

- **左栏**：会话列表、角色卡选择、会话管理（新建 / 删除 / 归档）
- **中央区域**：对话主区，消息输入与显示
- **右栏**：当前会话的配置面板（预设、模型参数、正则等）

## 你可以做的事

| 想做什么 | 怎么做 |
|---------|-------|
| 创建新会话 | 左栏点击新建 |
| 切换历史会话 | 左栏点击会话列表 |
| 加载角色卡 | 左栏选择角色卡 |
| 切换预设 | 右栏预设管理区选择 |
| 调整模型参数 | 右栏模型参数面板 |
| 编辑/重新生成消息 | 消息气泡上的操作按钮 |
| 启用联网搜索 | 对话中手动触发或 AI 自主触发 |
| 配置正则处理器 | 右栏正则规则区，可启用/禁用单条规则 |
| 配置 INJ 注入 | 右栏 INJ 配置区，设置自动注入的背景信息 |
| 导出对话记录 | 会话管理中导出 |

## 后端模式值

聊天模式对应后端模式值 `chat`。Bot 管理、Helper 等辅助视图也复用 `chat` 作为后端模式值，但在前端展示不同的界面。
