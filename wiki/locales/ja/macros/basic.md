# 基本マクロ

名前の挿入、日時、書式制御。パラメータ不要で、書くだけで使えます。

## 名前マクロ

ユーザー名またはキャラクター名を挿入します。

| マクロ | 別名 | 説明 | 出力例 |
|----|------|------|----------|
| `{{user}}` | `<user>` | 現在のユーザーの表示名 | `太郎` |
| `{{char}}` | `<bot>` `<char>` | 現在のキャラクターの表示名 | `ベイル` |

### 使用例

キャラクターカードの説明欄で：
```
{{char}}は優しい少女で、いつも{{user}}の気持ちを気にかけています。
```
置換後：
```
ベイルは優しい少女で、いつも太郎の気持ちを気にかけています。
```

最初のメッセージで：
```
「{{user}}、今日は元気そうだね！」{{char}}は微笑みながら言った。
```
置換後：
```
「太郎、今日は元気そうだね！」ベイルは微笑みながら言った。
```

> **ヒント**：`{{char}}` と `{{user}}` は、フロントエンド（AI 応答の表示時）でも置換される唯一のマクロです。その他のマクロはバックエンド（AI に送信する前）でのみ置換されます。

## 日時マクロ

現在の日時を挿入し、AI に「今」を認識させます。

| マクロ | 説明 | 出力例 |
|----|------|----------|
| `{{time}}` | 現在の時刻（ローカライズ短形式） | `14:30` |
| `{{date}}` | 現在の日付（ローカライズ長形式） | `2026年7月14日` |
| `{{weekday}}` | 現在の曜日 | `月曜日` |
| `{{isotime}}` | 24 時間制の時刻 | `14:30` |
| `{{isodate}}` | ISO 形式の日付 | `2026-07-14` |

### 使用例

システムプロンプトで時間認識を提供する場合：
```
当前时间：{{time}}
当前日期：{{date}}（{{weekday}}）
```
置換後：
```
当前时间：14:30
当前日期：2026年7月14日（月曜日）
```

## メッセージ時刻マクロ

チャット内の最後のメッセージの時刻情報を取得します。

| マクロ | 説明 | 出力例 |
|----|------|----------|
| `{{lasttime}}` | 最後のメッセージの時刻 | `14:25` |
| `{{lastdate}}` | 最後のメッセージの日付 | `2026年7月14日` |
| `{{idle_duration}}` | 前回のメッセージからの経過時間 | `5 minutes` |

### 使用例

AI に会話の間隔を認識させる場合：
```
距离上次对话已经过了 {{idle_duration}}。
```
置換後：
```
距离上次对话已经过了 2 hours。
```

## 書式制御マクロ

プロンプトテキストの書式を制御します。目に見える内容は出力しません。

| マクロ | 説明 |
|----|------|
| `{{newline}}` | 改行を1つ挿入します |
| `{{trim}}` | マクロの前後にある空行を除去します |
| `{{noop}}` | 空操作。空文字列に置換されます |

### 使用例

`{{trim}}` はテンプレート結合時に生じる余分な空行を除去するためによく使われます：

```
これは第一段落です。
{{trim}}
これは第二段落です。
```

`{{trim}}` がない場合、結合時に余分な空行が現れることがあります。追加すると空行が整理され、コンパクトで整った出力になります。

`{{noop}}` は「プレースホルダー」として使えます——テンプレート内で位置を示しつつ、出力は何も生成しません。
