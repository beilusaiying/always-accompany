# 游戏陪伴模式 (Companion)

配置桌宠和 Live2D 角色。AI 角色以桌面宠物形式陪伴，通过 Live2D 模型展示动态表情和动作，支持屏幕感知和 AI 自主发言。

## 进入方式

通过辅助菜单进入 Companion 视图。

## 界面布局

Companion 视图以 8 个段落导航组织内容，点击导航标签可跳转到对应段落：

| 段落 | 内容概述 |
|------|---------|
| 启动形象 | 角色卡、对话文件、截图频率等启动绑定 |
| Live2D | Live2D 模型选择、缩放、位置、待机动作 |
| 图片包 | 静态图片包管理、表情键、多图上传 |
| 互动触碰 | 热区配置、部件点选、命中检测 |
| 屏幕感知 | 自动截图、目标窗口、画质设置 |
| 安全 | 安全相关配置 |
| 陪伴消息 | 对话气泡样式、停留时间、游戏穿透 |
| 教程 | 使用教程与说明 |

## 核心功能

### 启动绑定

配置桌宠启动时使用的核心参数：

| 控件 | 说明 |
|------|------|
| 角色卡下拉 | 选择桌宠使用的角色卡 |
| 对话文件 | 绑定对话存档 |
| 对话模式 | 选择对话交互方式 |
| 截图频率 | 自动截图的触发间隔 |
| 轮询间隔 | AI 主动检查状态的间隔 |
| 频率自适应 | 根据用户活跃度自动调整轮询频率 |

### 桌宠形象

控制桌宠的显示方式和外观：

| 控件 | 说明 |
|------|------|
| 启用开关 | 开启/关闭桌宠显示 |
| 形象模式 | 选择 Live2D 或图片包 |
| 模型下拉 | 选择使用的模型/图片包 |
| 位置 | 桌宠停靠位置（左上/右上/左下/右下） |
| 待机表情 | 空闲时的默认表情 |
| 表情标签名 | 表情与 AI 输出的标签映射 |
| 动作标签名 | 动作与 AI 输出的标签映射 |

### Live2D

Live2D 模型的详细调整：

- **模型选择** —— 在已安装的 Live2D 模型间切换
- **缩放** —— 调整模型大小
- **位置** —— 调整模型在屏幕上的位置
- **待机动作** —— 设置空闲时循环播放的动作
- **保存微调** —— 保存当前调整的参数
- **拖拽定位** —— 直接拖拽模型到目标位置
- **逐参数调试** —— 逐一调整模型的各项参数

### 图片包

使用静态图片作为桌宠形象（无需 Live2D 模型）：

- **包选择** —— 选择已有的图片包
- **新建** —— 创建新的图片包
- **默认表情** —— 设置未匹配时显示的默认图片
- **缩放** —— 调整图片显示大小
- **表情键管理** —— 为不同表情名称绑定对应图片
- **多图上传** —— 批量上传表情图片

### 互动触碰

配置用户点击桌宠不同部位时的交互反应：

- **热区列表** —— 查看和管理已配置的所有触碰热区
- **点选部件** —— 在模型上点击选择要配置的部件
- **画热区** —— 在模型上手动绘制交互区域
- **放大编辑器** —— 放大视图以便精细调整热区位置
- **命中检测频率** —— 设置检测用户点击的频率

### 陪伴消息（对话框）

自定义桌宠对话气泡的外观和行为：

| 控件 | 说明 |
|------|------|
| 气泡预览 | 实时预览气泡效果 |
| 透明度 | 气泡背景透明度 |
| 停留时间 | 消息显示后多久自动消失 |
| 圆角 | 气泡圆角大小 |
| 底色 | 气泡背景颜色 |
| 文字色 | 消息文字颜色 |
| 描边色 | 气泡边框颜色 |
| 名字标签 | 是否显示角色名称标签 |
| 游戏穿透 | 开启后鼠标可穿透气泡点击游戏画面 |
| 横幅 | 横幅式消息显示 |
| 声音 | 消息到达时的提示音 |

### 屏幕感知

让 AI 能够"看到"用户的屏幕内容：

| 控件 | 说明 |
|------|------|
| 自动截图 | 开启/关闭自动截屏 |
| 频率 | 截图间隔时间 |
| 分辨率 | 截图分辨率 |
| 目标窗口 | 指定截取哪个窗口（全屏或特定应用） |
| 画质 | 截图压缩画质 |

### AI 自主

配置 AI 主动发起对话和行为的能力：

- **后端驱动开关列表** —— 逐项启用或禁用各类自主行为
- **Dwell 间隔** —— 设置 AI 主动发言的最小等待间隔

开启后 AI 可以在空闲时主动发起对话，根据屏幕感知内容和情境自主选择合适的动作和表情。

## 后端模式值

Companion 视图的前端 Tab 为 `companion`，不映射后端模式值。这意味着进入 Companion 视图时，后端的模式状态保持不变，仅切换前端界面。

## 使用建议

- **选择形象**：先决定使用 Live2D 还是图片包，再导入对应资源
- **配置触碰**：为模型的不同部位设置热区，让交互更自然
- **调整气泡**：根据游戏/桌面的背景色调整气泡透明度和配色，确保可读性
- **屏幕感知**：开启后 AI 能理解你正在做什么，但会消耗更多 API 调用
- **AI 自主**：开启 AI 自主设置后，桌宠会更生动，但也会消耗更多 API 调用
