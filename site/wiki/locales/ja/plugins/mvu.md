# 変数システム (beilu-mvu)

beilu-mvu（Model-View-Update）は always-accompany の変数システムプラグインです。プリセット、キャラクターカード、AI 返信で変数の読み書きが可能になり、ターンをまたいだ状態トラッキングを実現します。例えば、キャラクターの好感度、HP、タスク進捗などの動的な数値を変数システムで管理できます。

## 変数の種類

| 種類 | スコープ | ライフサイクル | マクロ構文 |
|------|--------|---------|--------|
| ローカル変数 | 現在の会話 | 会話の存続期間中 | `{{getvar::名称}}` / `{{setvar::名称::値}}` |
| グローバル変数 | 会話をまたぐ | 永続化 | `{{getglobalvar::名称}}` / `{{setglobalvar::名称::値}}` |

## 変数マクロ

### 変数の読み取り

```
{{getvar::hp}}           → ローカル変数 hp の値を読み取り
{{getglobalvar::score}}  → グローバル変数 score の値を読み取り
```

### 変数の書き込み

```
{{setvar::hp::100}}           → ローカル変数 hp = 100 に設定
{{setglobalvar::score::50}}   → グローバル変数 score = 50 に設定
```

### 数値演算

```
{{addvar::hp::-10}}           → hp を 10 減少
{{addglobalvar::score::5}}    → score を 5 増加
```

## パイプラインインターフェース

### GetPrompt

beilu-mvu の GetPrompt インターフェースは、現在の変数状態をプロンプトにインジェクションし、AI に現在の変数値を伝えることができます。

### TweakPrompt

TweakPrompt フェーズで、beilu-mvu はメッセージ内の変数マクロ置換を処理します。

### ReplyHandler

AI の返信が到着した後、beilu-mvu は返信中の変数操作コマンド（AI が特定の変数操作タグを使用した場合）を解析し、対応する読み書き操作を実行します。

## マクロシステムとの関係

beilu-mvu の変数マクロはマクロシステムのサブセットです。変数マクロはバックエンドの置換フェーズ（AI に送信される前）に実行されます。マクロ置換エンジン `evaluateMacros` は変数マクロに遭遇すると beilu-mvu の読み書き関数を呼び出します。

詳しくは[変数マクロ](../macros/variables.md)をご覧ください。

## 使用シーン

| シーン | 変数の例 |
|------|---------|
| RPG ゲーム | HP、MP、ゴールド、レベル |
| 好感度システム | 好感度数値、関係段階 |
| タスクトラッキング | タスク状態（進行中/完了）、進捗パーセンテージ |
| カウンター | 会話ターン数、イベントトリガー回数 |
| 条件分岐 | 変数値に応じて AI の返信スタイルを変更 |

## データ保存

- ローカル変数は会話とともに保存されます
- グローバル変数は SetData を通じて永続化されます
