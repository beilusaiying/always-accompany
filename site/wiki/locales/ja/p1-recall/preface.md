# P1 自己駆動発散リコールシステム：設計、アルゴリズムと実験（合集）

## 要旨

本合集は always-accompany プロジェクトにおける P1 自己駆動サブシステム——**外付けの発散思考チェーン**——を体系的に記述します。その出発点は設計者の根本的な判断にあります。大規模言語モデル（LLM）は構造上「収束マシン」であり、そのアテンション機構と生成プロセスは本質的に収束に向かう傾向を持ち、能動的な発散能力を備えていません。したがって、発散はモデル外部のノードとして実装する必要があります。P1 はモデルの外側に LLM に依存しない処理パイプラインを構築します。記憶リコールと対話コンテキストをアンカーポイントとして（収縮）、連想ネットワークと六条の学問軸（心理・情報・社会・論理・言語・認知）による並列発散を経て、共有候補プール内で空間加算投票と多対一収束により方向語を生成し（再収縮）、最終的にプロンプトインジェクションの形でモデルの生成に方向性フレームワークを提供します。

合集は現在、全七章です。第1～6章は P1 の設計思想、旧ノード体系、記憶設計、過去の実験を保存します。第7章は、Node0–4、直近最大5件のユーザーメッセージ + Data、四次元分離、ホワイトボックス証拠、遅延読み込み、有界キャッシュという現在の本番契約を記録します。「今、実際にどう動くか」を知りたい場合は第7章から読み、旧章の実行状態を現在のソースより優先しないでください。
