# 界面布局

## 三栏结构

| 区域 | 内容 |
|------|------|
| 左栏 | 角色信息 / 预设选择 / 世界书 / 模型参数（模式不同内容不同） |
| 中央 | 对话消息流 |
| 右栏 | 运行时开关 / 任务看板（可折叠） |
| 顶部 | 模式选择器（4个主模式） |
| 底部 | 输入框 |

左右栏可拖拽调宽，可折叠隐藏。IDE/工作模式下布局变为活动栏+侧边栏形式。

## 模式切换

顶部4个按钮（Ctrl+1~4）切主模式。点「···」进辅助视图（Bot管理 / 游戏陪伴 / 记忆管理 / ST适配）。

## 常用操作

| 操作 | 方法 |
|------|------|
| 发消息 | Enter |
| 换行不发送 | Shift + Enter |
| 重新生成 | 消息下方按钮 |
| 编辑消息 | 点击消息内容 |
| 删除消息 | 右键 → 删除 |
| 新建对话 | 扩展菜单 → 新建对话 |
| 切角色 | 左侧栏点其他角色卡 |
