# AI 操作后端

AI 通过后端连接操作你的开发环境——读写文件、执行命令、Git 操作等，42 个工具全部通过审批系统管控。

支持三种后端：

| 后端 | 适用场景 | 安装方式 |
|------|---------|---------|
| **CLI** | 不需要 IDE，随本体自动启动 | 无需安装——内置，开箱即用 |
| **VSCode** | 在 VSCode 中开发 | 扩展市场搜索 always-accompany |
| **Cursor** | 在 Cursor 中开发 | 扩展市场搜索 always-accompany |

三种后端共用同一协议（WebSocket + `<ideToolCall>` 标签），工具集完全一致，AI 无需区分。后端只负责执行工具——所有安全裁决（信任等级、权限规则、命令黑/灰名单、审批）都在本体完成，你在「AI 控制面板」的设置对三种后端同等生效。

## CLI 后端（无需 IDE，零安装）

CLI 后端随本体自动启动，不需要任何手动操作：

- **工作区**：跟随文件面板的「打开文件夹」——你在文件树打开哪个目录，CLI 就在哪个目录工作（改目录自动热切，无需重启）
- **端口 / 自动启动**：在「后端管理」面板的 CLI 后端区设置（默认端口 8931，被占用自动递增）
- **重启 / 停止**：同一面板一键操作
- AI 的提问（question）请在 beilu 网页端回答——CLI 后端本身没有交互界面

### CLI 与 IDE 后端的互斥让位

两套后端不会同时工作——**只要有任何一个 VSCode/Cursor 窗口在线，CLI 就自动「让位停机」**（省内存 CPU，也避免两套后端抢同一条指令）。这不是 bug：

- 你装了 YonBan 扩展、打开了编辑器 → CLI 自动停下，所有工具走编辑器；
- 你把编辑器窗口全部关掉 → CLI 自动恢复，无缝接管；
- 你在面板里**手动点了 CLI 的「启动 / 重启」** → 系统视为你明确要用 CLI，编辑器在线也不再停它。

所以如果你看到「CLI 刚启动几秒又自己停了」，先看看是不是有编辑器窗口连着——这是让位，不是崩溃。

## IDE 后端（VSCode / Cursor）

在扩展市场搜索 **always-accompany**，安装后自动连接。

### 开了多个编辑器窗口会怎样？

可以放心多开。每个 VSCode/Cursor 窗口都是独立的「执行端」，后端会同时连上所有在线窗口，并把**每个对话绑定到一个具体窗口**——就像给每条电话线接上各自的分机：

- **自动绑定**：你在某个编辑器窗口里打开某个对话，该对话就自动跟随这个窗口。
- **手动绑定**：在对话的「＋号」菜单里显式指定执行窗口。手动指定是「粘性」的——之后即使你在别的窗口打开这个对话，绑定也不会被悄悄改走；只有你再次手动指定、或原窗口彻底离线时才会变。
- **自动接回**：窗口重启换了端口、或你关掉又重新打开同一个项目文件夹，绑定会按「窗口身份 / 工作区」自动接回，不用重新设置。
- **安全兜底**：绑定的窗口关了、又没有打开同一工作区的其他窗口时，AI 的操作会**直接失败并告诉你原因**，绝不会跑到另一个窗口的项目里去写文件。

一句话：两个项目开两个窗口、对应两个对话，各写各的，互不串门。

## 连接到 always-accompany

| 步骤 | 操作 |
|------|------|
| 1 | 后端启动（CLI 随本体自启 / IDE 扩展自动启动）后，把实际端口与认证 Token 写入 `~/.beilu/` 发现文件 |
| 2 | 本体按发现文件自动找到活跃后端并完成 WebSocket 握手（端口自增后也能找对） |
| 3 | 连接建立后，前端进入[编程模式](beilu:mode/files)即可使用全部工具 |

支持断线自动重连。未连接任何后端时，AI 仍可通过本体自带的 `<file_op>` 文件工具在工作区内读写文件——两条轨并行，后端只是能力更全的一条。

## 前端连接面板

在编程模式活动栏点击 connections 按钮打开连接面板。

**连接卡片**：面板显示 CLI、VSCode、Cursor 三张卡片，每张包含：

- 状态灯（绿 = 已连接 / 灰 = 断开）
- 后端版本号
- WebSocket 地址
- 当前会话时长

**操作按钮**：

- 重连 — 断线后手动重连
- 断开 — 主动断开当前连接
- 连接 — 连接到后端实例
- 指南 — 查看安装与配置教程

**连接设置**：

| 设置 | 说明 |
|------|------|
| 自动重连 | 开关，断线后自动尝试重连 |
| 端口号 | 配置 WebSocket 端口（默认 8931） |
| 超时时间 | 连接超时阈值 |

**手动工具调用**：面板底部可手动向编辑器发送工具调用，用于调试或测试——选择目标 IDE、选择工具、填写参数 JSON、发送并查看结果。
