# ウェブ検索 (beilu-web)

beilu-web は AI がインターネットを検索しウェブページを閲覧できるようにします。AI がリアルタイム情報の取得、資料の検索、事実の確認を必要とする時、`<search>` タグと `<browse>` タグを使ってウェブリクエストを発行できます。

## 検索機能

### AI による検索発行

AI が返信中に `<search>` タグを使って検索リクエストを発行します。beilu-web がタグを解析して検索を実行し、結果を次のターンの会話にインジェクションします。

### 検索結果

検索結果には 3 つのフィールドが含まれます：

| フィールド | 説明 |
|------|------|
| title | ウェブページのタイトル |
| url | ウェブページのアドレス |
| snippet | コンテンツの要約 |

AI は検索結果を受け取った後、直接回答する（要約情報で十分な場合）か、`<browse>` タグで特定のウェブページにアクセスしてより詳細な内容を取得することができます。

### 手動検索

beilu-web の設定パネルでは、手動で検索語を入力して検索し、検索結果を確認することもできます。

## ウェブブラウジング

AI は `<browse>` タグを使って指定 URL のウェブページコンテンツにアクセスします。beilu-web がウェブページの本文を取得して AI に返します。

### クロール能力の検出

beilu-web は起動時に現在の環境のウェブクロール能力を自動検出します：

- Playwright ブラウザがインストールされている場合、JavaScript 動的ページのレンダリングが可能
- インストールされていない場合、シンプルな HTTP 取得にフォールバック（SPA ページの内容を取得できない場合があります）

`ensureBrowsers` で Playwright ブラウザをインストールすると、動的（JavaScript レンダリング）ページのクロールをサポートできます。

## セキュリティメカニズム

ウェブリクエストは `safeFetch` セキュリティ取得関数で送信され、以下が組み込まれています：

- タイムアウト保護
- レスポンスサイズ制限
- 悪意のある URL フィルタリング

## 使用シーン

| シーン | 説明 |
|------|------|
| リアルタイム情報の照会 | 天気、ニュース、為替レートなど最新データが必要な質問 |
| 技術ドキュメントの参照 | AI が公式ドキュメントを参照して技術的な質問に回答 |
| ファクトチェック | AI が不確かな情報を検証 |
| 資料収集 | 複数のソースから情報を集約 |

## 設定

beilu-web の設定パネルで検索エンジンや関連設定を調整できます。ウェブ機能が正常に動作するにはネットワーク接続が必要です。

## 記憶システムとの関係

beilu-web のウェブ検索は[記憶システム](../memory/overview.md)の P8 プリセットからも呼び出されます。AI が会話中に外部情報が必要と判断した時、P8 パイプラインがウェブ検索をトリガーし、検索結果が自動的に会話コンテキストに統合されます。
