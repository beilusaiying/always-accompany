# ゲームコンパニオンモード (Companion)

デスクトップペットと Live2D キャラクターを設定します。AI キャラクターがデスクトップペットとして寄り添い、Live2D モデルで動的な表情やアクションを表示します。スクリーン感知や AI の自律発言にも対応しています。

## 入り方

補助メニューから Companion ビューに入ります。

## インターフェースレイアウト

Companion ビューは 8 つのセクションナビゲーションで構成されています。ナビゲーションタブをクリックすると対応するセクションにジャンプします：

| セクション | 内容概要 |
|------|---------|
| 起動イメージ | キャラクターカード、対話ファイル、スクリーンショット頻度などの起動バインド |
| Live2D | Live2D モデルの選択、スケール、位置、待機アクション |
| 画像パック | 静止画像パックの管理、表情キー、複数画像アップロード |
| インタラクティブタッチ | ホットゾーン設定、パーツ選択、ヒット検出 |
| スクリーン感知 | 自動スクリーンショット、対象ウィンドウ、画質設定 |
| セキュリティ | セキュリティ関連の設定 |
| コンパニオンメッセージ | 対話バブルのスタイル、表示時間、ゲーム穿透 |
| チュートリアル | 使い方のチュートリアルと説明 |

## コア機能

### 起動バインド

デスクトップペット起動時に使用するコアパラメータを設定します：

| コントロール | 説明 |
|------|------|
| キャラクターカードドロップダウン | デスクトップペットが使用するキャラクターカードを選択します |
| 対話ファイル | 対話アーカイブをバインドします |
| 対話モード | 対話のインタラクション方式を選択します |
| スクリーンショット頻度 | 自動スクリーンショットのトリガー間隔 |
| ポーリング間隔 | AI が能動的にステータスをチェックする間隔 |
| 頻度自動調整 | ユーザーのアクティブ度に応じてポーリング頻度を自動調整します |

### デスクトップペットのイメージ

デスクトップペットの表示方法と外観を制御します：

| コントロール | 説明 |
|------|------|
| 有効スイッチ | デスクトップペットの表示をオン/オフします |
| イメージモード | Live2D または画像パックを選択します |
| モデルドロップダウン | 使用するモデル/画像パックを選択します |
| 位置 | デスクトップペットの配置位置（左上/右上/左下/右下） |
| 待機表情 | アイドル時のデフォルト表情 |
| 表情タグ名 | 表情と AI 出力のタグのマッピング |
| アクションタグ名 | アクションと AI 出力のタグのマッピング |

### Live2D

Live2D モデルの詳細調整：

- **モデル選択** —— インストール済みの Live2D モデル間で切り替えます
- **スケール** —— モデルのサイズを調整します
- **位置** —— 画面上のモデルの位置を調整します
- **待機アクション** —— アイドル時にループ再生するアクションを設定します
- **微調整を保存** —— 現在調整したパラメータを保存します
- **ドラッグで配置** —— モデルを直接ドラッグして目標位置に配置します
- **パラメータ個別デバッグ** —— モデルの各パラメータを1つずつ調整します

### 画像パック

静止画像をデスクトップペットのイメージとして使用します（Live2D モデル不要）：

- **パック選択** —— 既存の画像パックを選択します
- **新規作成** —— 新しい画像パックを作成します
- **デフォルト表情** —— マッチしない場合に表示するデフォルト画像を設定します
- **スケール** —— 画像の表示サイズを調整します
- **表情キー管理** —— 各表情名に対応する画像をバインドします
- **複数画像アップロード** —— 表情画像を一括アップロードします

### インタラクティブタッチ

ユーザーがデスクトップペットの各部位をクリックした時のインタラクション反応を設定します：

- **ホットゾーンリスト** —— 設定済みのすべてのタッチホットゾーンを閲覧・管理します
- **パーツ選択** —— モデル上でクリックして設定するパーツを選択します
- **ホットゾーンを描画** —— モデル上に手動でインタラクション領域を描画します
- **エディタを拡大** —— ホットゾーンの位置を精密調整するためにビューを拡大します
- **ヒット検出頻度** —— ユーザーのクリックを検出する頻度を設定します

### コンパニオンメッセージ（ダイアログボックス）

デスクトップペットの対話バブルの外観と動作をカスタマイズします：

| コントロール | 説明 |
|------|------|
| バブルプレビュー | バブル効果をリアルタイムプレビュー |
| 透明度 | バブル背景の透明度 |
| 表示時間 | メッセージ表示後に自動的に消えるまでの時間 |
| 角丸 | バブルの角丸の大きさ |
| 背景色 | バブルの背景色 |
| テキスト色 | メッセージのテキスト色 |
| ボーダー色 | バブルの枠線色 |
| 名前ラベル | キャラクター名ラベルの表示/非表示 |
| ゲーム穿透 | 有効にするとマウスがバブルを貫通してゲーム画面をクリックできます |
| バナー | バナー形式のメッセージ表示 |
| サウンド | メッセージ到着時の通知音 |

### スクリーン感知

AI がユーザーの画面内容を「見る」ことができるようにします：

| コントロール | 説明 |
|------|------|
| 自動スクリーンショット | 自動画面キャプチャのオン/オフ |
| 頻度 | スクリーンショットの間隔時間 |
| 解像度 | スクリーンショットの解像度 |
| 対象ウィンドウ | キャプチャするウィンドウを指定します（全画面または特定のアプリ） |
| 画質 | スクリーンショットの圧縮画質 |

### AI 自律

AI が能動的に対話や行動を開始する機能を設定します：

- **バックエンド駆動スイッチリスト** —— 各種自律行動を個別に有効/無効にします
- **Dwell 間隔** —— AI が能動的に発言する最小待機間隔を設定します

有効にすると、AI はアイドル時に能動的に対話を開始し、スクリーン感知の内容と状況に応じて適切なアクションと表情を自律的に選択します。

## バックエンドモード値

Companion ビューのフロントエンド Tab は `companion` で、バックエンドモード値にはマッピングされません。つまり、Companion ビューに入ってもバックエンドのモード状態は変わらず、フロントエンドのインターフェースのみが切り替わります。

## 使用上のアドバイス

- **イメージを選ぶ**：まず Live2D と画像パックのどちらを使用するか決めてから、対応するリソースをインポートしましょう
- **タッチを設定する**：モデルの各部位にホットゾーンを設定して、インタラクションをより自然にしましょう
- **バブルを調整する**：ゲーム/デスクトップの背景色に合わせてバブルの透明度と配色を調整し、可読性を確保しましょう
- **スクリーン感知**：有効にすると AI があなたの作業内容を理解できるようになりますが、より多くの API 呼び出しを消費します
- **AI 自律**：AI 自律設定を有効にするとデスクトップペットがより生き生きしますが、より多くの API 呼び出しも消費します
