# 高度なマクロ

ランダム選択、サイコロ、テキスト処理、時刻計算など。ほとんどはパラメータが必要で、ダブルコロン `::` で区切ります。

## ランダムと選択

### {{random::選択肢リスト}}

カンマ区切りの選択肢から**ランダム**に1つ選びます。置換のたびに結果が異なる場合があります。

```
{{random::晴れ,曇り,雨,雪}}
```

出力例：`雨`

**用途**：会話にランダム性と変化を加えます。

例——キャラクターのランダムな開始時の気分：
```
{{char}}の今日の気分は{{random::嬉しい,穏やか,憂鬱,興奮,のんびり}}です。
```

### {{pick::選択肢リスト}}

カンマ区切りの選択肢から**確定的**に1つ選びます。同じ入力は同じコンテキストで常に同じ結果を返します。

```
{{pick::春,夏,秋,冬}}
```

出力：`秋`（同じコンテキストでは毎回この結果になります）

**random との違い**：`random` は毎回異なる可能性がありますが、`pick` は同じコンテキストでは結果が固定されます。安定性が必要なときは `pick` を、変化が必要なときは `random` を使います。

## サイコロ

### {{roll:NdM}} / {{roll:NdM+K}}

サイコロを振るシミュレーションです。`N` はサイコロの数、`M` は面の数、`K` は任意の加減修正値です。

| 書き方 | 意味 | 結果範囲 |
|------|------|----------|
| `{{roll:1d6}}` | 6面サイコロを1個振る | 1~6 |
| `{{roll:2d10}}` | 10面サイコロを2個振って合計 | 2~20 |
| `{{roll:1d20+5}}` | 20面サイコロを1個振って5を加算 | 6~25 |
| `{{roll:3d6-2}}` | 6面サイコロを3個振って2を減算 | 1~16 |

### 使用例

ロールプレイでの技能判定：
```
{{user}}は鍵開けを試み、{{roll:1d20+3}} を出した（DC 15）。
```
出力例：
```
太郎は鍵開けを試み、18 を出した（DC 15）。
```

戦闘ダメージ計算：
```
{{char}}は剣を振り下ろした！{{roll:2d6+4}} ダメージを与えた。
```

## テキスト処理

### {{reverse::テキスト}}

テキストを逆順に出力します。

```
{{reverse::Hello World}}
```
出力：`dlroW olleH`

```
{{reverse::こんにちは}}
```
出力：`はちにんこ`

## 時刻計算

### {{timediff::時刻1::時刻2}}

2つの時点間の差分を計算し、人間が読みやすい時間差の説明を返します。

```
{{timediff::2026-01-01::2026-07-14}}
```
出力：時間差の人間が読みやすい表現

**用途**：プロンプト内で「ある出来事からどれくらい経ったか」や「ある時点までどれくらいか」を表現します。

## タイムゾーンとフォーマット

### {{time_utc+N}}

指定したタイムゾーンオフセットの現在時刻を取得します。`N` は UTC オフセットです。

| 書き方 | 意味 |
|------|------|
| `{{time_utc+8}}` | UTC+8 の時刻（東八区） |
| `{{time_utc+9}}` | UTC+9 の時刻（東九区） |
| `{{time_utc-5}}` | UTC-5 の時刻（米国東部標準時） |
| `{{time_utc+0}}` | UTC 時刻 |

例：
```
東京時間：{{time_utc+9}}
```

### {{datetimeformat FORMAT}}

カスタムフォーマット文字列を使って現在の日時を出力します。フォーマットは標準的な日時フォーマット構文に従います。

```
{{datetimeformat YYYY年MM月DD日 HH:mm}}
```
出力例：`2026年07月14日 14:30`

```
{{datetimeformat MM/DD/YYYY}}
```
出力例：`07/14/2026`

## 特殊用途マクロ

### {{banned "単語"}}

禁止ワードをマークします。プロンプト内で AI に特定の単語を使うべきでないことを伝えるために使用します。

```
{{banned "ある単語"}}
```

### {{//コメント内容}}

コメントマクロです。内容は完全に除去され、最終的なプロンプトには表示されません。プリセットテンプレート内にメモを書くのに適しています。

```
{{//この部分はプリセット編集者向けのコメントで、AIには見えません}}
本文のプロンプト内容はここに書きます。
```

## クイックリファレンス

| マクロ | パラメータ | 説明 | 確定性 |
|----|------|------|--------|
| `{{random::リスト}}` | カンマ区切りの選択肢 | ランダムに1つ選択 | ランダム |
| `{{pick::リスト}}` | カンマ区切りの選択肢 | 確定的に1つ選択 | 確定 |
| `{{roll:NdM}}` | サイコロ式 | サイコロを振る | ランダム |
| `{{reverse::テキスト}}` | 任意のテキスト | テキストを逆順に | 確定 |
| `{{timediff::t1::t2}}` | 2つの時点 | 時間差を計算 | 確定 |
| `{{time_utc+N}}` | タイムゾーンオフセット | 指定タイムゾーンの時刻 | 確定 |
| `{{datetimeformat FMT}}` | フォーマット文字列 | カスタム日付フォーマット | 確定 |
| `{{banned "単語"}}` | 単語 | 禁止ワードマーク | - |
| `{{//コメント}}` | コメント内容 | コメント（除去されます） | - |
