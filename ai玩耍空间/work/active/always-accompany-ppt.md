# always accompany 商业宣传PPT设计文档

## 1. 任务信息
- **类型**：产品宣讲/商业宣传
- **页数**：12页（硬边界）
- **密度档**：高密（详细+数据+注释，但不拥挤）
- **风格**：蓝白色调（深蓝标题 + 深灰正文 + 白底 + 蓝色强调）
- **特殊要求**：动态效果好、多用deco/bg_html小配件、字体优化、diagram框架图

## 2. 风格决策
- **配色方案**：
  - 主背景（深色页）：深邃蓝（#0A1931）
  - 主背景（浅色页）：纯净白（#F9F9F9）
  - 文字（深色页）：白（#FFFFFF）/ 银灰（#E0E6ED）
  - 文字（浅色页）：深炭灰（#2C3E50）/ 钢灰（#7F8C8D）
  - 强调色：科技蓝（#0085FF）/ 亮天蓝（#00D2FC）
- **深浅开合**：
  - s1 (封面)、s7 (过渡/架构)、s12 (结尾)：深邃蓝底（#0A1931）
  - s2-s6、s8-s11 (内容页)：纯净白底（#F9F9F9）
- **动画效果**：全局采用 `fade` 渐入，配合 `slide-up` 局部动效。
- **装饰配件**：
  - `bg_html`：在背景层绘制微弱的网格线（#EAEAEA）与半透明蓝色渐变圆（opacity: 0.05）。
  - `deco`：参数化几何图形（圆、矩形、连接线），用于引导视线。

### s2: 行业痛点 | 大模型的三座大山：上下文限制、注意力涣散与高昂算力成本
*   **版面视觉**：
    *   **背景**：纯净白底（#F9F9F9），带有灰色网格背景线。
    *   **布局**：三列垂直卡片网格，分别对应三大行业痛点。
    *   **卡片设计**：冷灰色边框卡片（#E0E6ED），顶部配以红色警示 Deco 标志。
*   **高密数据与文案**：
    *   **痛点 1：物理窗口限制 (Context Window Limit)** —— 即使是 128K/1M 窗口，面对海量历史对话或企业万级文档时，依然面临“大海捞针”困境，物理内存占用呈平方级（$O(N^2)$）暴涨。
    *   **痛点 2：注意力涣散 (Attention Lost in the Middle)** —— 大模型在处理长文本时，极易丢失中间段落的核心信息。测试表明，当上下文超过 64K 时，中间段落信息检索准确率骤降至 **<35%**。
    *   **痛点 3：算力与存储成本雪崩 (Cost Explosion)** —— 长期对话产生海量历史 Token，每次调用都需要全量重算（KV Cache 暴涨），导致企业级部署的 API 成本与服务器带宽成本呈指数级上升。
