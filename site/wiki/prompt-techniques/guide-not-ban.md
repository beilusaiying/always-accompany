# 引导优于禁止

这是提示词写作中最重要的原则之一：**告诉 AI 该做什么，比告诉它不该做什么更有效。**

## 为什么禁止性指令效果差

AI 处理"不要做 X"时，它首先要理解 X 是什么，然后试图避开。但"避开"是一个模糊的行为——避开之后做什么？AI 并不知道。结果要么是过度回避（连相关的好表现也一起消失），要么是换一种方式犯同样的问题。

而"做 Y"是一个明确的行为方向，AI 可以直接朝那个方向走。

## 技巧一：把禁止改成引导

### 核心原则

不说"不要做什么"，而说"以什么为主"。

### 对比示例

| 禁止式（效果差） | 引导式（效果好） |
|----------------|----------------|
| 不要使用比喻 | 以白描为主 |
| 不要写长句 | 使用短句，保持节奏明快 |
| 不要重复用户的话 | 用自己的话回应，推进对话 |
| 不要输出无关内容 | 聚焦当前场景，每段推进一个情节点 |
| 不要使用网络用语 | 使用书面口语化表达 |
| 禁止出现 OOC | 始终以角色身份回应 |

### 实际写法

```
错误：
不要使用比喻和排比。不要写太长的心理描写。
不要让角色说出不符合人设的话。

正确：
以白描为主，对话推动情节。
心理活动通过动作和微表情间接表达。
角色语言贴合各自的身份背景和说话习惯。
```

注意看：正确写法不仅说了"不要什么"，还说了"要什么"。AI 读完就知道该往哪个方向走。

## 技巧二：绝对命令改为指导

### 什么是绝对命令

"必须""绝对不能""永远不要""始终要"——这些都是绝对命令。

### 为什么要少用

1. **过拟合**：绝对命令让 AI 把这条规则的优先级拉到极高，挤压其他方面的表现。比如"必须每句话都体现角色性格"会让 AI 每句都生硬地塞入性格标签，反而不自然。
2. **阅读疲劳**：当提示词里满是"必须""不能"时，AI 的注意力被分散到太多硬性约束上，反而抓不住真正重要的东西。
3. **冲突风险**：绝对命令之间容易互相矛盾。"必须保持简洁"和"必须详细描写场景"放在一起，AI 不知道该听哪个。

### 怎么改

把"禁止"改成"避免/减少"，把"必须"改成"你会/使用"。

| 绝对命令（容易过拟合） | 指导性表达（更自然） |
|---------------------|-------------------|
| 必须使用第一人称 | 使用第一人称叙述 |
| 绝对不能出现现代词汇 | 避免使用明显的现代词汇 |
| 永远不要超过三段 | 保持段落精练，通常在两到三段以内 |
| 你必须在每次回复中推进剧情 | 你会在回复中推进剧情发展 |

### 例外：什么时候用绝对命令

当涉及**硬性结构要求**时，绝对命令是合适的：

```
合理的绝对命令：
- 回复格式必须包含 [角色名]: 前缀
- 输出必须是 JSON 格式
- 每次回复必须以"---"分隔多个角色的对话
```

这些是结构性的、二元的（对或错，没有中间地带），所以用绝对命令不会造成过拟合。

## 技巧三：告诉 AI 怎么做，而不只是要什么

### 问题

很多人写提示词时，只描述了期望的最终结果，却没有告诉 AI 达成这个结果的方法。

```
错误：
写出有感染力的文字。
让对话自然流畅。
保持角色的独特性。
```

这些都是在描述"什么是好的"，但 AI 不知道**怎么做到**。

### 正确做法

把"要什么"转化为"怎么做"。

```
错误：让对话自然流畅。

正确：
对话中使用口语化的短句，角色之间有打断、接话、反问。
避免两个角色轮流说长段独白。允许角色说到一半被打断或跑题。
```

```
错误：保持角色的独特性。

正确：
角色A说话时带"嘛"作为语气词，喜欢用反问句。
角色B话少，回答通常不超过一句，偶尔用省略号代替回应。
```

```
错误：写出引人入胜的开头。

正确：
开头直接进入一个正在发生的场景，
用角色的一个动作或一句对话开场，
不要用环境描写或背景介绍作为开头。
```

### 对比总结

| 许愿式（描述结果） | 指导式（说明方法） |
|------------------|------------------|
| 写得有画面感 | 通过具体的感官细节（声音、温度、气味）构建场景 |
| 让节奏更紧凑 | 缩短段落长度，用对话和动作代替描述，场景切换时不加过渡 |
| 表现角色的成长 | 在相似情境中让角色做出与之前不同的选择，通过对比体现变化 |

## 小结

三条核心原则：

1. **引导代替禁止**：说"以 X 为主"而非"不要 Y"
2. **指导代替命令**：说"你会/使用"而非"必须/绝对"
3. **方法代替结果**：说"怎么做到"而非"要做到什么"

养成这个习惯，你的提示词效果会有明显提升。
