# World Book

In the [World Book Editor](beilu:editor/worldbook), add entries: write keywords + fill in content. When keywords are mentioned in conversation, the content is automatically injected to the AI.

## Adding an Entry

1. Open the [World Book Editor](beilu:editor/worldbook)
2. Click to create a new entry
3. Fill in **keywords** (trigger condition, e.g., character name, place name)
4. Fill in **content** (information text to be injected for the AI to see)
5. Select a **trigger mode** (see three modes below)
6. Save

When matching keywords appear in conversation, the entry's content is automatically injected into the AI's context.

## Three Trigger Modes

| Mode | Name | Behavior | Suitable For |
|------|------|----------|--------------|
| **constant** | Always-on | Injected every turn; keywords are not checked | Information that is always needed (fundamental world settings) |
| **regex** | Keyword / regex matching | Triggered when matching keywords appear in conversation | Information that appears on demand (inject a description when a place name is mentioned) |
| **dynamic** | Dynamic check | Checks specific values in Memory Tables to decide whether to trigger | State-dependent information (inject behavioral guidance when a character is in a certain state) |

## Other Entry Settings

- **Injection position**: Before/after character description, at a specified depth in chat history, AN/EM native positions. The closer to the latest message, the more attention AI pays to it
- **enabled switch**: Global enable switch; the entry is completely inactive when disabled
- **boundCharName**: Character binding; only takes effect when the current character matches. You can prepare different World Book entries for different characters

## Special Markers

- `[GENERATE:*]` marker: Marked content is **visible only to the AI** and will not be shown to the user
- `[RENDER:*]` marker: Marked content is **visible only to the user** and will not be sent to the AI

This allows distinguishing between instructions for the AI and display content for the user within the same entry.

## World Book vs Memory System

| Dimension | World Book | Memory System |
|-----------|------------|---------------|
| Source | Pre-written by the user | Automatically generated by AI during conversation |
| Nature | Static settings (manually maintained) | Dynamic memory (automatically maintained) |
| Content | World settings, character profiles, rules | Events that occurred, information learned |
| Management | User edits in the interface | System automatically migrates and recalls |

Both ultimately enter the AI's context through the [Injection system](inj-overview.md), but their management methods and information sources are entirely different.
