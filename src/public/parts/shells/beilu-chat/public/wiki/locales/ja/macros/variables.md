# 変数マクロ

プリセットやキャラクターカード内で**データの保存と読み取り**を行い、状態追跡（好感度、HP、アイテム数など）に使用します。**ローカル変数**（現在のキャラクター/チャット専用）と**グローバル変数**（全キャラクター共有）に分かれ、操作は完全に対称です。

## 基本コンセプト

### 変数の保存場所

変数データは `macroMemory` に保存され、プリセットの `macro_variables` フィールドに永続化されます。これにより：

- 変数は会話をまたいで**永続的に保持**され、ページをリロードしても失われません
- ローカル変数は現在のキャラクター/チャットに紐づきます
- グローバル変数はすべてのキャラクター間で共有されます

### 変数の型

変数の値は**文字列**または**数値**です。数学演算（add/inc/dec）の際、システムは値を数値として処理しようとします。

## ローカル変数の操作

ローカル変数は現在のキャラクター/チャットの範囲内でのみ有効です。

| マクロ | 説明 | 例 |
|----|------|------|
| `{{setvar::名前::値}}` | 変数を設定 | `{{setvar::hp::100}}` |
| `{{getvar::名前}}` | 変数を読み取り | `{{getvar::hp}}` -> `100` |
| `{{addvar::名前::値}}` | 数値を加算 | `{{addvar::hp::-20}}` (hp が 80 になります) |
| `{{incvar::名前}}` | 1 を加算 | `{{incvar::turn}}` |
| `{{decvar::名前}}` | 1 を減算 | `{{decvar::hp}}` |

### 使用例

**初期状態の設定**（キャラクターカードの最初のメッセージ内）：
```
{{setvar::hp::100}}{{setvar::mp::50}}{{setvar::gold::0}}
冒険が始まりました！{{user}}の初期状態：HP {{getvar::hp}} / MP {{getvar::mp}}
```

**戦闘中のHP減少**：
```
{{addvar::hp::-15}}
{{char}}の攻撃が命中しました！{{user}}は 15 ダメージを受け、残り HP：{{getvar::hp}}
```

**ターンカウント**：
```
{{incvar::turn}}
=== 第 {{getvar::turn}} ターン ===
```

## グローバル変数の操作

グローバル変数はすべてのキャラクターとチャット間で共有されます。操作関数はローカル変数と完全に対称で、名前に `global` プレフィックスが付きます。

| マクロ | 説明 | 例 |
|----|------|------|
| `{{setglobalvar::名前::値}}` | グローバル変数を設定 | `{{setglobalvar::reputation::neutral}}` |
| `{{getglobalvar::名前}}` | グローバル変数を読み取り | `{{getglobalvar::reputation}}` |
| `{{addglobalvar::名前::値}}` | 数値を加算 | `{{addglobalvar::total_kills::1}}` |
| `{{incglobalvar::名前}}` | 1 を加算 | `{{incglobalvar::day_count}}` |
| `{{decglobalvar::名前}}` | 1 を減算 | `{{decglobalvar::energy}}` |

### 使用例

**キャラクター間で共有されるワールド状態**：
```
{{setglobalvar::world_time::morning}}
{{setglobalvar::weather::sunny}}
```

異なるキャラクターのプリセットからでも読み取れます：
```
現在は{{getglobalvar::world_time}}で、天気は{{getglobalvar::weather}}です。
```

**会話をまたぐ累積統計**：
```
{{incglobalvar::total_chats}}
これはあなたの第 {{getglobalvar::total_chats}} 回目の会話です。
```

## ローカル vs グローバル：選び方

| シーン | 推奨 | 理由 |
|------|------|------|
| キャラクターの好感度 | ローカル変数 | 各キャラクターで独立 |
| HP/MP/ステータス | ローカル変数 | 現在のキャラクターの冒険に属する |
| グローバルな時間/天気 | グローバル変数 | 全キャラクターで世界を共有 |
| プレイヤーの実績/統計 | グローバル変数 | キャラクターをまたいで累積 |
| 汎用的な設定プリファレンス | グローバル変数 | 特定のキャラクターに依存しない |

## 操作対照表

| 操作 | ローカル変数 | グローバル変数 |
|------|----------|----------|
| 設定 | `{{setvar::key::val}}` | `{{setglobalvar::key::val}}` |
| 読み取り | `{{getvar::key}}` | `{{getglobalvar::key}}` |
| 加算 | `{{addvar::key::N}}` | `{{addglobalvar::key::N}}` |
| インクリメント | `{{incvar::key}}` | `{{incglobalvar::key}}` |
| デクリメント | `{{decvar::key}}` | `{{decglobalvar::key}}` |

## 注意事項

- 存在しない変数を読み取ると空文字列が返され、エラーにはなりません
- `addvar` に負の数を渡すことで減算を実現できます：`{{addvar::hp::-10}}`
- `setvar` は既存の値を上書きします
- 変数名には英数字とアンダースコアの使用を推奨し、特殊文字は避けてください
- 変数の設定と読み取りはいずれもバックエンドのマクロ置換段階（AI に送信する前）に行われます
