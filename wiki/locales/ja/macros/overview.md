# マクロ

プリセットやキャラクターカードに `{{user}}` と書くと、AI の応答時に自動的にあなたのユーザー名に置き換わります。すべてのマクロは二重波括弧で囲み、実行時に実際の内容に置換されます。

## よく使うマクロ早見表

| 書き方 | 効果 | 例 |
|------|------|------|
| `{{user}}` | あなたのユーザー名 | `こんにちは、{{user}}！` → `こんにちは、太郎！` |
| `{{char}}` | 現在のキャラクター名 | `{{char}}は言った：` → `ベイルは言った：` |
| `{{time}}` | 現在の時刻 | `今は {{time}}` → `今は 14:30` |
| `{{date}}` | 現在の日付 | `今日は {{date}}` → `今日は 2026年7月14日` |
| `{{random::a,b,c}}` | ランダムに1つ選択 | `気分は{{random::嬉しい,穏やか,興奮}}` → `気分は穏やか` |
| `{{roll:1d6}}` | サイコロを振る | `{{roll:1d6}} が出た` → `4 が出た` |
| `{{setvar::hp::100}}` | 変数を設定 | ローカル変数 hp を 100 に設定します |
| `{{getvar::hp}}` | 変数を読み取り | ローカル変数 hp の値を読み取ります |
| `{{trim}}` | 空白を除去 | 余分な改行を整理します |

## 書き方のルール

**二重波括弧**でマクロ名を囲みます：`{{マクロ名}}`

パラメータ付きの場合は**ダブルコロン**で区切ります：`{{マクロ名::パラメータ1::パラメータ2}}`

SillyTavern の旧書式と互換性があります：`<user>` は `{{user}}` と同等、`<bot>` は `{{char}}` と同等です

## 使用できる場所

- [プリセット](beilu:editor/persona-edit)のシステムプロンプト、キャラクターカード説明、メッセージテンプレート
- キャラクターカードの各フィールド（説明、最初のメッセージ、シナリオなど）
- ユーザーメッセージテンプレートと AI 応答テンプレート
- 記憶システムのプロンプトテンプレート
- プラグインが注入するプロンプト

## マクロの置換タイミング

### バックエンド置換（主要）

ユーザーがメッセージを送信 → バックエンドがプロンプトを組み立て → マクロ置換 → AI に送信。ほとんどのマクロはここで置換が完了します。

### フロントエンド置換（表示時）

AI の応答がフロントエンドに到着した後、`{{char}}` と `{{user}}` を置換してキャラクター名を正しく表示します。その他のマクロは応答内では機能しません。

## 全マクロの分類

| 分類 | 説明 | 典型例 | 詳細 |
|------|------|----------|------|
| 基本マクロ | 名前、時刻、書式制御 | `{{user}}` `{{time}}` `{{trim}}` | [基本マクロ](beilu:wiki/macros/basic.md) |
| 高度なマクロ | ランダム、サイコロ、時刻計算 | `{{random::a,b}}` `{{roll:1d6}}` | [高度なマクロ](beilu:wiki/macros/advanced.md) |
| 変数マクロ | ローカル/グローバル変数の読み書き | `{{getvar::hp}}` `{{setvar::hp::100}}` | [変数マクロ](beilu:wiki/macros/variables.md) |
| 記憶システムマクロ | 記憶モジュール専用プレースホルダー | `{{tableData}}` `{{hotMemory}}` | [記憶システムマクロ](beilu:wiki/macros/memory.md) |
| IDE/コーディングマクロ | コードモード専用 | `{{sub_mode}}` `{{code_file:x}}` | [IDE/コーディングマクロ](beilu:wiki/macros/ide.md) |
| env カスタムマクロ | プラグイン/コアが環境経由で注入 | `{{workspace_root}}` `{{active_preset_name}}` | [env カスタム変数マクロ](beilu:wiki/macros/env.md) |

## 注意事項

- マクロ名は**大文字小文字を区別**します：`{{User}}` は `{{user}}` と異なります
- 認識されないマクロタグは**そのまま保持**され、エラーにはなりません
- マクロは**ネストして使用**できます：あるマクロの出力に別のマクロが含まれていれば、さらに置換されます
- AI の応答内容に書かれたマクロタグのうち、`{{char}}` と `{{user}}` のみフロントエンドで置換され、その他のマクロは応答内では機能しません
