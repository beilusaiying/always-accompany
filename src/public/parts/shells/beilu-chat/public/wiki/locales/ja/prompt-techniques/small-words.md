# 小さな言葉の大きな力

ひとつの的確な専門用語は、長い説明文よりもずっと効果的なことがあります。これは AI のトレーニングデータにおいて、専門用語が膨大な専門知識と結びついているからです——ひとつの言葉を使うだけで、AI の対応する知識ネットワーク全体を「起動」することができます。

## しくみ

AI の言語モデルでは、ひとつひとつの言葉は孤立しておらず、大量の関連概念とネットワークを形成しています。一般的な言葉の関連ネットワークは小さく、専門用語の関連ネットワークははるかに豊かです。

```
一般的な言葉：「感情」
  → AI が関連付けるもの：嬉しい、悲しい、怒る......（漠然としている）

専門用語：「プルチックの感情の輪モデル」
  → AI が関連付けるもの：8つの基本感情、感情の輪、
    感情の強度レベル、複合感情の組み合わせ方......（的確かつ豊か）
```

専門用語はひとつの鍵のようなもので、AI の知識ベースにある対応する扉を開くことができます。

## 実際の例

### ライティングの場面

| 長い説明（効果が普通） | 小さな言葉（効果がより良い） |
|-------------------|------------------|
| 「キャラクターの感情は複数の層を持つべきで、単純な喜びや悲しみではなく、複雑で複合した感情状態を表現するべきです」 | 「キャラクターの感情はプルチックの感情の輪モデルを参照し、複合感情を表現する」 |
| 「論述の際はまず大前提を提示し、次に小前提を提示し、最後に結論を導く」 | 「三段論法の構造を使う」 |
| 「キャラクターに専門的な方法で簡単な概念を説明させず、普通の人のように自然に会話させる」 | 「知識の呪い効果に注意し、キャラクターは日常的な視点で表現する」 |

### 開発者の場面

| 長い説明 | 小さな言葉 |
|---------|--------|
| 「コードの各関数は1つのことだけを行い、複数の機能をひとつの関数に詰め込まない」 | 「単一責任の原則に従う」 |
| 「エラー処理では起こりうるすべての問題を考慮し、エラー後もシステムが動き続けられるようにする」 | 「防御的プログラミング、優雅なデグラデーションを確保する」 |
| 「インターフェースを設計するとき、利用者が誤って使いにくいようにする」 | 「最小驚き原則に従う」 |

## 使い方のコツ

### 1. 正しい用語を選ぶ

適当に専門用語を投げるだけでは効果がありません。用語は AI のトレーニングデータで十分にカバーされているもの——つまり、学術界や業界で本当に広く使われている概念でなければなりません。

```
有効な用語（AI の知識ベースで十分カバーされている）：
- プルチックの感情の輪モデル（心理学）
- 三段論法（論理学）
- 知識の呪い（認知心理学）
- 英雄の旅（物語学）
- 氷山理論（ライティング技法）
- チェーホフの銃（演劇理論）

効果が疑わしい用語（マイナーすぎる、または新しすぎる）：
- 小さなコミュニティが作った造語
- 広く採用されていない新理論
```

### 2. 詰め込みすぎない

小さな言葉の価値は的確な起動にあります。詰め込むとシグナルが衝突してしまいます。

```
悪い例：
三段論法、ソクラテス式問答法、背理法、
ヘーゲルの弁証法を使ってキャラクターの対話ロジックを構成する。

良い例：
キャラクターの論述には三段論法の構造を使い、必要に応じて反問で展開を進める。
```

1〜2個の的確な用語で十分です。用語が多すぎると、AI はすべてを同時に満たそうとしてしまい、結果的にどれもうまくできなくなります。

### 3. 簡単な補足説明を付けても良い

ある用語が現在の文脈で AI に正確に理解されるか不安な場合、一言補足説明を加えることができます：

```
キャラクターの感情はプルチックの感情の輪モデルを参照する——同じ場面で
複数の異なる感情を同時に感じる場合があり、単一の感情反応ではない。
```

これにより用語の知識ネットワークを起動しつつ、意図する側面を限定することができます。

### 4. 具体的な指針と組み合わせる

小さな言葉は「知識を呼び出す」役割を持ち、具体的な指針は「知識を応用する」役割を持ちます。両方を組み合わせると最も効果的です。

```
小さな言葉のみ（方向は合っているが十分でない）：
氷山理論を使う。

小さな言葉 + 具体的な指針（的確）：
氷山理論を使う：キャラクターの本心は動作と細節で暗示し、
内心の独白で直接語らない。対話のサブテキストは表面的な意味よりも重要。
```

## よく使われる小さな言葉 早見表

| 分野 | 用語 | 起動される知識 |
|------|------|-----------|
| 感情描写 | プルチックの感情の輪モデル | 8つの基本感情・複合感情・強度レベル |
| 論理表現 | 三段論法 | 大前提 → 小前提 → 結論の論証構造 |
| キャラクター対話 | 知識の呪い | キャラクターは自分の認知を超えた方法では話さない |
| 物語構造 | 英雄の旅 | 日常→召命→試練→変容→帰還 |
| ライティング技法 | 氷山理論 | 表面に見えるのは一角、深い意味は暗示で伝える |
| ドラマの緊張感 | チェーホフの銃 | 登場する細節はすべて物語上の意味を持つ |
| サスペンスのリズム | 遅延満足 | 答えをすぐに明かさず、情報を段階的に解放する |
| コード設計 | 単一責任の原則 | ひとつのモジュールはひとつのことだけを行う |
| インターフェース設計 | 最小驚き原則 | 動作が利用者の直感的な期待に合っている |

## まとめ

- 的確な専門用語は AI の知識ネットワークを起動でき、長い説明文をはるかに上回る効果があります
- AI のトレーニングデータで十分にカバーされている用語を選びましょう
- 詰め込まず、1〜2個の的確なものを使いましょう
- 具体的な指針と組み合わせて使い、知識を起動しつつ方向を限定しましょう
