# Bot モード

AI キャラクターを複数の外部プラットフォーム（Discord、Telegram、LINE など）で自動運用し、メッセージに応答させます。

## 入り方

補助メニューから Bot 管理ビューに入ります。

## インターフェースレイアウト

### アクティビティバーボタン（3 個）

| ボタン | 名称 | 開くパネル |
|------|------|-----------|
| list | Bot リスト | すべての Bot インスタンスの設定と管理 |
| log | ログ | Bot 実行ログ |
| monitor | モニタリング | Bot の実行状態をリアルタイムで監視 |

## コア機能

### マルチプラットフォーム設定

Bot リストパネルの上部に 10 個のプラットフォーム Tab があり、クリックして対応するプラットフォームの設定エリアに切り替えます：

| プラットフォーム | 入力が必要な認証情報フィールド |
|------|-------------------|
| Discord | Bot Token、Application ID |
| Telegram | Bot Token |
| Slack | Bot Token、App Token、Signing Secret |
| LINE | Channel Access Token、Channel Secret |
| X (Twitter) | API Key、API Secret、Access Token、Access Secret、Bearer Token |
| Lark | App ID、App Secret |
| DingTalk | App Key、App Secret |
| WeCom | Corp ID、Agent ID、Secret |
| WeChat | App ID、App Secret |

各プラットフォームの認証情報を入力すれば、すぐにオンラインで稼働できます。

**操作ボタン**：
- 保存 —— 現在のプラットフォームの認証情報設定を保存します
- 起動 —— Bot を起動してメッセージの監視を開始します
- 停止 —— Bot の動作を停止します
- モニタリングを表示 —— monitor パネルにジャンプして実行状態を確認します

### C6 トリガールール

Bot が誰のメッセージに応答するかを設定します：

| オプション | 説明 |
|------|------|
| 全員 | 誰が送信したメッセージでも応答をトリガーします |
| メインユーザーのみ | メインユーザーのメッセージにのみ応答します |
| メインユーザー + ホワイトリスト | メインユーザーとホワイトリストに指定されたユーザーのメッセージに応答します |

### 権限レベル（L0 - L3）

| レベル | 説明 |
|------|------|
| L0 | 最低権限、基本的な対話のみ |
| L1 | 基本権限、一部の機能を使用できます |
| L2 | 上級権限、大半の機能を使用できます |
| L3 | 最高権限、すべての機能にアクセスできます |

ユーザー/ロールごとに異なる権限レベルを割り当てて、トリガーできる Bot 機能の範囲を制御できます。

### キャラクターカードの2層管理

Bot モードではキャラクターカードに2層構造を採用しています：

**外層 —— ウィンドウモード分類**：キャラクターカードを always-accompany のウィンドウモード別にグループ表示します：
- chat —— チャットモードのキャラクターカード
- code —— コードモードのキャラクターカード
- work —— ワークモードのキャラクターカード

**内層 —— キャラクターカードインスタンス**：各キャラクターカードインスタンスには以下が含まれます：
- 永続リンク —— Bot とキャラクターカードのバインド関係が永続化され、再起動後に自動復元されます
- 対話リスト —— そのキャラクターカードに属するすべての対話
- タスクリスト —— そのキャラクターカードに関連するタスク

異なるプラットフォーム/チャンネルに異なるキャラクターカードをバインドすることで、各キャラクターが独立した人格設定と対話コンテキストを維持します。

## バックエンドモード値

Bot 管理ビューのフロントエンド Tab は `bot` で、バックエンドモード値 `chat` に対応します（チャットモードのバックエンドロジックを共用しています）。

## 使用上のアドバイス

- **単一プラットフォームから始める**：まず1つのプラットフォームで設定して効果を検証してから、マルチプラットフォームに展開しましょう
- **権限制御**：本番環境ではトリガーホワイトリストと権限レベルを設定し、不正利用を防ぐことを推奨します
- **キャラクターの差別化**：プラットフォーム/シーンごとに異なるキャラクターカードを設定し、AI の振る舞いをそのプラットフォームのスタイルに合わせましょう
