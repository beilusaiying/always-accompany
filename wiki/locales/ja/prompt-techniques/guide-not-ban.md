# 誘導は禁止に優る

これはプロンプト作成において最も重要な原則の一つです：**AI に何をすべきか伝える方が、何をすべきでないか伝えるよりも効果的です。**

## なぜ禁止の指示は効果が低いのか

AI が「X をしないで」を処理する際、まず X が何かを理解し、それを避けようとします。しかし「避ける」は曖昧な行動です——避けた後に何をすればいいのか？ AI には分かりません。結果として、過度に回避する（関連する良い表現まで消える）か、別の形で同じ問題を起こすことになります。

一方「Y をする」は明確な行動方向であり、AI はその方向に直接進むことができます。

## テクニック一：禁止を誘導に変える

### 核心原則

「何をしないで」ではなく、「何を主とする」と伝えます。

### 対比例

| 禁止式（効果が低い） | 誘導式（効果が高い） |
|----------------|----------------|
| 比喩を使わないで | 白描を主とする |
| 長文を書かないで | 短文を使い、テンポを明快に保つ |
| ユーザーの言葉を繰り返さないで | 自分の言葉で応答し、対話を前に進める |
| 関係のない内容を出力しないで | 現在のシーンに集中し、各段落で一つのプロットポイントを進める |
| ネット用語を使わないで | 書き言葉ベースの口語的表現を使用する |
| OOC を禁止 | 常にキャラクターとして応答する |

### 実際の書き方

```
悪い例：
比喩と対句を使わないでください。長い心理描写を書かないでください。
キャラクター設定に合わないセリフを言わせないでください。

正しい例：
白描を主とし、対話でプロットを推進します。
心理活動は動作や微表情を通じて間接的に表現します。
キャラクターの言葉はそれぞれのバックグラウンドや話し方の癖に沿ったものにします。
```

正しい書き方は「何をしないか」だけでなく「何をするか」も述べている点に注目してください。AI は読み終えると、どの方向に進むべきか分かります。

## テクニック二：絶対的な命令を指導に変える

### 絶対的な命令とは

「必ず」「絶対にしてはならない」「決して～しない」「常に～する」——これらはすべて絶対的な命令です。

### なぜ控えるべきか

1. **過学習**：絶対的な命令は AI にそのルールの優先度を極端に高くさせ、他の側面のパフォーマンスを圧迫します。例えば「必ず毎文でキャラクターの性格を表現すること」は、AI が毎文で生硬に性格ラベルを挿入し、かえって不自然になります。
2. **読み疲れ**：プロンプト中に「必ず」「してはならない」が溢れると、AI の注意力が多すぎる厳格な制約に分散され、本当に重要なものを掴めなくなります。
3. **矛盾リスク**：絶対的な命令同士は矛盾しやすいです。「必ず簡潔に保つ」と「必ずシーンを詳細に描写する」を一緒に置くと、AI はどちらに従えばいいか分かりません。

### どう変えるか

「禁止」を「避ける/減らす」に、「必ず」を「あなたは～します/使用する」に変えます。

| 絶対的な命令（過学習しやすい） | 指導的な表現（より自然） |
|---------------------|-------------------|
| 必ず一人称を使用すること | 一人称で叙述します |
| 絶対に現代的な語彙を出さないこと | 明らかに現代的な語彙の使用を避けます |
| 決して3段落を超えないこと | 段落を簡潔に保ち、通常は2〜3段落以内とします |
| 毎回の返信で必ずプロットを進めること | あなたは返信の中でプロットを進めます |

### 例外：いつ絶対的な命令を使うか

**厳格な構造要件**に関わる場合、絶対的な命令は適切です：

```
合理的な絶対的命令：
- 返信フォーマットには必ず [キャラクター名]: プレフィックスを含めること
- 出力は必ず JSON フォーマットであること
- 毎回の返信で必ず "---" で複数キャラクターの対話を区切ること
```

これらは構造的で二元的な（正しいか間違いか、中間地帯がない）ものなので、絶対的な命令を使っても過学習は起きません。

## テクニック三：AI にやり方を伝える、結果だけでなく

### 問題

多くの人がプロンプトを書く際、期待する最終結果だけを描写し、その結果を達成する方法を AI に伝えていません。

```
悪い例：
感染力のある文章を書いてください。
対話を自然で流暢にしてください。
キャラクターの独自性を保ってください。
```

これらはすべて「何が良いか」を描写していますが、AI は**どうやって達成するか**分かりません。

### 正しいやり方

「何が欲しいか」を「どうやるか」に変換します。

```
悪い例：対話を自然で流暢にしてください。

正しい例：
対話では口語的な短文を使い、キャラクター間で割り込み、受け答え、反問があるようにします。
二人のキャラクターが交互に長い独白を述べるのは避けます。
途中で割り込まれたり話が脱線することを許容します。
```

```
悪い例：キャラクターの独自性を保ってください。

正しい例：
キャラクターAは話す際に「まあ」を語気として使い、反問文を好みます。
キャラクターBは言葉が少なく、返答は通常一文以内で、
時折省略号で返事を代替します。
```

```
悪い例：引き込まれる冒頭を書いてください。

正しい例：
冒頭は進行中のシーンに直接入り、
キャラクターの動作や一言のセリフで始め、
環境描写や背景紹介で始めないでください。
```

### 対比まとめ

| 願掛け式（結果の描写） | 指導式（方法の説明） |
|------------------|------------------|
| 臨場感のある文章を書いて | 具体的な感覚ディテール（音、温度、匂い）でシーンを構築する |
| テンポをもっと緊密に | 段落を短くし、対話と動作で描写を代替し、シーン転換時にトランジションを入れない |
| キャラクターの成長を表現して | 似た状況でキャラクターに以前と異なる選択をさせ、対比で変化を示す |

## まとめ

3 つの核心原則：

1. **誘導で禁止を代替する**：「Y をしないで」ではなく「X を主とする」と言う
2. **指導で命令を代替する**：「必ず/絶対に」ではなく「あなたは～します/使用する」と言う
3. **方法で結果を代替する**：「何を達成すべきか」ではなく「どうやって達成するか」を言う

この習慣を身につければ、プロンプトの効果が明確に向上します。
