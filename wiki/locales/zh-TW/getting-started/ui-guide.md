# 介面佈局

## 三欄結構

| 區域 | 內容 |
|------|------|
| 左欄 | 角色資訊 / 預設集選擇 / 世界書 / 模型參數（模式不同內容不同） |
| 中央 | 對話訊息流 |
| 右欄 | 執行階段開關 / 任務看板（可摺疊） |
| 頂部 | 模式選擇器（4 個主模式） |
| 底部 | 輸入框 |

左右欄可拖曳調寬，可摺疊隱藏。IDE/工作模式下佈局變為活動欄+側邊欄形式。

## 模式切換

頂部 4 個按鈕（Ctrl+1~4）切主模式。點「···」進輔助檢視（Bot 管理 / 遊戲陪伴 / 記憶管理 / ST 適配）。

## 常用操作

| 操作 | 方法 |
|------|------|
| 發訊息 | Enter |
| 換行不發送 | Shift + Enter |
| 重新產生 | 訊息下方按鈕 |
| 編輯訊息 | 點擊訊息內容 |
| 刪除訊息 | 右鍵 → 刪除 |
| 新建對話 | 擴充功能表 → 新建對話 |
| 切角色 | 左側欄點其他角色卡 |
