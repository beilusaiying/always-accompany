# 审批与权限

YonBan 的 AI 写操作都会进入统一权限与执行门控链。规则可以直接拒绝、要求审批或放行；进入审批队列只是其中一种结果。

## 权限等级

| 等级 | 名称 | 允许的操作 |
|------|------|-----------|
| L0 | 只读 | 仅 read_file、list_files、search 等读操作 |
| L1 | 读 | 读操作 + 诊断 + 导航 |
| L2 | 读写需审批 | 读 + 写操作（每次写操作需用户逐条审批） |
| L3 | 完整 + 命令 | 读写 + 命令执行（run_command / run_script） |
| L4 | 信任 | 所有操作自动放行，跳过审批（系统强制确认与敏感默认兜底仍然生效） |
| L5 | ⚠ 跳过审批 | 跳过审批队列，但不绕过更早的命令硬阻断、子模式权限、远程白名单和其他专用安全闸 |

在编程模式控制面板的权限等级下拉菜单中切换。可前往[安全中心](beilu:settings/security)查看全局安全策略。

### ⚠ 关于界面里的 L5「全部放行」

L5 是「跳过审批队列」，不是关闭全部安全链：

- **L4（信任）**：大部分操作自动放行，但底线还在——灰名单里勾了「L4 也问」的高危命令（如 shutdown、reg）仍会弹审批，敏感文件（.env 等）的默认保护仍然兜底。
- **L5（跳过审批）**：审批门会被跳过，但此前已经判定为禁止的命令、子模式硬权限、路径边界、`git push` 远程白名单与其他专用闸仍然有效。它不能把硬拒绝变成自动执行。

L5 会显著减少逐条确认，因此切换时仍需红色二次确认。**只建议在完全受信的本机、且你实时盯着 AI 操作时短暂使用**；用完请及时切回 L4 及以下。

> 当前界面仍把这一档标为「全部放行」。准确语义是：跳过审批队列，不是绕过此前已经生效的硬拒绝和专用安全检查。

## 审批流程

写操作从 AI 发出到实际执行，经过以下流程：

1. AI 发出写操作请求（write_file / run_command / git_commit 等）
2. 子模式硬权限、命令安全和用户规则先判断 deny / ask / allow
3. deny 直接拒绝；ask 才进入审批队列并在前端弹出提示；allow 继续进入统一执行闸
4. 用户对 ask 请求选择**批准**或**拒绝**
5. 通过全部闸门后执行并返回结果；任一环节拒绝都会把原因返回给 AI

L4 信任模式可以跳过部分审批（灰名单「L4 也问」项与系统强制确认除外）；L5 跳过审批队列，但不会跳过步骤 2 中先于审批发生的硬拒绝与专用安全检查。

## 五级安全闸

审批系统内部由五级安全闸串联，任一级拦截即阻止执行：

| 级别 | 名称 | 作用 |
|------|------|------|
| 1 | 命令闸 | 黑名单命令永久禁止（如 rm -rf /）；灰名单命令需审批（每条可设是否 L4 也确认）；能力白名单内命令按权限等级放行 |
| 2 | 规则集引擎 | 用户自定义规则：deny（拒绝）/ ask（需审批）/ allow（放行），按优先级匹配 |
| 3 | 审批门 | 系统强制审批（L2 写操作）/ 策略审批（规则集命中 ask）/ 信任跳过（L4） |
| 4 | 统一执行闸 | fail-closed 设计——闸异常时默认拒绝，不会漏放 |
| 5 | 审批指纹绑定 | 审批通过后为请求生成 sha256 指纹，执行时校验指纹一致——防止审批通过后请求被篡改 |

## 命令安全

命令执行（run_command / run_script）有额外的安全层：

| 名单 | 说明 |
|------|------|
| 黑名单 | 严重破坏类命令永久禁止执行，无论权限等级（如格式化磁盘、递归删除、擦盘/改引导）。每条可单独启停/删除，权限面板可增删 |
| 灰名单 | 需要显式审批的命令。每条带「L4 也问」开关：勾选=即使 L4 完全信任也弹审批（如 shutdown、reg）；不勾=最多限到 L3，L4 免审批（如 git rebase、npm uninstall） |
| 能力白名单 | 常用安全命令（如 ls、cat、git status），在 L3+ 自动放行 |

## 前端控制面板

在编程模式活动栏点击 control 按钮打开控制面板，集中管理以下设置：

| 控件 | 类型 | 说明 |
|------|------|------|
| 权限等级 | 档位徽章 / 下拉菜单 | L0 ~ L5，控制 AI 可执行的操作范围（切到 L5 需通过红色二次确认弹窗；逐条微调后会生成「自定义」档） |
| 自动保存 | 开关 | 开启后文件修改自动保存到磁盘 |
| 自动继续 | 开关 + 延迟设置 | AI 完成一步后自动继续下一步，可设置等待延迟 |
| 完成提示音 | 开关 | AI 完成任务时播放提示音 |
| 清理模式 | 下拉菜单 | 选择代码清理策略 |
| 手动清理 | 按钮 | 立即执行一次清理 |
