# 引導優於禁止

這是提示詞寫作中最重要的原則之一：**告訴 AI 該做什麼，比告訴它不該做什麼更有效。**

## 為什麼禁止性指令效果差

AI 處理「不要做 X」時，它首先要理解 X 是什麼，然後試圖避開。但「避開」是一個模糊的行為——避開之後做什麼？AI 並不知道。結果要麼是過度回避（連相關的好表現也一起消失），要麼是換一種方式犯同樣的問題。

而「做 Y」是一個明確的行為方向，AI 可以直接朝那個方向走。

## 技巧一：把禁止改成引導

### 核心原則

不說「不要做什麼」，而說「以什麼為主」。

### 對比範例

| 禁止式（效果差） | 引導式（效果好） |
|----------------|----------------|
| 不要使用比喻 | 以白描為主 |
| 不要寫長句 | 使用短句，保持節奏明快 |
| 不要重複使用者的話 | 用自己的話回應，推進對話 |
| 不要輸出無關內容 | 聚焦目前場景，每段推進一個情節點 |
| 不要使用網路用語 | 使用書面口語化表達 |
| 禁止出現 OOC | 始終以角色身份回應 |

### 實際寫法

```
錯誤：
不要使用比喻和排比。不要寫太長的心理描寫。
不要讓角色說出不符合人設的話。

正確：
以白描為主，對話推動情節。
心理活動透過動作和微表情間接表達。
角色語言貼合各自的身份背景和說話習慣。
```

注意看：正確寫法不僅說了「不要什麼」，還說了「要什麼」。AI 讀完就知道該往哪個方向走。

## 技巧二：絕對命令改為指導

### 什麼是絕對命令

「必須」「絕對不能」「永遠不要」「始終要」——這些都是絕對命令。

### 為什麼要少用

1. **過擬合**：絕對命令讓 AI 把這條規則的優先級拉到極高，擠壓其他方面的表現。比如「必須每句話都體現角色性格」會讓 AI 每句都生硬地塞入性格標籤，反而不自然。
2. **閱讀疲勞**：當提示詞裡滿是「必須」「不能」時，AI 的注意力被分散到太多硬性約束上，反而抓不住真正重要的東西。
3. **衝突風險**：絕對命令之間容易互相矛盾。「必須保持簡潔」和「必須詳細描寫場景」放在一起，AI 不知道該聽哪個。

### 怎麼改

把「禁止」改成「避免/減少」，把「必須」改成「你會/使用」。

| 絕對命令（容易過擬合） | 指導性表達（更自然） |
|---------------------|-------------------|
| 必須使用第一人稱 | 使用第一人稱敘述 |
| 絕對不能出現現代詞彙 | 避免使用明顯的現代詞彙 |
| 永遠不要超過三段 | 保持段落精練，通常在兩到三段以內 |
| 你必須在每次回覆中推進劇情 | 你會在回覆中推進劇情發展 |

### 例外：什麼時候用絕對命令

當涉及**硬性結構要求**時，絕對命令是合適的：

```
合理的絕對命令：
- 回覆格式必須包含 [角色名]: 前綴
- 輸出必須是 JSON 格式
- 每次回覆必須以「---」分隔多個角色的對話
```

這些是結構性的、二元的（對或錯，沒有中間地帶），所以用絕對命令不會造成過擬合。

## 技巧三：告訴 AI 怎麼做，而不只是要什麼

### 問題

很多人寫提示詞時，只描述了期望的最終結果，卻沒有告訴 AI 達成這個結果的方法。

```
錯誤：
寫出有感染力的文字。
讓對話自然流暢。
保持角色的獨特性。
```

這些都是在描述「什麼是好的」，但 AI 不知道**怎麼做到**。

### 正確做法

把「要什麼」轉化為「怎麼做」。

```
錯誤：讓對話自然流暢。

正確：
對話中使用口語化的短句，角色之間有打斷、接話、反問。
避免兩個角色輪流說長段獨白。允許角色說到一半被打斷或跑題。
```

```
錯誤：保持角色的獨特性。

正確：
角色A說話時帶「嘛」作為語氣詞，喜歡用反問句。
角色B話少，回答通常不超過一句，偶爾用省略號代替回應。
```

```
錯誤：寫出引人入勝的開頭。

正確：
開頭直接進入一個正在發生的場景，
用角色的一個動作或一句對話開場，
不要用環境描寫或背景介紹作為開頭。
```

### 對比總結

| 許願式（描述結果） | 指導式（說明方法） |
|------------------|------------------|
| 寫得有畫面感 | 透過具體的感官細節（聲音、溫度、氣味）建構場景 |
| 讓節奏更緊湊 | 縮短段落長度，用對話和動作代替描述，場景切換時不加過渡 |
| 表現角色的成長 | 在相似情境中讓角色做出與之前不同的選擇，透過對比體現變化 |

## 小結

三條核心原則：

1. **引導代替禁止**：說「以 X 為主」而非「不要 Y」
2. **指導代替命令**：說「你會/使用」而非「必須/絕對」
3. **方法代替結果**：說「怎麼做到」而非「要做到什麼」

養成這個習慣，你的提示詞效果會有明顯提升。
