# YonBan

在擴充市場裝 YonBan，AI 就能直接操作你的 IDE——讀寫檔案、執行命令、Git 操作等，30+ 工具全部透過審核系統管控。

## 安裝

在 VSCode 或 Cursor 擴充市場搜尋 **always-accompany**，安裝 YonBan 擴充套件。

## 連接到 always-accompany

| 步驟 | 操作 |
|------|------|
| 1 | 安裝擴充套件後，YonBan 自動連接 always-accompany 後端（預設連接埠 8931） |
| 2 | 擴充套件自動產生認證 Token，寫入 `~/.beilu/ide_ws_token`，後端讀取後完成 WebSocket 交握 |
| 3 | 連接建立後，前端進入[程式碼模式](beilu:mode/files)即可使用全部 IDE 工具 |

支援斷線自動重連。

## 前端連接面板

在程式碼模式活動列點擊 connections 按鈕開啟連接面板。

**連接卡片**：面板顯示 VSCode 和 Cursor 兩張卡片，每張包含：

- 狀態燈（綠 = 已連接 / 灰 = 斷開）
- 編輯器版本號
- WebSocket 位址
- 目前會話時長

**操作按鈕**：

- 重連 — 斷線後手動重連
- 斷開 — 主動斷開目前連接
- 連接 — 連接到新的編輯器執行個體
- 指南 — 查看擴充套件安裝與設定教學

**連接設定**：

| 設定 | 說明 |
|------|------|
| 自動重連 | 開關，斷線後自動嘗試重連 |
| 連接埠號 | 設定 WebSocket 連接埠（預設 8931） |
| 逾時時間 | 連接逾時閾值 |

**手動工具呼叫**：面板底部可手動向編輯器傳送工具呼叫，用於偵錯或測試——選擇目標 IDE、選擇工具、填寫參數 JSON、傳送並查看結果。
