# アイデンティティ設定テクニック

アイデンティティ設定はプロンプトの出発点です。AI は「自分は誰なのか」を知ってこそ、「どう話すか、どう行動するか」を決められます。良いアイデンティティ設定は、AI の全体的なパフォーマンスの方向性を正しく、スタイルを安定させることができます。

## 具体的な複合型アイデンティティ

### なぜ漠然としてはいけないのか

「あなたは作家です」——これは曖昧すぎます。AI は訓練データにおける「作家」の平均的なパフォーマンスを当てはめ、結果として特徴のない汎用的な出力になります。

アイデンティティ設定は**具体的**であるべきで、最良は**複合型**で、複数の修飾語を重ねて精確なプロフィールを作り上げます。

### 正しい例 vs 悪い例

```
悪い例：あなたは小説作家です。

正しい例：あなたは非伝統的な現代ライトノベル作家です。
```

この複合アイデンティティを分解すると：
- **非伝統的** —— AI に型通りにならないよう伝え、テンプレート化された「AI っぽい」文章を避けます
- **現代** —— 文化的コンテキストと時代背景を限定します
- **ライトノベル** —— ジャンルのスタイルを限定します。ライトノベルには独自のナラティブのテンポと対話密度があります

修飾語が一つ増えるごとに、AI の出力はさらに焦点が絞られます。

### その他の複合アイデンティティ例

| シーン | 漠然としたアイデンティティ | 複合アイデンティティ |
|------|---------|---------|
| ロールプレイ | あなたは AI アシスタントです | あなたは戦争を経験した退役軍医で、性格は沈着ですが時折ブラックユーモアを見せます |
| ライティング支援 | あなたは編集者です | あなたはウェブ小説のテンポ管理に特化した責任編集者で、冗長な段落を削るのが得意です |
| コードアシスタント | あなたはプログラマーです | あなたは関数型プログラミングを好み、コードの可読性を重視するバックエンドエンジニアです |

### 「非伝統的」の妙用

創作系シーンでは、「非伝統的」や類似の反テンプレート修飾語を加えることで、AI のテンプレート化傾向を効果的に減らせます。AI は大量の「伝統的な」書き方で訓練されており、修飾語がないと最も「安全な」スタイルをデフォルトで出力します——それは往々にして最も特徴のないものです。

```
効果の比較：

「あなたは恋愛小説作家です」
→ AI の傾向：華麗な辞藻、大量の心理描写、テンプレート化されたプロット

「あなたは非伝統的な現代恋愛作家です」
→ AI の傾向：より抑制された表現、より日常的な対話、より意外なプロット展開
```

## 機能のモジュール化：AIRP 構造

アイデンティティ設定が複雑になった場合、すべてを一段落に詰め込まないでください。モジュール化の方法で整理し、各モジュールが一つの側面を担当するようにします。

### AIRP 構造

検証済みのプロンプト構成構造で、ロールプレイや創作シーンに適しています：

| モジュール | 内容 | 役割 |
|------|------|------|
| **A - アイデンティティ (Actor)** | キャラクターのアイデンティティ定義 | AI に「自分は誰か」を伝える |
| **I - タスク (Instruction)** | 現在何をすべきか | AI に「何をすべきか」を伝える |
| **R - ユーザープロフィール (Reader)** | ユーザーの好みと特徴 | AI に「誰とコミュニケーションしているか」を伝える |
| **P - 回避事項 (Pitfalls)** | 回避すべきパフォーマンス | AI に「何をすべきでないか」を伝える |

ロールプレイシーンでは、さらにモジュールを拡張できます：

| 拡張モジュール | 内容 |
|---------|------|
| ロールプレイ指導 | キャラクターの行動パターン、話し方の癖 |
| ナラティブスタイル | 人称、時制、テンポ |
| ドラマスタイル | コンフリクト処理、感情表現方法 |
| ライティングスタイル | 語彙の好み、修辞手法 |
| POV（視点） | 誰の視点で叙述するか |

### モジュール化の例

```
悪い例：一段落に詰め込む
────────────────
あなたは非伝統的なライトノベル作家で、学園日常を書きます、
ユーザーは軽快なコメディスタイルが好みで、比喩を多用しないで、
対話は自然に、一人称で、テンポが間延びしないように、
キャラクターの口癖を入れて……
```

```
正しい例：モジュール化して整理
────────────────
## アイデンティティ
あなたは非伝統的な現代ライトノベル作家です。

## タスク
学園日常のシーンを中心に叙述を展開し、対話でプロットを推進します。

## ユーザープロフィール
軽快でユーモラスな基調を好み、キャラクター間の自然なインタラクションが好きです。

## 回避事項
長い心理独白や過度な修辞を避けます。

## ナラティブスタイル
一人称、現在時制、テンポは明快、シーン転換はきっぱりと。

## ライティングスタイル
白描と対話を主とし、語彙は日常的に、キャラクターの言葉はそれぞれの口癖を反映します。
```

モジュール化の利点：
- **メンテナンスしやすい**：効果が悪い部分があれば、対応するモジュールを修正するだけで、全体を書き直す必要がありません
- **階層が明確**：AI が各次元の要件をより正確に理解できます
- **再利用可能**：効果的なモジュールはキャラクターやシーンをまたいで再利用できます

## beilu での活用

beilu の[プリセットシステム](../presets/overview.md)は本来モジュール化されています——各プリセット条目が一つの独立したモジュールであり、自由に組み合わせられます。キャラクターカードやカスタムプリセットを書く際には、AIRP 構造を参考にして内容を整理し、異なる次元の指針を異なるプリセット条目に配置できます。キャラクターカードは[編集画面](beilu:editor/persona-edit)で編集できます。
