# 記憶系統巨集

beilu-memory 外掛在建構記憶提示詞時使用的專用佔位符。記憶注入階段自動替換為實際記憶資料。

> **注意**：記憶系統巨集由記憶系統在自己的鏈路裡替換（主對話注入鏈與記憶子 AI 鏈各有替換點），不依賴預設集巨集引擎；個別巨集（如 `{{lastUserMessage}}`）在預設集巨集引擎上下文中同樣可用。

## 記憶資料巨集

| 巨集 | 說明 | 內容來源 |
|----|------|----------|
| `{{tableData}}` | 目前模式的記憶表格資料 | 記憶表格（結構化記憶） |
| `{{hotMemory}}` | 熱層記憶 | forever/appointments/user_profile 等持久資料 |
| `{{chat_history}}` | 最近 N 條聊天記錄 | 聊天歷史 |
| `{{lastUserMessage}}` | 使用者最後一條訊息 | 目前對話 |
| `{{contextSummary}}` | 上下文壓縮摘要 | 記憶系統的自動摘要 |

### {{tableData}}

記憶表格是 always-accompany 記憶系統的核心資料結構之一。不同的記憶模式（如日常模式、冒險模式）有不同的表格欄位定義。`{{tableData}}` 會被替換為目前模式對應的表格內容。

### {{hotMemory}}

熱層記憶包含多種持久化的記憶資料：

- **forever**：永久記憶條目
- **appointments**：日程/約定
- **user_profile**：使用者畫像資訊
- 以及其他由記憶系統管理的熱層資料

### {{chat_history}}

注入最近的 N 條聊天訊息，讓記憶 AI 瞭解目前對話的上下文。具體條數由記憶系統設定決定。

### {{lastUserMessage}}

使用者在目前對話中傳送的最後一條訊息。記憶 AI 用它來判斷需要更新哪些記憶。

### {{contextSummary}}

當對話過長時，記憶系統會產生上下文壓縮摘要。這個巨集引用該摘要內容。

## 輔助資訊巨集

| 巨集 | 說明 |
|----|------|
| `{{presetList}}` | 記憶 AI 可選的預設集列表 |
| `{{current_date}}` | 目前日期（記憶系統內部使用） |

### {{presetList}}

列出可供記憶 AI 選擇的預設集清單。記憶系統在某些情境下需要知道有哪些預設集可用。

### {{current_date}}

提供目前日期資訊給記憶 AI，幫助它正確處理與時間相關的記憶（如日程、時間線事件）。

## 執行鏈路

記憶系統巨集的替換流程如下：

```
使用者發訊息
  -> beilu-memory 外掛啟動
  -> 載入記憶提示詞範本（含巨集佔位符）
  -> 從記憶儲存中提取資料
  -> 將 {{tableData}}、{{hotMemory}} 等替換為實際資料
  -> 組裝完成的記憶提示詞
  -> 注入到主提示詞中傳給 AI
```

這個過程與主巨集引擎是**並行獨立**的——記憶系統自行處理自己的巨集，處理完的結果作為一個整體被注入到主提示詞裡。

## 使用情境

記憶系統巨集主要在以下情境中使用：

| 情境 | 涉及巨集 | 說明 |
|------|--------|------|
| 記憶整理提示詞 | `{{tableData}}` `{{hotMemory}}` `{{chat_history}}` `{{lastUserMessage}}` | 告訴記憶 AI 目前有哪些記憶、對話說了什麼 |
| 上下文壓縮 | `{{contextSummary}}` | 為記憶 AI 提供長對話的摘要 |
| 記憶格式說明 | `{{presetList}}` `{{current_date}}` | 輔助資訊 |

## 注意事項

- 記憶系統巨集**不能**在普通預設集或角色卡中使用——它們只在 beilu-memory 的內部範本中生效
- 這些巨集由 beilu-memory 外掛**獨立替換**，不經過後端核心巨集引擎
- 如果需要在預設集中引用記憶資料，應透過記憶系統的注入機制，而不是直接寫記憶巨集
