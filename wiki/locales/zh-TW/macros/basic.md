# 基礎巨集

名稱插入、時間日期、格式控制。無需參數，寫上即用。

## 名稱巨集

插入使用者名稱或角色名。

| 巨集 | 別名 | 說明 | 範例輸出 |
|----|------|------|----------|
| `{{user}}` | `<user>` | 目前使用者的顯示名稱 | `小明` |
| `{{char}}` | `<bot>` `<char>` | 目前角色的顯示名稱 | `貝露` |

### 使用範例

在角色卡描述中：
```
{{char}}是一個溫柔的少女，她總是關心{{user}}的感受。
```
替換後：
```
貝露是一個溫柔的少女，她總是關心小明的感受。
```

在首條訊息中：
```
「{{user}}，你今天看起來很開心呢！」{{char}}微笑著說。
```
替換後：
```
「小明，你今天看起來很開心呢！」貝露微笑著說。
```

> **提示**：`{{char}}` 和 `{{user}}` 是唯一會在前端（AI 回覆顯示時）也被替換的巨集。其他巨集只在後端（傳送給 AI 前）替換。

## 時間日期巨集

插入目前時間和日期，讓 AI 感知「現在」。

| 巨集 | 說明 | 範例輸出 |
|----|------|----------|
| `{{time}}` | 目前時間（本地化短格式） | `14:30` |
| `{{date}}` | 目前日期（本地化長格式） | `2026年7月14日` |
| `{{weekday}}` | 目前星期幾 | `星期一` |
| `{{isotime}}` | 24 小時制時間 | `14:30` |
| `{{isodate}}` | ISO 格式日期 | `2026-07-14` |

### 使用範例

在系統提示中提供時間感知：
```
目前時間：{{time}}
目前日期：{{date}}（{{weekday}}）
```
替換後：
```
目前時間：14:30
目前日期：2026年7月14日（星期一）
```

## 訊息時間巨集

取得聊天中最後一條訊息的時間資訊。

| 巨集 | 說明 | 範例輸出 |
|----|------|----------|
| `{{lasttime}}` | 最後一條訊息的時間 | `14:25` |
| `{{lastdate}}` | 最後一條訊息的日期 | `2026年7月14日` |
| `{{idle_duration}}` | 距離上次訊息過了多久 | `5 minutes` |

### 使用範例

讓 AI 感知對話間隔：
```
距離上次對話已經過了 {{idle_duration}}。
```
替換後：
```
距離上次對話已經過了 2 hours。
```

## 格式控制巨集

控制提示詞文字格式，不產生可見內容。

| 巨集 | 說明 |
|----|------|
| `{{newline}}` | 插入一個換行符 |
| `{{trim}}` | 移除巨集所在位置前後的空行 |
| `{{noop}}` | 空操作，替換為空字串 |

### 使用範例

`{{trim}}` 常用於消除範本拼接時產生的多餘空行：

```
這是第一段。
{{trim}}
這是第二段。
```

如果沒有 `{{trim}}`，拼接時可能出現多餘空行。加上後，空行會被清理掉，輸出緊湊整潔。

`{{noop}}` 可以用來「佔位」——在範本裡標記一個位置，但不產生任何輸出。
