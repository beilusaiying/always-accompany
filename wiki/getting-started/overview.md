# 快速开始

欢迎。这一页带你从"刚打开界面一脸茫然"走到"和 AI 聊上第一句话"。整个过程只有三步：**配一个 AI 服务源 → 选个角色发消息 → 按需要切模式**。跟着做就行，每一步都会告诉你在哪里点、点完会看到什么。

在动手之前，先花 30 秒理解一件事：beilu 本身不产生 AI 回复——它更像一台性能很好的"车"，而 AI 服务源就是"油"。车是现成的，你只需要告诉它去哪家加油。这就是第一步要做的事。

## 第一步：添加 AI 服务源

**在哪里点**：点右上角的齿轮图标（或按 `Ctrl + ,`）打开设置，左侧图标栏里找到闪电图标「AI服务源」（[设置 → AI服务源](beilu:settings/api)），点「添加」。

**会看到什么**：一个表单，主要就填四样东西——

| 项目 | 填什么 |
|------|--------|
| 名称 | 随便取，给自己看的，用来区分不同的源 |
| API 类型 | 下拉选一个（这是最容易卡住的地方，下面细说） |
| 服务地址 | 选好类型后会自动填入默认地址，用中转站就换成中转站给你的地址 |
| API Key | 服务商给你的密钥，粘贴进来 |

然后点「获取模型列表」，在模型下拉里选一个，保存。

**「API 类型」怎么选**：这个下拉里既有「Google Gemini（原生）」「Ollama（本地原生）」这样的官方直连项，也有一排「Claude / DeepSeek / OpenAI 兼容……」的选项。简单记：

- 用**官方直连**的 Gemini 或本地 Ollama → 选带「原生」字样的那两项；
- 用**中转站 / 一键 API / 任何 OpenAI 格式的服务** → 选对应服务商的名字，找不到就选「OpenAI 兼容（自动检测）」。

背后其实是一套"两层选择"的设计（先选走哪条路、再选说哪种方言），第一次配不用深究，卡住了或想弄明白"为什么有两个 Gemini"，去看 [配置 AI 服务源](install.md)，那页用比喻讲透了。

配好后，发条消息试试就知道通没通（怎么发看第二步）。没反应的话，[后台监控](beilu:settings/monitor) 里能看到具体错误。

## 第二步：选角色，说第一句话

**在哪里点**：左侧栏点一张角色卡（没有就点角色列表上方的「+」创建一个，填个名字就够）。然后在底部输入框打字。

**注意：发送是 `Ctrl + Enter`，不是 Enter。** 直接按 Enter 是换行——这是为了让你安心写长消息不怕手滑发出去。第一次用几乎人人都会在这里愣一下，不是你的问题。

**会看到什么**：你的消息出现在对话流里，AI 的回复会一个字一个字地流出来。聊上了，恭喜。

## 第三步：按需求切模式

**在哪里点**：顶部中间有个显示当前模式的按钮（默认写着「AIRP」），点它会弹出模式选择面板。

| 模式 | 快捷键 | 干什么用 |
|------|--------|---------|
| 全智能 | Ctrl+1 / Alt+1 | 你说需求，AI 自动判断该用哪个模式干活 |
| AIRP | Ctrl+2 / Alt+2 | 角色对话、创意写作（默认就在这里） |
| IDE | Ctrl+3 / Alt+3 | AI 写代码 + 操作本地文件 |
| 工作 | Ctrl+4 / Alt+4 | 自动化任务、委派、定时执行 |

在浏览器里用 **Alt+数字**（Chrome 会把 Ctrl+数字抢去切浏览器标签页）；桌面客户端里 Ctrl 和 Alt 都行。

模式按钮旁边还有个「···」，里面是辅助视图（记忆 / Bot / 陪伴 / ST适配 / 额外插件）——打开它们不会打断你当前的对话。详见 [模式系统](beilu:wiki/modes/overview.md) 和 [界面布局](ui-guide.md)。

## 有些东西不用你配，它已经在跑了

这一节是预期管理——先知道哪些是"开箱即用"，哪些是"要自己开"，能省掉很多"咦怎么没反应"的困惑。

**联网搜索：默认就能用。** 不用填任何 key、不用装任何东西，AI 觉得需要查资料时会自己去搜（默认是多引擎并发，自动挑结果）。只有一种情况需要你动手：你的网络环境需要走代理才能访问搜索引擎——去联网设置面板（≡ 菜单或右栏的联网图标）把代理地址填进 proxy_url 就行。

**记忆：已经有两个"管家"在自动上班。** beilu 的记忆系统里有一排编号 P1~P8 的记忆 AI，但**默认真正自动运行的只有两个**：P1（每轮对话帮 AI 回忆相关的事）和 P2（对话攒多了自动总结归档）。P3~P8（日总结、月归档、格式修复、压缩等）默认是**关闭**的——所以如果你发现"每日总结从来没出现过"，那不是坏了，是还没开。想体验它们，去「···」→ 记忆 → P系列引擎面板手动开启。详见 [记忆系统](beilu:wiki/memory/overview.md)。

**记忆是跟着角色走的，不是跟着对话走的。** 同一张角色卡，你开十个对话，记忆是同一份——换个对话窗口，AI 依然记得你们之前的事。想要"完全陌生重新开始"，得换一张新的角色卡，而不是新建对话。

## 常见坑 FAQ

**问：按 Enter 怎么发不出去？**
答：发送是 `Ctrl + Enter`，Enter 是换行。

**问：发了消息 AI 不回复？**
答：九成是服务源的问题。去 [后台监控](beilu:settings/monitor) 看错误日志——Key 错了、地址填错了、模型名不对，都会在那里写明白。

**问：为什么换了个对话，AI 还记得之前的事？**
答：这是特性不是 bug。记忆按角色卡共享（见上一节）。

**问：说好的自动日总结/月总结呢？**
答：P3~P8 默认关闭，去记忆管理的 P系列面板手动开。

**问：顶部怎么找不到"四个模式按钮"？**
答：现在是一个下拉式的模式选择器（显示当前模式名的那个按钮），点开就能看到四个模式。
