# 正規表現拡張 (beilu-regex)

beilu-regex は正規表現スクリプトエンジンであり、AI の返信がユーザーに届く前後でテキストのマッチングと置換を行います。SillyTavern の正規表現スクリプト形式と互換性があり、ST コミュニティの正規表現スクリプトをインポートできます。

## 動作原理

beilu-regex はメッセージパイプラインの 2 つのフェーズで動作します：

### TweakPrompt フェーズ（送信前）

TweakPrompt の dl=0 ラウンド（最終ラウンド）で、beilu-regex は AI に送信されるメッセージに対して正規表現処理を行えます。

### ReplyHandler フェーズ（返信後）

AI の返信到着後、beilu-regex が返信テキストに対して正規表現ルールを実行し、マッチング、置換、フィルタリングなどの操作を行います。

## ルール構造

各正規表現ルールには以下が含まれます：

| フィールド | 説明 |
|------|------|
| 名称 | ルールの表示名 |
| マッチパターン | 正規表現（標準的な正規表現構文をサポート） |
| 置換テキスト | マッチ成功時に置き換える内容 |
| 適用範囲 | AI 返信 / ユーザー入力 / 両方に適用 |
| 有効状態 | このルールが有効かどうか |
| 適用プリセット | ルールがどのプリセットにバインドされているか |

## ルール管理

### CRUD 操作

SetData インターフェースの異なる `_action` 値でルールの CRUD 操作を行います：

- ルールの作成
- ルールの編集
- ルールの削除
- ルールの有効化/無効化
- ルール順序の調整

### SillyTavern からのインポート

beilu-regex は `importFromSTFormat` 関数を提供しており、SillyTavern 形式の正規表現スクリプトを直接インポートできます。インポート時にフィールド形式が自動変換されます。

キャラクターカードのインポート時に正規表現スクリプトが含まれている場合も、自動的にインポートされて beilu-regex に登録されます。

## 正規表現防護（ReDoS 防護）

beilu-regex には regexGuard セキュリティメカニズムが組み込まれており、悪意のあるまたは意図しない正規表現による ReDoS（正規表現サービス拒否）攻撃を防止します：

- 壊滅的なバックトラッキングパターンの検出
- 実行タイムアウト保護
- セキュリティスイッチ `regexGuard.enabled` は owner 権限で保護

## プリセットバインド

正規表現ルールは特定のプリセットにバインドできます。プリセット切替時に、現在のプリセットに関連付けられたルールのみが有効になります。これにより、異なるキャラクター/シーンで異なる正規表現処理ルールを使用できます。

プリセット切替時に、beilu-preset が `_resyncPresetRegex` を呼び出して正規表現ルールの有効状態を同期します。

## 典型的な用途

| 用途 | 説明 |
|------|------|
| フォーマットクリーンアップ | AI 返信中の余分な空行、特殊マーカーを除去 |
| コンテンツフィルタリング | 不要な返信フラグメントをフィルタリング |
| タグ変換 | AI のカスタムタグを HTML やその他の形式に変換 |
| キャラクター名置換 | 表示前にキャラクター名のバリエーション表記を置換 |
| 思考チェーン非表示 | AI 返信中の推論プロセスタグを非表示 |

## データ保存

ルールデータはプラグインディレクトリの `config_data.json` に保存されます（データはコードとともに移行されず、元の場所に残ります）。
