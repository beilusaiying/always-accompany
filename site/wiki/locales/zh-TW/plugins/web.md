# 聯網搜尋 (beilu-web)

beilu-web 讓 AI 能夠搜尋網際網路並瀏覽網頁。當 AI 需要取得即時資訊、查找資料或驗證事實時，它可以透過 `<search>` 和 `<browse>` 標籤發起聯網請求。

## 搜尋功能

### AI 發起搜尋

AI 在回覆中使用 `<search>` 標籤發起搜尋請求。beilu-web 解析標籤，執行搜尋，並將結果注入到下一輪對話中。

### 搜尋結果

搜尋結果包含三個欄位：

| 欄位 | 說明 |
|------|------|
| title | 網頁標題 |
| url | 網頁地址 |
| snippet | 內容摘要 |

AI 收到搜尋結果後，可以選擇直接回答（如果摘要資訊足夠），或者透過 `<browse>` 標籤存取具體網頁取得更詳細的內容。

### 手動搜尋

在 beilu-web 的設定面板中，你也可以手動輸入搜尋詞進行搜尋，查看搜尋結果。

## 網頁瀏覽

AI 使用 `<browse>` 標籤存取指定 URL 的網頁內容。beilu-web 會抓取網頁正文並回傳給 AI。

### 爬取能力探測

beilu-web 啟動時會自動探測目前環境的網頁爬取能力：

- 如果安裝了 Playwright 瀏覽器，可以渲染 JavaScript 動態頁面
- 如果沒有安裝，退回到簡單的 HTTP 抓取（可能無法取得 SPA 頁面內容）

可以透過 `ensureBrowsers` 安裝 Playwright 瀏覽器，以支援動態（JavaScript 渲染）頁面的爬取。

## 安全機制

聯網請求透過 `safeFetch` 安全抓取函式發送，內建了：

- 逾時保護
- 回應大小限制
- 惡意 URL 過濾

## 使用情境

| 情境 | 說明 |
|------|------|
| 查詢即時資訊 | 天氣、新聞、匯率等需要最新資料的問題 |
| 技術文件查閱 | AI 查閱官方文件來回答技術問題 |
| 事實核查 | 驗證 AI 不確定的資訊 |
| 資料收集 | 匯總多個來源的資訊 |

## 設定

在 beilu-web 的設定面板中可以調整搜尋引擎和相關設定。聯網功能需要網路連線才能正常工作。

## 與記憶系統的關係

beilu-web 的聯網搜尋也被[記憶系統](../memory/overview.md)的 P8 預設集調用。當 AI 在對話過程中判斷需要外部資訊時，P8 管線會觸發聯網搜尋，搜尋結果自動整合到對話上下文中。
