# 遊戲陪伴模式 (Companion)

設定桌寵和 Live2D 角色。AI 角色以桌面寵物形式陪伴，透過 Live2D 模型展示動態表情和動作，支援螢幕感知和 AI 自主發言。

## 進入方式

透過輔助功能表進入 Companion 檢視。

## 介面佈局

Companion 檢視以 8 個段落導航組織內容，點擊導航標籤可跳轉到對應段落：

| 段落 | 內容概述 |
|------|---------|
| 啟動形象 | 角色卡、對話檔案、截圖頻率等啟動綁定 |
| Live2D | Live2D 模型選擇、縮放、位置、待機動作 |
| 圖片包 | 靜態圖片包管理、表情鍵、多圖上傳 |
| 互動觸碰 | 熱區設定、部件點選、命中檢測 |
| 螢幕感知 | 自動截圖、目標視窗、畫質設定 |
| 安全 | 安全相關設定 |
| 陪伴訊息 | 對話氣泡樣式、停留時間、遊戲穿透 |
| 教學 | 使用教學與說明 |

## 核心功能

### 啟動綁定

設定桌寵啟動時使用的核心參數：

| 控制項 | 說明 |
|------|------|
| 角色卡下拉 | 選擇桌寵使用的角色卡 |
| 對話檔案 | 綁定對話存檔 |
| 對話模式 | 選擇對話互動方式 |
| 截圖頻率 | 自動截圖的觸發間隔 |
| 輪詢間隔 | AI 主動檢查狀態的間隔 |
| 頻率自適應 | 根據使用者活躍度自動調整輪詢頻率 |

### 桌寵形象

控制桌寵的顯示方式和外觀：

| 控制項 | 說明 |
|------|------|
| 啟用開關 | 開啟/關閉桌寵顯示 |
| 形象模式 | 選擇 Live2D 或圖片包 |
| 模型下拉 | 選擇使用的模型/圖片包 |
| 位置 | 桌寵停靠位置（左上/右上/左下/右下） |
| 待機表情 | 閒置時的預設表情 |
| 表情標籤名 | 表情與 AI 輸出的標籤映射 |
| 動作標籤名 | 動作與 AI 輸出的標籤映射 |

### Live2D

Live2D 模型的詳細調整：

- **模型選擇** —— 在已安裝的 Live2D 模型間切換
- **縮放** —— 調整模型大小
- **位置** —— 調整模型在螢幕上的位置
- **待機動作** —— 設定閒置時循環播放的動作
- **儲存微調** —— 儲存目前調整的參數
- **拖曳定位** —— 直接拖曳模型到目標位置
- **逐參數除錯** —— 逐一調整模型的各項參數

### 圖片包

使用靜態圖片作為桌寵形象（無需 Live2D 模型）：

- **包選擇** —— 選擇已有的圖片包
- **新建** —— 建立新的圖片包
- **預設表情** —— 設定未匹配時顯示的預設圖片
- **縮放** —— 調整圖片顯示大小
- **表情鍵管理** —— 為不同表情名稱綁定對應圖片
- **多圖上傳** —— 批次上傳表情圖片

### 互動觸碰

設定使用者點擊桌寵不同部位時的互動反應：

- **熱區列表** —— 檢視和管理已設定的所有觸碰熱區
- **點選部件** —— 在模型上點擊選擇要設定的部件
- **畫熱區** —— 在模型上手動繪製互動區域
- **放大編輯器** —— 放大檢視以便精細調整熱區位置
- **命中檢測頻率** —— 設定檢測使用者點擊的頻率

### 陪伴訊息（對話框）

自訂桌寵對話氣泡的外觀和行為：

| 控制項 | 說明 |
|------|------|
| 氣泡預覽 | 即時預覽氣泡效果 |
| 透明度 | 氣泡背景透明度 |
| 停留時間 | 訊息顯示後多久自動消失 |
| 圓角 | 氣泡圓角大小 |
| 底色 | 氣泡背景顏色 |
| 文字色 | 訊息文字顏色 |
| 描邊色 | 氣泡邊框顏色 |
| 名字標籤 | 是否顯示角色名稱標籤 |
| 遊戲穿透 | 開啟後滑鼠可穿透氣泡點擊遊戲畫面 |
| 橫幅 | 橫幅式訊息顯示 |
| 聲音 | 訊息到達時的提示音 |

### 螢幕感知

讓 AI 能夠「看到」使用者的螢幕內容：

| 控制項 | 說明 |
|------|------|
| 自動截圖 | 開啟/關閉自動截圖 |
| 頻率 | 截圖間隔時間 |
| 解析度 | 截圖解析度 |
| 目標視窗 | 指定截取哪個視窗（全螢幕或特定應用程式） |
| 畫質 | 截圖壓縮畫質 |

### AI 自主

設定 AI 主動發起對話和行為的能力：

- **後端驅動開關列表** —— 逐項啟用或停用各類自主行為
- **Dwell 間隔** —— 設定 AI 主動發言的最小等待間隔

開啟後 AI 可以在閒置時主動發起對話，根據螢幕感知內容和情境自主選擇合適的動作和表情。

## 後端模式值

Companion 檢視的前端 Tab 為 `companion`，不映射後端模式值。這意味著進入 Companion 檢視時，後端的模式狀態保持不變，僅切換前端介面。

## 使用建議

- **選擇形象**：先決定使用 Live2D 還是圖片包，再匯入對應資源
- **設定觸碰**：為模型的不同部位設定熱區，讓互動更自然
- **調整氣泡**：根據遊戲/桌面的背景色調整氣泡透明度和配色，確保可讀性
- **螢幕感知**：開啟後 AI 能理解你正在做什麼，但會消耗更多 API 呼叫
- **AI 自主**：開啟 AI 自主設定後，桌寵會更生動，但也會消耗更多 API 呼叫
