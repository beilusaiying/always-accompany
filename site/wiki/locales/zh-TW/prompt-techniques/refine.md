# 精簡與迭代

提示詞不是越長越好，也不是寫一次就完。精簡讓 AI 抓住重點，迭代讓提示詞越來越好。

## 減少無用提示詞

### 三種常見的「無用」

**1. 中英雙語標題**

```
錯誤：
## Writing Style / 寫作風格
你的寫作以白描為主......

## Character Voice / 角色語言
角色對話要自然......
```

中英雙語標題不會讓 AI 理解得更好，只會浪費 token 和分散注意力。AI 完全能理解純中文標題。

```
正確：
## 寫作風格
你的寫作以白描為主......

## 角色語言
角色對話要自然......
```

**2. 內容單一化（同一個意思反覆說）**

```
錯誤：
對話要自然。角色之間的交流要像真實對話一樣。
避免生硬的台詞，讓角色的語言貼近日常。
每個角色的說話方式都應該像真人一樣自然。
```

這四句話說的是同一件事。AI 不會因為你說了四遍就更重視，反而會被重複內容稀釋其他要點的權重。

```
正確：
角色對話使用口語化短句，允許打斷、接話和跑題。
```

一句話就夠了，而且比四句話更清晰。

**3. 過度直接範例**

```
錯誤：
比如角色A會說「今天天氣真好啊」，角色B會回答「是啊，好想出去玩」，
然後角色A說「那我們去公園吧」，角色B說「好啊好啊」......
（長達十幾輪的範例對話）
```

過多的直接範例會導致 AI **過擬合**——它不是學到了「怎麼寫對話」，而是記住了「就該這樣寫對話」，輸出變得像在複述你的範例。

少量、精選的範例才有效。（詳見「少樣本提示」章節。）

## 精簡但避免許願

### 什麼是許願

許願就是把「期望的最終效果」當成了提示詞指引。

```
這是許願：
寫出引人入勝的故事。
讓讀者沉浸其中。
創造令人難忘的角色。
```

這些話描述的是「好小說」的特徵，但 AI 不知道**怎麼做到**。就像跟一個人說「把飯做好吃」——他需要的是菜譜，不是「做好吃」這三個字。

### 精簡 ≠ 許願

精簡是去掉廢話，留下有效指引。許願是去掉了方法，只留下了願望。

| 許願（無效） | 精簡的有效指引 |
|------------|--------------|
| 寫出有畫面感的場景 | 用具體感官細節建構場景：溫度、聲音、氣味 |
| 讓對話真實自然 | 對話用口語短句，允許打斷和跑題 |
| 創造有深度的角色 | 角色在兩難選擇中展現價值觀衝突 |
| 保持文章節奏緊湊 | 段落不超過三行，場景切換不加過渡 |

### 精簡檢查法

寫完提示詞後，逐條檢查：

1. **這條能不能指導 AI 的具體行為？** —— 能，保留；不能，改寫或刪除
2. **去掉這條，AI 的表現會變差嗎？** —— 會，保留；不會，刪除
3. **這條和其他條重複了嗎？** —— 重複就合併成一條

## 提示詞迭代

好提示詞不是寫出來的，是改出來的。

### A/B 測試

同一個情境，用兩版提示詞分別讓 AI 產生，對比效果。

```
版本 A：
以白描為主，避免比喻。

版本 B：
以白描為主，減少比喻的使用頻率。

同一輸入 → 對比兩個版本的輸出 → 選效果更好的
```

改動一次只改一處，這樣才能判斷是哪個改動帶來了效果變化。如果同時改了三處，效果變好了也不知道是哪處起了作用。

### 拆解問題

AI 表現不好時，不要籠統地說「效果差」。把問題拆解成具體的方面：

```
籠統：「AI 寫的對話不好」

拆解：
- 對話太長？ → 加一條「角色每次說話不超過兩句」
- 對話太書面？ → 加一條「使用口語化表達」
- 角色分不清？ → 給每個角色加具體的說話特徵
- 對話沒推進？ → 加一條「每輪對話推進一個資訊點」
```

拆解之後，每個問題都有針對性的解法，改起來效率高得多。

### 分析失敗案例

當 AI 輸出了一段不好的內容，不要只是覺得「不好」然後重新產生。去分析**為什麼不好**：

1. **看 AI 到底寫了什麼** —— 具體哪裡不符合你的要求
2. **對照提示詞** —— 你的提示詞有沒有覆蓋到這個方面。沒覆蓋就加上，覆蓋了就改寫法
3. **看 CoT**（如果有）—— AI 在分析階段是怎麼理解你的要求的，有沒有理解偏差

### 迭代循環

```
寫提示詞
    ↓
測試（多次產生，看整體表現）
    ↓
發現問題（拆解成具體方面）
    ↓
分析原因（提示詞沒覆蓋？覆蓋了但寫法不對？）
    ↓
修改提示詞（一次改一處）
    ↓
再次測試
    ↓
（循環直到滿意）
```

## 小結

- **去掉無用內容**：重複的、雙語的、過多的範例，都是雜訊
- **精簡不等於許願**：保留能指導具體行為的指引，刪掉只描述結果的願望
- **迭代才能變好**：A/B 測試、拆解問題、分析失敗，是提升提示詞的正路
