# 联网搜索 (beilu-web)

beilu-web 让 AI 能够搜索互联网并浏览网页——查实时信息、翻文档、核对事实。

好消息是：**默认配置就能用**。开关打开后，系统默认用"多平台并发"模式同时向多个搜索引擎发请求，取最好的结果，你不需要研究该选哪个引擎。

## 怎么开

联网设置面板有两个入口：≡ 菜单里的"联网搜索"，或右栏的联网图标。

基础区就几个开关（详见下方"四个开关"）。把"联网搜索"总闸打开，就完成了——无需填任何 key，默认引擎组合免费可用。

## 四个开关分别管什么

面板上的开关是**并联关系**，各管一条独立链路——不是多选一。想彻底断网需要关掉总闸，只关其中一个达不到"AI 完全不联网"的效果：

| 开关 | 控制的链路 |
|------|-----------|
| **联网搜索**（总闸） | 一切联网能力的总开关 |
| **直接搜索** `<search>` | AI 在回复里直接发起搜索的能力 |
| **P8 搜索**（主动帮搜） | 记忆系统的联网子 AI：检索 AI 判断"这轮需要外部信息"时，自动触发 P8 去搜索、筛选、注入结果。默认开 |
| **自动浏览** `<browse>` | AI 直接打开某个网址读取网页正文的能力 |

另有一个**结果注入**开关（"仅本轮 / 留在对话"）：

- **默认（留在对话）**：搜索结果作为系统消息写入对话历史，持久可见——你可以在对话尾部回看 AI 搜到了什么，AI 下轮也天然记得。
- **勾选"仅本轮"**：结果只在当轮生成时对 AI 可见，不写入历史。

## 需要代理时怎么配

如果你的网络需要代理才能访问搜索引擎：在面板的代理输入框填代理地址，格式如 `http://127.0.0.1:7890`（Clash 默认端口示例）。

- 用 TUN/全局代理模式的用户**不需要**填这里——流量已经全局走代理了。
- 只在"浏览器能上网但程序请求不通"的场景填。

## 引擎怎么选（可以不选）

默认是 **multi 多平台并发**，不用管。想固定用某个引擎（比如排查问题）时，在高级区下拉选择：

| 引擎 | 类型 | 需要什么 |
|------|------|---------|
| ddgs | Python 桥（抗风控最强） | 本机 Python + `pip install ddgs`（缺了会自动后台安装，首次搜索可能没结果，第二次就好了）。默认并发池成员 |
| sogou | 直接抓取 | 无需配置。默认并发池成员 |
| bing / edge | 直接抓取 | 无需配置 |
| google | 爬虫 | 无需配置（部分网络环境会被人机验证拦截） |
| browser | 真浏览器拟人流 | 首次需下载 Chromium 内核（约 150MB，自动装到项目目录）。结果质量高但慢（数秒到数十秒），所以不在默认池里，需要时手动加入 |
| tavily | API 服务 | 需要 API key（不在下拉里，配置文件配置） |
| searxng | 自建实例 | 需要自建 SearXNG 地址（不在下拉里） |

高级区还能配**域名黑白名单**（过滤搜索结果里不想要的站点）和噪音词表。

> 注意一个边界：域名黑白名单只过滤**搜索结果**。AI 用 `<browse>` 直接访问某个网址不经过这份名单（仍有内网防护兜底）。

## AI 是怎么触发搜索的

有两条并存的通道，都最终走同一套搜索管线：

1. **记忆域通道（主力）**：检索 AI 在后台判断"这个问题需要最新信息"，触发 P8 联网子 AI。P8 会自己决定搜什么关键词、结果够不够、要不要换词再搜——多轮自主搜索后把筛选过的结果注入对话。这就是"你没让它搜它自己去搜了"的来源，对应"P8 搜索"开关。
2. **插件直连通道**：AI 在回复里直接写 `<search>关键词</search>` 或 `<browse>网址</browse>` 标签，本插件解析执行，结果下一轮给 AI。对应"直接搜索"和"自动浏览"两个开关。

搜索结果经过一整套自动处理：广告/噪音过滤 → 去重排序 → 域名多样性控制 → 正文校验（抓取排名靠前的页面正文核对相关度）→ 安全中性化，最后才给 AI。你无需干预。

## 手动搜索与诊断

面板里可以手动输入关键词搜索，直接看结果——用来验证联网是否正常。

搜索不好使时，用面板的**诊断**功能：它会分五步检查配置、网络可达性、测试搜索、浏览器内核等，并告诉你卡在哪一步。

## 使用场景

| 场景 | 说明 |
|------|------|
| 查询实时信息 | 天气、新闻、汇率等需要最新数据的问题 |
| 技术文档查阅 | AI 查阅官方文档来回答技术问题 |
| 事实核查 | 验证 AI 不确定的信息 |
| 资料收集 | 汇总多个来源的信息 |

## 与记忆系统的关系

P8 是[记忆系统](../memory/overview.md)的八个子 AI 之一，专职联网。它的触发判断来自检索 AI（P1），搜索执行则与本插件共用同一套底层管线——所以联网设置面板的引擎/代理/黑白名单配置对两条通道都生效。
