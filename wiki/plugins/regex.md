# 正则增强 (beilu-regex)

beilu-regex 是一个正则脚本引擎，用于在 AI 回复到达用户之前和之后对文本进行匹配和替换。兼容 SillyTavern 的正则脚本格式，可以导入 ST 社区的正则脚本。

## 工作原理

beilu-regex 在消息管线的两个阶段工作：

### TweakPrompt 阶段（发送前）

在 TweakPrompt 的 dl=0 轮（最后一轮），beilu-regex 可以对即将发送给 AI 的消息进行正则处理。

### ReplyHandler 阶段（回复后）

AI 回复到达后，beilu-regex 对回复文本执行正则规则，进行匹配、替换、过滤等操作。

## 规则结构

每条正则规则包含：

| 字段 | 说明 |
|------|------|
| 名称 | 规则的显示名称 |
| 匹配模式 | 正则表达式（支持标准正则语法） |
| 替换文本 | 匹配成功时替换为的内容 |
| 作用范围 | 应用于 AI 回复 / 用户输入 / 两者 |
| 启用状态 | 是否激活此规则 |
| 适用预设 | 规则与哪些预设绑定 |

## 规则管理

### CRUD 操作

通过 SetData 接口的不同 `_action` 值进行规则的增删改查：

- 创建规则
- 编辑规则
- 删除规则
- 启用/禁用规则
- 调整规则顺序

### 从 SillyTavern 导入

beilu-regex 提供 `importFromSTFormat` 函数，可以直接导入 SillyTavern 格式的正则脚本。导入时会自动转换字段格式。

导入角色卡时，如果卡中包含正则脚本，也会自动导入并注册到 beilu-regex。

## 正则防护（ReDoS 防护）

beilu-regex 内置了 regexGuard 安全机制，防止恶意或意外的正则表达式导致 ReDoS（正则表达式拒绝服务）攻击：

- 检测潜在的灾难性回溯模式
- 执行超时保护
- 安全开关 `regexGuard.enabled` 受 owner 权限保护

## 预设绑定

正则规则可以与特定预设绑定。切换预设时，只有与当前预设关联的规则会生效。这使得不同角色/场景可以使用不同的正则处理规则。

预设切换时，beilu-preset 会调用 `_resyncPresetRegex` 同步正则规则的激活状态。

## 典型用途

| 用途 | 说明 |
|------|------|
| 格式清理 | 去除 AI 回复中的多余空行、特殊标记 |
| 内容过滤 | 过滤不需要的回复片段 |
| 标签转换 | 将 AI 的自定义标签转换为 HTML 或其他格式 |
| 角色名替换 | 在显示前替换角色名的变体写法 |
| 思维链隐藏 | 隐藏 AI 回复中的推理过程标签 |

## 数据存储

规则数据存储在插件目录的 `config_data.json` 中（数据不随代码迁移，留在原位）。
