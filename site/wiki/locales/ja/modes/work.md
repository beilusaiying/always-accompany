# ワークモード (Work)

## ワークモードに入る

| 方法 | 操作 |
|------|------|
| トップモードセレクター | 「Work」タブをクリック |
| キーボードショートカット | `Ctrl+4` または `Alt+4` |

ワークモードに切り替えると、システムが自動的に scheduler（定時タスクスケジューラ）を起動します。入った後のデフォルトは全幅 AI チャットエリアです。

## タスクシーン別の操作

### タスクを管理する

アクティビティバーの **overview** ボタンをクリックしてタスクダッシュボードを開きます。

- **タスクリスト** — ステータスごとに進行中/未着手/完了の3グループに分かれ、各グループにカウントと進捗バーが表示されます
- **作業ファイル管理** — 作業ファイルの作成、閲覧、編集、削除（CRUD）。ファイルはタスクと関連付けられます

### AI の権限を調整する

アクティビティバーの **toolkit** ボタンをクリックしてツールボックスを開きます。

- **権限クイックプリセット** — ワンクリックで切り替え：フル（全権限）/ 最小（基本権限）/ 読み取り専用
- **個別権限スイッチ** — 11 項目のツール権限を1つずつ設定します
- **パスホワイトリスト/ブラックリスト** — AI がアクセスできるファイルパスまたはアクセス禁止のファイルパスを指定します
- **コマンドカテゴリ認可** — コマンドカテゴリごとに一括で認可または禁止します

### AI にタスクを委任する

- タスクを AI に委任して独立実行させます。AI は独立スレッドで完了するため、メインの対話をブロックしません
- 委任の進捗と結果を確認できます

### 定時タスクを設定する

- 定時トリガーのタスクを設定します（cron 式スケジューリング）
- プリセットのワークフローを自動実行します
- ワークモードに切り替えると scheduler が自動起動します

### パイプラインを編成する

- **Skill グループカード** — 各カードにグループ名とステップ数が表示されます。起動ボタン（▶）をクリックして実行を開始します
- **新規グループ** — 新規作成ボタンをクリックするとモーダルが表示されます。グループ名を入力し、含めるサブモードとその順序を選択します。実行時は順番どおりにサブモードを自動切り替えしながら進行します

### MCP サービスに接続する

アクティビティバーの **mcp** ボタンをクリックします。

- MCP（Model Context Protocol）サービスに接続し、AI が呼び出せるツールセットを拡張します
- カスタム MCP サーバー設定をサポートします

### 実行状態を監視する

アクティビティバーの **operations** ボタンをクリックしてモニタリングパネルを開き、実行状態とログを確認します。

### 並行タスクを管理する

アクティビティバーの **groups** ボタンをクリックして、並行タスクグループを管理します。

## アクティビティバーボタン一覧

| ボタン | 名称 | 開くサイドバーパネル |
|------|------|-----------------|
| chat | デフォルトチャット | 全幅 AI チャット（デフォルトビュー） |
| overview | タスクダッシュボード | タスクリスト、作業ファイル管理 |
| history | 対話履歴 | 過去の対話リストと切り替え |
| toolkit | ツールボックス | 権限、ツール、コマンド認可 |
| mcp | MCP | MCP サービスの接続と管理 |
| operations | モニタリング | 実行状態とログ監視 |
| groups | 並行グループ | 並行タスクグループ管理 |
| submodes | サブモード | サブモードリスト（動的インジェクション） |

## サブモード（11 個）

ワークモードには 11 個のサブモードが内蔵されており、ワークフローの全工程をカバーします：

| サブモード | 用途 |
|--------|------|
| タスク確認師 | 要件を理解し、認識を確認し、タスクファイルを作成します |
| タスク設計 | タスク MD を読み込み、最終効果から逆算して実行フローを設計します |
| フロー最適化 | フローを最適化し、トークン消費を削減し、ステップを精簡します |
| フレームワーク審査 | フロー設計のエラーを審査します。最適化のみで差し戻しはしません |
| プロンプト設計 | タスクに必要なプロンプトを設計します |
| プロンプト+プリセット設計 | always-accompany のプロンプトとプリセット自体を設計します |
| Skill/スクリプト制作 | スクリプト、skill、MCP 接続の制作 |
| フロー組み立て | プロンプト、skill、スクリプトを実行可能なフローグループに組み立てます |
| フローグループ実行 | フローグループを実行し、順番に各ステップを実行してログを記録します |
| 検証 | ユーザー検証または自動検証で実行結果を確認します |
| 仕上げ・アーカイブ | タスク MD をアーカイブし、インデックスを更新し、完了レポートを生成します |

各サブモードはプリセット、API ソース、モデル、サンプリングパラメータを個別にバインドできます。詳しくは[サブモードと切り替え](beilu:wiki/modes/submodes.md)をご覧ください。

サブモード選択バーは入力欄の上にあり、クリックするとフローティングリストが表示されて切り替えられます。サブモード管理パネルでは、ID、アイコン、名称、説明、プリセットバインディング、API ソース選択、後処理ルール、プレフィル内容、有効/無効スイッチを設定できます。

## バックエンドモード値

ワークモードはバックエンドモード値 `work` に対応し、フロントエンド Tab は `work` です。
