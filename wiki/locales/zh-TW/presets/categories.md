# 預設集分類與選擇

## 切換和篩選預設集

### 按使用情境選

| 你想做的事 | 推薦分類 | 理由 |
|-----------|---------|------|
| 角色扮演對話 | clone | 包含角色行為引導、對話風格控制 |
| 日常聊天 | clone 或通用 | 輕量級指令，自然對話 |
| 寫程式碼 | code | 包含程式碼規範、輸出格式、工具使用指令 |
| 任務管理 / 文件 | work | 包含任務分解、格式要求、審批流程 |
| 自訂情境 | 自建預設集 | 完全按你的需求定製 |

### 按模式自動載入

如果你在模式設定中綁定了預設集（詳見 [預設集與模式聯動](mode-binding.md)），切換模式時會自動載入對應預設集，通常不需要手動選擇。

### 按角色/對話獨立設定

每個角色和每個對話視窗可以獨立綁定預設集。系統透過 **active_preset_map** 記錄每個對話使用的預設集，互不干擾：

- 和角色 A 聊天用預設集 X
- 和角色 B 聊天用預設集 Y
- 切換對話視窗時，預設集自動恢復

## 管理預設集

### 檢視已安裝預設集

在預設集管理面板中可以看到所有已安裝的預設集，按 bucket 分組顯示。每個預設集顯示名稱、描述和目前狀態。

### 匯入預設集

支援匯入 SillyTavern 格式的預設集 JSON 檔案。匯入時系統會：

1. 解析預設集 JSON，提取條目和參數
2. 註冊到 registry.json
3. 如果攜帶 bucket 欄位，歸入對應分類
4. 如果攜帶 model_params，儲存模型參數

### 匯出預設集

可以將目前預設集匯出為 SillyTavern 相容的 JSON 檔案，方便分享或備份。也可以透過[匯入匯出](beilu:settings/import-export)面板批次操作。匯出包含全部條目、排序、參數和分類資訊。

### 刪除預設集

刪除內建預設集實際上是標記為「已刪除」（記錄在 config.json 的 deleted_builtins 中），可以隨時恢復。使用者自建的預設集刪除後需要重新匯入。

## 分類邏輯

always-accompany 透過 **bucket（分組桶）** 對預設集進行分類管理。每個預設集在註冊時會標記所屬 bucket，前端按 bucket 分組展示。

### 內建分類

| Bucket | 說明 | 預設集數量 | 適用模式 |
|--------|------|---------|---------|
| code | 程式碼輔助類預設集 | 11+ | Code / IDE 模式 |
| work | 工作流類預設集 | 12+ | Work 模式 |
| clone | 角色扮演 / 克隆類預設集 | 5+ | Chat / AIRP 模式 |
| _(無分類)_ | 通用預設集 | 按需 | 所有模式 |

### 分類的來源

預設集的 bucket 資訊記錄在 **registry.json**（預設集註冊表）中，這是分組的單一權威源。匯入預設集時如果 JSON 檔案攜帶了 bucket 欄位，會自動註冊到對應分類。

沒有 bucket 欄位的預設集，前端會根據預設集名稱中的關鍵詞進行回退匹配，盡量歸入合適的分組。

## 預設集選擇的優先級

系統確定目前對話使用哪個預設集時，按以下優先級：

1. **對話級綁定**：active_preset_map 中以 chatId 為鍵記錄的預設集
2. **模式級綁定**：mode_preset_bindings 中該模式的預設預設集
3. **全域預設**：active_preset（全域設定的預設預設集）
