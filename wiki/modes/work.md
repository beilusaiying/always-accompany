# 工作模式 (Work)

## 进入工作模式

| 方式 | 操作 |
|------|------|
| 顶部模式选择器 | 点击「Work」标签 |
| 键盘快捷键 | `Ctrl+4` 或 `Alt+4` |

切入工作模式时，系统会自动启动 scheduler（定时任务调度器）。进入后默认为全宽 AI 对话区。

## 按任务场景操作

### 管理任务

点击活动栏的 **overview** 按钮打开任务台。

- **任务列表** — 按状态分为进行中/待办/已完成三组，每组显示计数和进度条
- **工作文件管理** — 创建、查看、编辑、删除工作文件（CRUD），文件与任务关联

### 调整 AI 权限

点击活动栏的 **toolkit** 按钮打开工具箱。

- **权限快速预设** — 一键切换：完整（全部权限）/ 最小（基本权限）/ 只读
- **逐条权限开关** — 对 11 项工具权限逐一设置
- **路径白名单/黑名单** — 指定 AI 可访问或禁止访问的文件路径
- **命令分类授权** — 按命令类别批量授权或禁止

### 委派任务给 AI

- 将任务委派给 AI 独立执行，AI 在独立线程中完成，不阻塞主对话
- 可查看委派进度和结果

### 设置定时任务

- 配置定时触发的任务（cron 式调度）
- 自动执行预设的工作流程
- 切入工作模式时 scheduler 自动启动

### 编排流水线

- **Skill 组卡片** — 每张卡片显示组名和步骤数，点击启动按钮（▶）开始执行
- **新建组** — 点击新建按钮弹出模态框，填写组名并勾选要包含的子模式及其顺序，执行时按顺序自动切换子模式推进

### 连接 MCP 服务

点击活动栏的 **mcp** 按钮。

- 连接 MCP（Model Context Protocol）服务，扩展 AI 可调用的工具集
- 支持自定义 MCP 服务端配置

### 监控运行状态

点击活动栏的 **operations** 按钮打开监控面板，查看运行状态与日志。

### 管理并行任务

点击活动栏的 **groups** 按钮，管理并行任务组。

## 活动栏按钮一览

| 按钮 | 名称 | 打开的侧边栏面板 |
|------|------|-----------------|
| chat | 默认对话 | 全宽 AI 对话（默认视图） |
| overview | 任务台 | 任务列表、工作文件管理 |
| history | 对话历史 | 历史对话列表与切换 |
| toolkit | 工具箱 | 权限、工具、命令授权 |
| mcp | MCP | MCP 服务连接与管理 |
| operations | 监控 | 运行状态与日志监控 |
| groups | 并行组 | 并行任务组管理 |
| submodes | 子模式 | 子模式列表（动态注入） |

## 子模式（11 个）

工作模式内置 11 个子模式，覆盖工作流全流程：

| 子模式 | 用途 |
|--------|------|
| 任务确认师 | 理解需求，核对理解，建立任务文件 |
| 任务设计 | 读取任务 MD，反推设计执行流程 |
| 流程优化 | 优化流程，减少 token 消耗，精简步骤 |
| 框架审查 | 审查流程设计错误，只优化不打回 |
| 提示词设计 | 为任务设计所需的提示词 |
| 提示词+预设设计 | 设计 always-accompany 提示词与预设本身 |
| Skill/脚本制作 | 制作脚本、skill、MCP 接入 |
| 流程组装 | 将提示词、skill、脚本组装为流程组 |
| 执行流程组 | 运行流程组，按顺序执行并记录日志 |
| 验证 | 用户验证或自动验证执行结果 |
| 收尾归档 | 归档任务 MD，更新索引，生成完成报告 |

每个子模式可独立绑定预设、API 源、模型和采样参数。详见 [子模式与切换](beilu:wiki/modes/submodes.md)。

子模式选择栏位于输入框上方，点击弹出浮层列表供切换。在子模式管理面板中可配置 ID、图标、名称、描述、预设绑定、API 源选择、后处理规则、预填充内容和启用/禁用开关。

## 后端模式值

工作模式对应后端模式值 `work`，前端 Tab 为 `work`。
