# 格式与符号运用

提示词的格式——标题层级、符号标记、视觉分隔——影响 AI 对内容的解读权重。合理的格式让重点突出、层次清晰；过度的格式则会适得其反。

## 核心原则：适度

格式符号不是越多越好。过多的加粗、标题、分隔线会形成"饱和式打击"——当所有东西都在强调时，等于什么都没有强调。

```
错误（饱和式打击）：
────────────────
# **重要规则**
## *写作风格*
### ⚠️ 注意事项
- **必须** 使用 **白描**
- **必须** 保持 **节奏**
- **绝对不要** 使用 ~~比喻~~
---
## **角色设定**
### ⚡ 核心特征
> ⚠️ **重要**：角色 **必须** 保持 **一致性**

→ 到处都是加粗、标题、符号、分隔线，
  AI 分不清什么才是真正重要的。
```

```
正确（适度使用）：
────────────────
# 写作风格
以白描为主，保持节奏明快。

# 角色设定
角色在不同场景中保持**核心性格**一致，
但允许情绪和表达方式随场景变化。

→ 只有"核心性格"被加粗，
  因为这是这段话中最关键的概念。
```

## 标题层级

### 只用一级标题

在提示词中，建议只使用 `#` 一级标题来划分模块。过多的层级（`##` `###`）会让结构变得复杂，AI 需要额外精力来解析层级关系，反而分散了对内容本身的注意力。

```
错误（层级过多）：
# 写作指南
## 风格
### 叙事
#### 节奏
##### 对话节奏
段落不超过三行。

正确（扁平结构）：
# 叙事节奏
段落不超过三行，对话用口语短句。
```

如果内容确实需要细分，用段落自然分隔就够了，不需要每一层都加标题。

## 强调标记的使用

### 引号和加粗

用 `""` 或 `**` 包裹**真正重要**的内容。什么算真正重要？如果 AI 忽略了这个词/这句话，整个输出的方向就会偏——那它就值得被强调。

```
有效的强调：
角色的行为必须符合**当前情绪状态**，而非人设的默认性格。

→ "当前情绪状态"是这句话的关键区分点，
   不强调的话 AI 可能默认用人设性格来驱动行为。
```

```
无效的强调：
**角色**的**行为**必须**符合**当前**情绪状态**。

→ 什么都加粗 = 什么都没加粗。
```

### 使用建议

| 符号 | 用途 | 频率 |
|------|------|------|
| `#` | 模块分隔 | 每个主题模块一个 |
| `**加粗**` | 关键概念强调 | 一段话最多 1-2 处 |
| `""引号` | 专有名词或特定表述 | 需要精确引用时 |
| `---` 分隔线 | 大模块之间的视觉分隔 | 偶尔使用 |
| `> 引用块` | 补充说明或注意事项 | 偶尔使用 |

## 常见格式问题

### 列表滥用

不是所有内容都需要列表化。当内容之间有逻辑关系（先后、因果）时，用自然语言段落更好。

```
不合适的列表：
- 先分析角色当前的情绪
- 然后考虑角色会做什么反应
- 最后写出角色的动作和对话

更好的写法：
从角色当前的情绪出发，推演角色的反应，
再通过动作和对话表现出来。
```

列表适合并列的、独立的条目，比如：
- 多个角色的特征分别列出
- 几条互不相关的注意事项
- 清单式的格式要求

### 过度嵌套

```
错误：
- 角色特征
  - 性格
    - 核心性格
      - 沉稳
    - 次要性格
      - 偶尔幽默
  - 说话方式
    - 口癖
      - "嘛"
    - 句式
      - 短句为主

正确：
角色性格沉稳，偶尔流露幽默。
说话时带"嘛"作为口癖，以短句为主。
```

深度嵌套的列表在提示词中几乎没有正面作用。AI 不会因为你的结构更"完整"就表现更好——它需要的是清晰的信息，不是精美的大纲。

## 小结

- **少即是多**：符号和格式只在真正需要强调时使用
- **扁平优于层级**：一级标题分模块，段落分细节，不需要层层嵌套
- **强调要精准**：一段话中只强调最关键的 1-2 个概念
- **自然语言优先**：有逻辑关系的内容用段落表达，并列独立的条目才用列表
