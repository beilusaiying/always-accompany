# 進階巨集

隨機選擇、擲骰子、文字處理、時間計算等。大多需要參數，用雙冒號 `::` 分隔。

## 隨機與選擇

### {{random::選項列表}}

從逗號分隔的選項中**隨機**選一個。每次替換結果可能不同。

```
{{random::晴天,陰天,雨天,雪天}}
```

可能輸出：`雨天`

**用途**：為對話增加隨機性和變化感。

範例——角色的隨機開場情緒：
```
{{char}}今天的心情是{{random::開心,平靜,憂鬱,興奮,慵懶}}的。
```

### {{pick::選項列表}}

從逗號分隔的選項中**確定性**地選一個。相同的輸入在相同的上下文中總是回傳相同的結果。

```
{{pick::春,夏,秋,冬}}
```

輸出：`秋`（同一上下文下每次都是這個結果）

**與 random 的區別**：`random` 每次都可能不同，`pick` 在同一上下文下結果固定。需要穩定性時用 `pick`，需要變化時用 `random`。

## 擲骰子

### {{roll:NdM}} / {{roll:NdM+K}}

模擬擲骰子。`N` 是骰子數量，`M` 是骰子面數，`K` 是可選的加減修正值。

| 寫法 | 含義 | 結果範圍 |
|------|------|----------|
| `{{roll:1d6}}` | 擲 1 個 6 面骰 | 1~6 |
| `{{roll:2d10}}` | 擲 2 個 10 面骰，求和 | 2~20 |
| `{{roll:1d20+5}}` | 擲 1 個 20 面骰，加 5 | 6~25 |
| `{{roll:3d6-2}}` | 擲 3 個 6 面骰，減 2 | 1~16 |

### 使用範例

角色扮演中的技能檢定：
```
{{user}}嘗試開鎖，擲出了 {{roll:1d20+3}} 點（DC 15）。
```
可能輸出：
```
小明嘗試開鎖，擲出了 18 點（DC 15）。
```

戰鬥傷害計算：
```
{{char}}揮劍攻擊！造成 {{roll:2d6+4}} 點傷害。
```

## 文字處理

### {{reverse::文字}}

將文字反轉輸出。

```
{{reverse::Hello World}}
```
輸出：`dlroW olleH`

```
{{reverse::你好世界}}
```
輸出：`界世好你`

## 時間計算

### {{timediff::時間1::時間2}}

計算兩個時間點之間的差值，回傳人類可讀的時間差描述。

```
{{timediff::2026-01-01::2026-07-14}}
```
輸出：時間差的人類可讀表示

**用途**：在提示詞中表達「距某事件過了多久」或「還有多久到某個時間點」。

## 時區與格式化

### {{time_utc+N}}

取得指定時區偏移的目前時間。`N` 為 UTC 偏移量。

| 寫法 | 含義 |
|------|------|
| `{{time_utc+8}}` | UTC+8 時間（東八區） |
| `{{time_utc+9}}` | UTC+9 時間（東九區） |
| `{{time_utc-5}}` | UTC-5 時間（美東標準時） |
| `{{time_utc+0}}` | UTC 時間 |

範例：
```
東京時間：{{time_utc+9}}
```

### {{datetimeformat FORMAT}}

使用自訂格式字串輸出目前日期時間。格式遵循標準的日期時間格式化語法。

```
{{datetimeformat YYYY年MM月DD日 HH:mm}}
```
可能輸出：`2026年07月14日 14:30`

```
{{datetimeformat MM/DD/YYYY}}
```
可能輸出：`07/14/2026`

## 特殊用途巨集

### {{banned "詞語"}}

標記一個違禁詞。用於在提示詞中告知 AI 某些詞不應使用。

```
{{banned "某個詞"}}
```

### {{//註解內容}}

註解巨集。內容會被完全移除，不會出現在最終的提示詞中。適合在預設集範本中寫備註。

```
{{//這段是給預設集編輯者看的註解，AI不會看到}}
正式的提示詞內容在這裡。
```
