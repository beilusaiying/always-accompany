# P1 自驅動發散召回系統：設計、演算法與實驗（合集）

## 摘要

本合集系統性地描述 always-accompany 專案中的 P1 自驅動子系統——一條**外置的發散思維鏈**。其出發點是設計者的一個基本判斷：大語言模型（LLM）在結構上是「收攏機器」，其注意力機制與產生過程天然趨向匯聚，而不具備主動發散能力；因此發散必須以模型外置節點的方式實現。P1 在模型之外構建了一條不依賴 LLM 的處理管線：以記憶召回與對話上下文為錨點（收縮），經聯想網路與六條學科軸（心理、資訊、社會、邏輯、語言、認知）並行發散，在共享候選池中以空間加性投票與多對一收攏產出方向詞（再收縮），最終以提示詞注入的方式為模型的產生提供方向性框架。

合集目前共七章。第1–6章保留 P1 的設計理念、舊節點體系、記憶設計與歷史實驗；第7章單獨記錄目前的生產契約，包括 Node0–4、最近最多 5 條使用者訊息 + Data、四維隔離、白盒證據、延遲載入與有界快取。閱讀「現在實際怎麼跑」時請先看第7章，歷史章節中的舊執行態不再覆蓋目前原始碼。

## 閱讀約定（全書統一）

1. **數值來源分級**。文中數值一律標注來源級別：**經實驗校準的定檔值**（由可複查的實驗鎖定）或**初始預設值（未經系統性調優）**。形狀級公式（結構）為規格描述；具體權重、係數與閾值以實現為準。
2. **執行態聲明**。自驅動 P1 已透過本機 Node0–4 召回接入目前宿主主鏈；AI P1 仍保留為互斥的可選模式，也允許兩者都關閉，但不允許兩個 owner 同時執行。第1–6章中的「組件態 / AI P1 現役」是 2026年7月的歷史快照；目前路由、輸入契約和實測邊界以[第7章](ch7-current-runtime.md)與原始碼為準。
3. **引文**。除極少數標注「設計者原話」的引文外，全書均為對設計意圖與實現的規範轉述。
4. **相關工作分檔**。第3章對每項演算法給出 prior-art 對照，分檔口徑：A＝機制高度相似且公開時間早於本系統設計（可能撞車）；B＝部分相似（組件重疊、整體機制不同）；C＝僅概念詞相近；D＝未找到相似公開工作。核查結論為 A＝0。
5. **術語**。各章在術語首次出現處給出定義；全書術語表見第6章附錄A。
