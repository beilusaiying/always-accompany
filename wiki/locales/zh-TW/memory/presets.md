# 記憶AI預設集(P1-P8)

記憶系統的幕後運行著多個專用 AI 預設集（Preset），各自負責記憶生命週期的不同環節。這些預設集不是使用者直接互動的角色 AI，而是系統級的後台工作者。

## 預設集一覽

| 預設集 | 名稱 | 職能 | 觸發時機 |
|------|------|------|----------|
| **P1** | 檢索 AI | NLP 分詞 + 聯想擴展 + 四維打分，從溫/冷層召回相關記憶 | 每輪對話前 |
| **P2** | 表格總結/歸檔 AI | 臨時記憶超閾值時產生總結並歸檔到溫層 | 臨時記憶超閾值 |
| **P3** | 每日總結 AI | 日終匯總當天事件，產生日總結 | 每日收尾 |
| **P4** | 熱→溫轉移 AI | 將熱層中過期/低權重的記憶移入溫層 | 搬遷檢查時 |
| **P5** | 月度總結/歸檔 AI | 為滿歸檔期的溫層月份編纂月總結 | 月度歸檔時 |
| **P6** | 格式檢查/修復 AI | 檢查並修復表格和記憶檔案中的格式問題 | 格式檢查/一鍵升級時 |
| **P7** | 壓縮 AI | 上下文過長時產生摘要 | 上下文超限時 |
| **P8** | 聯網搜尋 AI | 調用外部搜尋取得資訊 | AI 判斷需要外部資訊時 |

## P1：檢索 AI

P1 是記憶召回引擎（P1 自驅動管線），每輪對話前自動運行。

**運行鏈**：

```
使用者訊息進入
    ↓
NLP 分詞：將使用者訊息拆分為關鍵詞
    ↓
聯想擴展：對關鍵詞進行語義聯想，產生擴展詞集
    ↓
多詞共現比對：在 warm/cold 層中查找包含擴展詞的記憶條目
    ↓
四維打分：對候選條目按四個維度評分
    ↓
排序篩選：取得分最高的條目
    ↓
注入上下文：將召回的條目拼入本輪上下文
```

**四維打分**：

| 維度 | 含義 | 權重傾向 |
|------|------|----------|
| **semantic** | 語義相關度 | 內容與目前話題的語義比對程度 |
| **lexical** | 詞彙比對度 | 關鍵詞的直接比對程度 |
| **recency** | 時間近度 | 越新的記憶得分越高 |
| **importance** | 重要性 | 被標記為重要的記憶得分更高 |

四個維度的得分加權求和後排序，取 top-N 條目注入上下文。

## P2：總結歸檔

P2 負責將臨時記憶提煉為結構化記憶並歸檔到溫層。

**運行鏈**：

```
臨時記憶超過閾值
    ↓
P2 讀取臨時記憶內容
    ↓
提取關鍵資訊：事件、情感、決策、新認知
    ↓
歸納為結構化條目並產生總結
    ↓
寫入對應的記憶表格（透過 <tableEdit> 機制）
    ↓
歸檔到溫層（觸發搬遷檢查）
```

## P3-P6：記憶生命週期維護

P3 到 P6 各自負責記憶「新陳代謝」的一個環節，在後台按時機自動運行：

| 預設集 | 職能 | 說明 |
|------|------|------|
| **P3 每日總結 AI** | 日終匯總當天事件 | 在每日收尾時把當天發生的事匯總成日總結（對應 #6 日總結表） |
| **P4 熱→溫轉移 AI** | 熱層降溫 | 把熱層中過期或低權重的記憶條目移入溫層，控制熱層容量 |
| **P5 月度總結/歸檔 AI** | 月度歸檔 | 為達到歸檔期的溫層月份編纂月總結，物理搬移由系統自動執行 |
| **P6 格式檢查/修復 AI** | 格式維護 | 檢查並修復表格與記憶檔案中的格式問題，配合工具列的「格式檢查/一鍵升級」 |

這些預設集配合 P1（召回）、P2（歸檔）、P7（壓縮）、P8（聯網）構成完整的記憶管線，使用者通常無需手動干預。

## P7：壓縮 AI

P7 在上下文接近限制時觸發，產生對話摘要以釋放空間。

**運行鏈**：

```
上下文 token 數接近模型限制
    ↓
系統觸發 P7
    ↓
P7 讀取較早的對話輪次
    ↓
產生壓縮摘要
    ↓
摘要存入 context_summary.json
    ↓
原始對話輪次從上下文中移除
    ↓
後續對話中，摘要替代原始內容出現在上下文中
```

詳見 [上下文壓縮](compression.md)。

## P8：聯網搜尋

P8 在 AI 判斷需要外部資訊時觸發。

**運行鏈**：

```
AI 判斷目前問題需要外部資訊
    ↓
系統調用 P8
    ↓
P8 建構搜尋查詢
    ↓
調用搜尋介面取得結果
    ↓
將搜尋結果注入目前上下文
    ↓
AI 基於搜尋結果繼續回覆
```

## 預設集間的協作

一輪典型的對話中，預設集的協作順序：

```
使用者發訊息
    ↓
P1 召回相關記憶 → 注入上下文
    ↓
AI 回覆（可能觸發 P8 聯網搜尋）
    ↓
AI 回覆中的 <tableEdit> 寫入熱層
    ↓
達到閾值時 P2 執行總結歸檔
    ↓
上下文過長時 P7 執行壓縮
```

## P系列引擎編輯面板

在[記憶管理](beilu:mode/memory)中點擊工具列的 **pseries** 按鈕，可開啟 P 系列引擎編輯面板。

### 版面配置

- **左側清單**：顯示 P1 到 P8 全部預設集，點擊切換
- **右側詳情**：展示並編輯選中預設集的完整設定

### 可編輯項

| 項目 | 說明 |
|------|------|
| 啟用 toggle | 控制該預設集是否生效 |
| 描述 | 預設集的功能說明文字 |
| AI 調用參數 | AI 源、模型、後處理、預填充、temperature 等 |
| 提示詞組 | 按查看模式（chat / code / work）編輯不同的提示詞集 |

### 提示詞編輯

切換查看模式後，右側展示該模式下的提示詞清單。支援增刪改查（CRUD）：新建提示詞條目、編輯內容、調整順序、刪除條目。

## 記憶AI預設集互動面板

在[記憶管理](beilu:mode/memory)的檢索/診斷區，或透過預設集切換器進入互動面板。

### 預設集切換器

根據目前模式顯示可用預設集：

- **聊天模式**：顯示 P2-P6
- **程式碼/工作模式**：顯示 P2-P7

點擊預設集名稱切換到對應的互動介面。

### AI 對話互動

- **運行預設集**：點擊運行按鈕，系統調用選中的預設集，結果以氣泡形式展示
- **使用者輸入**：在輸入框中追加訊息並發送，與預設集 AI 進行多輪對話
- **非同步運行**：長時間運行的預設集可在後台執行，完成後點擊「查看」取得結果
- **清空**：重設目前預設集的對話歷史

### 提示詞預覽

互動面板提供三個預覽標籤頁：

| 標籤 | 內容 |
|------|------|
| 訊息清單 | 按 section 分段展示最終發送給 AI 的訊息結構 |
| 原始 JSON | 查看完整的原始請求資料 |
| 預設集預覽 | 預覽預設集本身的設定內容 |

### 檔案樹與匯入匯出

- **檔案樹檢視**：以樹狀結構瀏覽預設集相關的檔案
- **匯入匯出**：支援 zip 和 json 格式的預設集匯入匯出

## 說明書庫

在[記憶管理](beilu:mode/memory)中點擊工具列的 **skills** 按鈕，開啟說明書庫管理。

### 結構

說明書按模式分類（如 IDE 模式、工作模式），左側清單展示目前模式下的所有說明書，右側顯示選中說明書的詳情。

### 新建與編輯

點擊新建或編輯按鈕會彈出懸浮窗，包含以下欄位：

- **名稱**：說明書的標識名
- **作用**：功能描述
- **模式**：適用的工作模式
- **triggers**：觸發條件（何時啟動該說明書）
- **正文**：說明書的完整內容

## 診斷面板

在[記憶管理](beilu:mode/memory)中點擊工具列的 **diag** 按鈕，或在檢索/診斷區切換到「診斷」子 Tab。

面板展示以下資訊：

- **外掛啟用狀態**：記憶外掛是否已啟用
- **auto_trigger**：P1 自動觸發是否開啟
- **P1 狀態**：目前 P1 引擎的運行狀態
- **快取資訊**：快取字元數與快取時間
- **輸出佇列**：待處理的輸出條目
- **啟用預設集清單**：目前已啟用的預設集清單
- **快取內容**：可展開查看完整的快取資料

## 開發注意事項

- 各預設集使用獨立的系統提示詞，定義其行為和輸出格式
- 預設集的觸發條件和閾值在設定中可調
- P1 的召回品質直接影響 AI 的「記憶力」表現，是效能調校的關鍵環節
- P2-P6 分別負責記憶生命週期的不同環節（歸檔、日/月總結、搬遷、格式修復），配合 P1 召回、P7 壓縮、P8 聯網構成完整的記憶管線
