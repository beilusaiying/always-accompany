# 精简与迭代

提示词不是越长越好，也不是写一次就完。精简让 AI 抓住重点，迭代让提示词越来越好。

## 减少无用提示词

### 三种常见的"无用"

**1. 中英双语标题**

```
错误：
## Writing Style / 写作风格
你的写作以白描为主......

## Character Voice / 角色语言
角色对话要自然......
```

中英双语标题不会让 AI 理解得更好，只会浪费 token 和分散注意力。AI 完全能理解纯中文标题。

```
正确：
## 写作风格
你的写作以白描为主......

## 角色语言
角色对话要自然......
```

**2. 内容单一化（同一个意思反复说）**

```
错误：
对话要自然。角色之间的交流要像真实对话一样。
避免生硬的台词，让角色的语言贴近日常。
每个角色的说话方式都应该像真人一样自然。
```

这四句话说的是同一件事。AI 不会因为你说了四遍就更重视，反而会被重复内容稀释其他要点的权重。

```
正确：
角色对话使用口语化短句，允许打断、接话和跑题。
```

一句话就够了，而且比四句话更清晰。

**3. 过度直接示例**

```
错误：
比如角色A会说"今天天气真好啊"，角色B会回答"是啊，好想出去玩"，
然后角色A说"那我们去公园吧"，角色B说"好啊好啊"......
（长达十几轮的示例对话）
```

过多的直接示例会导致 AI **过拟合**——它不是学到了"怎么写对话"，而是记住了"就该这样写对话"，输出变得像在复述你的示例。

少量、精选的示例才有效。（详见"少样本提示"章节。）

## 精简但避免许愿

### 什么是许愿

许愿就是把"期望的最终效果"当成了提示词指引。

```
这是许愿：
写出引人入胜的故事。
让读者沉浸其中。
创造令人难忘的角色。
```

这些话描述的是"好小说"的特征，但 AI 不知道**怎么做到**。就像跟一个人说"把饭做好吃"——他需要的是菜谱，不是"做好吃"这三个字。

### 精简 ≠ 许愿

精简是去掉废话，留下有效指引。许愿是去掉了方法，只留下了愿望。

| 许愿（无效） | 精简的有效指引 |
|------------|--------------|
| 写出有画面感的场景 | 用具体感官细节构建场景：温度、声音、气味 |
| 让对话真实自然 | 对话用口语短句，允许打断和跑题 |
| 创造有深度的角色 | 角色在两难选择中展现价值观冲突 |
| 保持文章节奏紧凑 | 段落不超过三行，场景切换不加过渡 |

### 精简检查法

写完提示词后，逐条检查：

1. **这条能不能指导 AI 的具体行为？** —— 能，保留；不能，改写或删除
2. **去掉这条，AI 的表现会变差吗？** —— 会，保留；不会，删除
3. **这条和其他条重复了吗？** —— 重复就合并成一条

## 提示词迭代

好提示词不是写出来的，是改出来的。

### A/B 测试

同一个场景，用两版提示词分别让 AI 生成，对比效果。

```
版本 A：
以白描为主，避免比喻。

版本 B：
以白描为主，减少比喻的使用频率。

同一输入 → 对比两个版本的输出 → 选效果更好的
```

改动一次只改一处，这样才能判断是哪个改动带来了效果变化。如果同时改了三处，效果变好了也不知道是哪处起了作用。

### 拆解问题

AI 表现不好时，不要笼统地说"效果差"。把问题拆解成具体的方面：

```
笼统："AI 写的对话不好"

拆解：
- 对话太长？ → 加一条"角色每次说话不超过两句"
- 对话太书面？ → 加一条"使用口语化表达"
- 角色分不清？ → 给每个角色加具体的说话特征
- 对话没推进？ → 加一条"每轮对话推进一个信息点"
```

拆解之后，每个问题都有针对性的解法，改起来效率高得多。

### 分析失败案例

当 AI 输出了一段不好的内容，不要只是觉得"不好"然后重新生成。去分析**为什么不好**：

1. **看 AI 到底写了什么** —— 具体哪里不符合你的要求
2. **对照提示词** —— 你的提示词有没有覆盖到这个方面。没覆盖就加上，覆盖了就改写法
3. **看 CoT**（如果有）—— AI 在分析阶段是怎么理解你的要求的，有没有理解偏差

### 迭代循环

```
写提示词
    ↓
测试（多次生成，看整体表现）
    ↓
发现问题（拆解成具体方面）
    ↓
分析原因（提示词没覆盖？覆盖了但写法不对？）
    ↓
修改提示词（一次改一处）
    ↓
再次测试
    ↓
（循环直到满意）
```

## 小结

- **去掉无用内容**：重复的、双语的、过多的示例，都是噪音
- **精简不等于许愿**：保留能指导具体行为的指引，删掉只描述结果的愿望
- **迭代才能变好**：A/B 测试、拆解问题、分析失败，是提升提示词的正路
