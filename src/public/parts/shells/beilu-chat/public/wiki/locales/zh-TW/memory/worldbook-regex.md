# 正規表示式與渲染條目

世界書條目中正規表示式比對和 GENERATE/RENDER 標記的用法。

## 正規表示式比對

當條目設定 `useRegex: true` 時，key 和 keysecondary 中的關鍵詞將作為正規表示式進行比對。

### 基本用法

| 需求 | 正規表示式寫法 | 比對範例 |
|------|----------|----------|
| 精確詞 | `魔法` | 「魔法師」、「學魔法」 |
| 詞邊界 | `\b魔法\b` | 僅比對獨立的「魔法」 |
| 多選一 | `魔法\|法術\|咒語` | 任一詞出現即比對 |
| 可選部分 | `魔法(師)?` | 「魔法」或「魔法師」 |
| 萬用字元 | `魔.*師` | 「魔法師」、「魔導師」 |

### 與 selective 配合

當 `selective: true` 時，key 和 keysecondary 都使用正規表示式比對，兩者必須同時命中才觸發。

**範例**：
- key: `森林|叢林|樹林`
- keysecondary: `夜晚|深夜|黑暗`
- 效果：只有當對話中同時提到「森林類」和「夜晚類」的詞時，才注入關於「夜間森林」的設定

### 注意事項

- 正規表示式的特殊字元（`.` `*` `+` `?` `(` `)` `[` `]` `{` `}` `\` `^` `$` `|`）如果要作為字面字元比對，需要反斜線跳脫
- 比對範圍包括使用者訊息和 AI 回覆的近期內容（具體掃描深度取決於設定）
- 正規表示式比對是大小寫敏感的，需要不區分大小寫時使用 `(?i)` 旗標

## GENERATE 與 RENDER 標記

世界書條目的 content 中可以使用兩種特殊標記來區分資訊的可見對象。

### [GENERATE:*] — 僅 AI 可見

```
[GENERATE:角色內心活動指引]
當角色在森林中時，描寫環境時應包含以下感官細節：
- 聽覺：鳥鳴、風聲、樹葉沙沙
- 嗅覺：泥土、花香、腐葉
- 觸覺：潮溼的空氣、腳下的落葉
[/GENERATE]
```

`[GENERATE:*]` 包裹的內容只會出現在發給 AI 的上下文中，不會在使用者介面上顯示。適用於：

- 給 AI 的寫作指導
- 角色行為規則
- 內部邏輯說明
- 不希望使用者直接看到的元指令

### [RENDER:*] — 僅使用者可見

```
[RENDER:場景氣氛文字]
--- 陰暗的森林，月光穿過樹冠灑下斑駁的光影 ---
[/RENDER]
```

`[RENDER:*]` 包裹的內容只會在使用者介面上顯示，不會發給 AI。適用於：

- 場景氛圍描述（裝飾性文字）
- UI 提示資訊
- 給使用者的說明文字
- 不需要 AI 處理但需要使用者看到的內容

### 混合使用

一個條目可以同時包含普通內容、GENERATE 內容和 RENDER 內容：

```
這是森林區域的設定。

[GENERATE:AI寫作指導]
描寫森林時注意季節變化對環境的影響。
[/GENERATE]

[RENDER:使用者提示]
提示：你目前位於古老森林的深處。
[/RENDER]
```

在這個範例中：
- 「這是森林區域的設定。」—— AI 和使用者都能看到
- GENERATE 部分 —— 只有 AI 看到
- RENDER 部分 —— 只有使用者看到

### 運行鏈

```
世界書條目觸發，content 進入注入流程
    ↓
解析 content 中的標記：
  - 找到 [GENERATE:*]...[/GENERATE] 區塊
  - 找到 [RENDER:*]...[/RENDER] 區塊
  - 剩餘部分為普通內容
    ↓
建構 AI 上下文時：
  - 包含普通內容
  - 包含 GENERATE 區塊內容
  - 排除 RENDER 區塊內容
    ↓
建構使用者顯示時：
  - 包含普通內容
  - 排除 GENERATE 區塊內容
  - 包含 RENDER 區塊內容
```

## 開發注意事項

- 標記的語法是 `[GENERATE:名稱]` 和 `[/GENERATE]` 配對，名稱部分用於標識但不影響邏輯
- 標記不能巢狀（不能在 GENERATE 區塊裡放 RENDER 區塊）
- 解析發生在注入時，解析失敗（如缺少關閉標籤）時整個 content 作為普通內容處理
- 正規表示式比對的掃描範圍（往回看多少輪對話）影響觸發的靈敏度，過大會增加誤觸發，過小會漏觸發
