# Screen Perception (beilu-eye)

beilu-eye provides two independent features:

1. **Desktop screenshot perception**: Automatically captures screen content, enabling the AI to "see" what you are doing
2. **Electron desktop pet**: Displays a virtual AI character avatar on your desktop

## Desktop Screenshot Perception

### How It Works

beilu-eye uses a Python script to periodically capture the desktop screen in the background:

```
Python script captures the screen
    ↓
Sends the screenshot to the always-accompany backend via HTTP POST
    ↓
Backend stores it in temporary injection state (injection_state)
    ↓
Frontend polling detects the new screenshot
    ↓
Sent as a file attachment with the message to AI
    ↓
AI sees the screenshot and provides feedback
    ↓
Screenshot is automatically cleared; not retained in subsequent context
```

### Key Features

- **One-shot injection**: After the AI sees a screenshot once, it is automatically cleared and does not occupy subsequent conversation context space
- **On-demand triggering**: Screenshots are not sent every turn; they are only injected when a new screenshot is available
- **Token authentication**: The Python script and backend authenticate via a pet-token, preventing unauthorized injection

### Use Cases

| Scenario | Description |
|----------|-------------|
| Coding assistance | AI sees your IDE screen and understands the current code context |
| Game Companion | AI sees the game screen and provides real-time strategy advice |
| Teaching & tutoring | AI sees your operating interface and offers timely corrections or guidance |
| Work assistance | AI sees the document/spreadsheet you are working on |

## Electron Desktop Pet

### Features

The desktop pet is a floating virtual AI character avatar window on your desktop. It runs independently of the browser and is always displayed on the desktop.

### How to Enable

Find the desktop pet option in the settings center and click to enable. always-accompany will automatically start the Electron desktop pet process.

### Process Management

The desktop pet process is managed centrally by the always-accompany backend:

- **4-second reconcile cycle**: Checks the desktop pet process status every 4 seconds
- **Auto-restart**: If the desktop pet process exits unexpectedly, it is automatically restarted
- **Graceful degradation**: If the Electron binary does not exist (not installed), the user is prompted to install rather than crashing

### Prerequisites

The desktop pet feature requires installing Electron dependencies. Run `npm install` in the `desktop-eye` directory.

## Security Mechanisms

### pet-token Gate

When the Python screenshot script sends data to the backend, it must carry a valid pet-token. This token is generated by the backend when the desktop pet/screenshot process starts and revoked when the process closes. Unauthorized requests are blocked.

### Allowlist / Blocklist

You can configure window allowlists and blocklists to control which applications' screenshots the AI can see and which it cannot.

## Configuration

| Setting | Description | Default |
|---------|-------------|---------|
| Screenshot interval | Time interval for the Python script's screenshots | 3 seconds |
| Desktop pet toggle | Whether to enable the Electron desktop pet | Off |
| Window blocklist | List of windows not to capture | - |
| Window allowlist | List of windows to exclusively capture | - |
