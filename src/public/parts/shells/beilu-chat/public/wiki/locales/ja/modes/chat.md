# チャットモード (Chat / AIRP)

## チャットモードに入る

| 方法 | 操作 |
|------|------|
| トップモードセレクター | 「Chat」タブをクリック |
| キーボードショートカット | `Ctrl+2` または `Alt+2` |

入った後、中央の対話エリアにメッセージを入力するだけで会話を始められます。

## 基本操作

- **日常会話**：メッセージを直接入力します。特別な設定は不要です
- **ロールプレイ**：左カラムからキャラクターカードを選び、適切なプリセットを選択してから会話を始めます
- **パラメータ調整**：右カラムのモデルパラメータパネルで AI の表現を微調整します（例：Temperature を下げてより安定した応答を得る）

## インターフェースレイアウト

3カラムレイアウトで、左右のカラムは折りたたみ可能です：

- **左カラム**：セッションリスト、キャラクターカード選択、セッション管理（新規作成 / 削除 / アーカイブ）
- **中央エリア**：対話メインエリア、メッセージの入力と表示
- **右カラム**：現在のセッションの設定パネル（プリセット、モデルパラメータ、正規表現など）

## できること

| やりたいこと | 方法 |
|---------|-------|
| 新しいセッションを作成 | 左カラムの新規作成をクリック |
| 過去のセッションに切り替え | 左カラムのセッションリストをクリック |
| キャラクターカードを読み込む | 左カラムでキャラクターカードを選択 |
| プリセットを切り替え | 右カラムのプリセット管理エリアで選択 |
| モデルパラメータを調整 | 右カラムのモデルパラメータパネル |
| メッセージを編集/再生成 | メッセージバブルの操作ボタン |
| Web 検索を有効化 | 対話中に手動トリガーまたは AI が自動トリガー |
| 正規表現プロセッサを設定 | 右カラムの正規表現ルールエリアで、個別のルールを有効化/無効化できます |
| INJ インジェクションを設定 | 右カラムの INJ 設定エリアで、自動注入するバックグラウンド情報を設定します |
| 対話履歴をエクスポート | セッション管理からエクスポート |

## バックエンドモード値

チャットモードはバックエンドモード値 `chat` に対応します。Bot 管理、Helper などの補助ビューも `chat` をバックエンドモード値として共用しますが、フロントエンドでは異なるインターフェースを表示します。
