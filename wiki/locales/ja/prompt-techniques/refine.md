# 精練と反復

プロンプトは長ければ良いわけではなく、一度書いて終わりでもありません。精練することで AI は重要なポイントをつかめるようになり、反復することでプロンプトはどんどん良くなっていきます。

## 無駄なプロンプトを減らす

### よくある「無駄」の3パターン

**1. 中英二言語の見出し**

```
悪い例：
## Writing Style / 写作风格
你的写作以白描为主......

## Character Voice / 角色语言
角色对话要自然......
```

中英二言語の見出しは AI の理解を助けません。トークンを無駄にするだけでなく、注意力も分散してしまいます。AI は純粋な日本語（または中国語）の見出しで十分理解できます。

```
良い例：
## 写作风格
你的写作以白描为主......

## 角色语言
角色对话要自然......
```

**2. 内容の一本化（同じ意味の繰り返し）**

```
悪い例：
对话要自然。角色之间的交流要像真实对话一样。
避免生硬的台词，让角色的语言贴近日常。
每个角色的说话方式都应该像真人一样自然。
```

この4文はすべて同じことを言っています。AI は4回言われたからといってそれを重視するわけではありません。むしろ繰り返しの内容が他の要点の重みを薄めてしまいます。

```
良い例：
角色对话使用口语化短句，允许打断、接话和跑题。
```

1文で十分です。しかも4文よりもずっと明確です。

**3. 直接例示の過剰**

```
悪い例：
比如角色A会说"今天天气真好啊"，角色B会回答"是啊，好想出去玩"，
然后角色A说"那我们去公园吧"，角色B说"好啊好啊"......
（長さ十数ターンの例示会話）
```

直接例示が多すぎると、AI が**過学習**を起こします——「対話の書き方」を学んだのではなく、「このように書くべき」と記憶してしまい、出力があなたの例示を繰り返すだけになってしまいます。

少量かつ厳選された例示だけが効果的です。（詳しくは「少数ショットプロンプティング」の章を参照してください。）

## 精練しつつ「許願」を避ける

### 「許願」とは何か

許願とは、「期待する最終的な効果」をそのままプロンプトの指針にしてしまうことです。

```
これは許願：
写出引人入胜的故事。
让读者沉浸其中。
创造令人难忘的角色。
```

これらの言葉は「良い小説」の特徴を描写しているだけで、AI には**どうすればそれができるか**がわかりません。「美味しく料理してください」と言うようなものです——必要なのはレシピであって、「美味しく」という言葉ではありません。

### 精練 ≠ 許願

精練とは無駄な言葉を削り、有効な指針だけを残すことです。許願とは方法を削り、願望だけを残すことです。

| 許願（無効） | 精練された有効な指針 |
|------------|--------------|
| 情景描写を生き生きとさせる | 具体的な感覚的細節で情景を構成する：温度・音・匂い |
| 対話をリアルで自然にする | 対話には口語調の短文を使い、遮りや話題の逸れを許容する |
| 奥行きのあるキャラクターを作る | 板挟みの状況でキャラクターの価値観の葛藤を見せる |
| 文章のテンポをコンパクトに保つ | 段落は3行以内、場景転換に繋ぎを加えない |

### 精練チェック法

プロンプトを書き終えたら、各項目を確認しましょう：

1. **この項目は AI の具体的な行動を指導できるか？** —— できる→残す；できない→書き直すか削除する
2. **この項目を削除すると AI のパフォーマンスが下がるか？** —— 下がる→残す；下がらない→削除する
3. **この項目は他の項目と重複していないか？** —— 重複している→1つにまとめる

## プロンプトの反復

良いプロンプトは書いて完成するものではなく、修正を重ねて完成するものです。

### A/B テスト

同じ場面で2バージョンのプロンプトをそれぞれ AI に生成させ、効果を比較します。

```
バージョン A：
以白描为主，避免比喻。

バージョン B：
以白描为主，减少比喻的使用频率。

同じ入力 → 2つのバージョンの出力を比較 → 効果の良い方を選択
```

変更は1回につき1箇所だけにしましょう。そうすることで、どの変更が効果をもたらしたかを判断できます。3箇所を同時に変更して効果が上がっても、どの変更が良かったのかわかりません。

### 問題の分解

AI のパフォーマンスが良くない場合、漠然と「効果が悪い」と言うのではなく、問題を具体的な側面に分解しましょう：

```
漠然とした表現：「AI の書く対話が良くない」

分解：
- 対話が長すぎる？ → 「キャラクターが1回に話す量は2文以内」を追加
- 対話が書き言葉すぎる？ → 「口語的な表現を使う」を追加
- キャラクターが区別できない？ → 各キャラクターに具体的な話し方の特徴を追加
- 対話が話を進めていない？ → 「対話の各ターンで1つの情報ポイントを進める」を追加
```

分解することで、それぞれの問題に対して具体的な解決策が生まれ、修正の効率が大幅に上がります。

### 失敗例の分析

AI が良くない内容を出力したとき、「良くない」と感じてすぐ再生成するだけにしてはいけません。**なぜ良くないのか**を分析しましょう：

1. **AI が実際に何を書いたかを見る** —— 具体的にどこがあなたの要求に合っていないか
2. **プロンプトと照らし合わせる** —— そのプロンプトはその側面をカバーしているか。カバーしていなければ追加し、カバーしているなら書き方を変える
3. **CoT を確認する**（ある場合）—— AI は分析フェーズであなたの要求をどのように理解していたか、解釈のズレはないか

### 反復サイクル

```
プロンプトを書く
    ↓
テスト（複数回生成し、全体的なパフォーマンスを確認）
    ↓
問題を発見（具体的な側面に分解）
    ↓
原因を分析（プロンプトがカバーしていない？カバーしているが書き方が悪い？）
    ↓
プロンプトを修正（1回につき1箇所）
    ↓
再テスト
    ↓
（満足するまで繰り返す）
```

## まとめ

- **無駄な内容を削る**：繰り返し・二言語・過剰な例示はすべてノイズです
- **精練は許願とは違う**：具体的な行動を指導できる指針を残し、結果だけを描写する願望を削る
- **反復することで良くなる**：A/B テスト・問題の分解・失敗の分析が、プロンプトを向上させる正しい方法です
