# env カスタム変数マクロ

プラグインが `extension.macro_env` を通じてカスタムキーバリューペアを注入し、それらのキーが自動的に使用可能なマクロになります。

## 仕組み

```
プラグインが extension.macro_env.my_key = "my_value" を設定
  -> マクロ環境に my_key が登場
  -> プリセットで {{my_key}} と書くと "my_value" に置換されます
```

これは**完全に動的**な仕組みです——プラグインはいつでも `macro_env` の値を更新でき、次回のマクロ置換時に新しい値が使用されます。

## 既存の env マクロ

以下は現在 always-accompany 公式プラグインが注入している env マクロです：

| マクロ | 注入元 | 説明 |
|----|----------|------|
| `{{workspace_root}}` | beilu-files | 現在のワークスペースのルートディレクトリパス |
| `{{workspace_tree}}` | beilu-files | 現在のワークスペースのディレクトリツリー構造 |
| `{{active_preset_name}}` | プリセットシステム（コア） | 現在アクティブなプリセットの名前 |
| `{{active_preset_description}}` | プリセットシステム（コア） | 現在アクティブなプリセットの紹介（description フィールド） |
| `{{work_sub_modes_list}}` | beilu-memory | ワークモードの全サブモード一覧（紹介付き）。ワークモード以外では空。動的コンテンツ——末尾エントリ `INJ-work-submodes-data` でのみ使用してください（「データ注入エントリとデータマクロ」ページを参照） |
| `{{code_sub_modes_list}}` | beilu-memory | コードモードの全サブモード一覧（紹介付き）。コードモード以外では空。動的コンテンツ——末尾エントリ `INJ-code-submodes-data` でのみ使用してください |
| `{{current_mode}}` | beilu-memory | 現在アクティブなモード（chat/code/work など） |
| `{{active_project}}` | beilu-memory | 現在アクティブなプロジェクト名 |
| `{{browser_status}}` | beilu-browser | ブラウザ接続ステータス（connected / disconnected）。動的コンテンツ——末尾エントリ `INJ-browser-status-data` でのみ使用してください（0722 に INJ-browser 頭部から分離） |
| `{{browser_port}}` | beilu-browser | Chrome CDP デバッグポート番号（ステータス行と一緒に末尾エントリで扱われます） |

> **動的マクロ配置の鉄則**：毎ターンまたは頻繁に変化するマクロ（状態・一覧・データ類）は頭部（`depth >= 1`）エントリのテンプレートで使用禁止——頭部の1文字変化でプロンプトキャッシュプレフィックス全体が無効化されます。動的マクロは必ず末尾の `*-data` エントリに配置してください。詳細は「データ注入エントリとデータマクロ」ページを参照。

### {{workspace_root}}

beilu-files プラグインが注入します。値は現在のファイルワークスペースのルートディレクトリパスです。コードモードで、AI はこのマクロを通じてプロジェクトの場所を知ることができます。

### {{workspace_tree}}

beilu-files プラグインが注入します。値は現在のワークスペースのディレクトリツリーのテキスト表現です。AI がプロジェクトのファイル構造を把握でき、ファイルを1つずつ列挙する必要がなくなります。

### {{active_preset_name}} と {{active_preset_description}}

プリセットシステムがプロンプト組み立て時にマウントします（そのターンで実際に使用されるプリセットエンジンと同一ソース）。現在アクティブなプリセットの名前と紹介にそれぞれ置換されます。

主な用途はプリセット思考スケルトン（beilu_think）の**アイデンティティ自己チェック**です：

```
当前任务身份={{active_preset_name}}
!!!现在的需要做的事情是否是我的身份范围!!!:{{active_preset_name}}—{{active_preset_description}}
```

AI は毎ターン返信前に、実際のプリセットの身元と紹介を使って現在の作業が身分の範囲内かを照合します。空欄を感覚で埋めることはなくなります。プリセットの紹介はプリセット管理画面で編集でき、編集後はマクロの値が即座に追従します。

### {{work_sub_modes_list}} と {{code_sub_modes_list}}

beilu-memory がエクスポートします。対応するモードの全サブモードのリアルタイム一覧に置換され、各行は `- id: 名前 — 紹介` の形式です。それぞれ自分のモードがアクティブなときだけ内容を持ち（work マクロはワークモード、code マクロはコードモード）、それ以外では空文字列に置換されるため、2つのマクロを並べて書いても干渉しません：

```
当前身份的工作是否符合现在的身份:{{work_sub_modes_list}}{{code_sub_modes_list}}
```

一覧はサブモード設定のライブデータ由来です——プリセットではマクロを参照すれば十分で、サブモード一覧を手書きする必要はありません（手書き一覧は設定変更に伴いずれていきます）。

## プラグインからカスタムマクロを注入する方法

プラグイン開発者の場合、カスタムマクロを注入するにはプラグイン内で `extension.macro_env` を設定します：

```
extension.macro_env = {
    my_custom_key: "値はマクロ置換時に挿入されます",
    another_key: dynamicValue
};
```

設定後、プリセットやキャラクターカードで `{{my_custom_key}}` と `{{another_key}}` が使用できるようになります。

### ポイント

- **キー名がそのままマクロ名**：`macro_env` のキーが直接 `{{キー名}}` マクロに対応します
- **値は動的に更新可能**：プラグインは実行時に `macro_env` の値を更新でき、次回のマクロ置換で自動的に反映されます
- **複数プラグインのマージ**：複数プラグインの `macro_env` は同一のマクロ環境にマージされます
- **バックエンド置換**：env マクロはバックエンドのマクロエンジン（evaluateMacros）段階で置換されます

## 実行リンク

```
各プラグインが初期化時または実行時に extension.macro_env を設定
  -> ユーザーがメッセージを送信
  -> バックエンドがプロンプトを組み立て
  -> TweakPrompt Round1: buildMacroEnvFromPromptStruct
     すべてのプラグインの macro_env をマクロ環境にマージ
  -> Round2: PresetEngine.buildAllEntries -> evaluateMacros
     {{key}} に遭遇するとマクロ環境から検索して置換
  -> 置換後のプロンプトが AI に送信されます
```

## 他のマクロとの関係

| 比較項目 | env マクロ | 組み込みマクロ（例：{{user}}） | 変数マクロ（例：{{getvar::x}}） |
|----------|--------|----------------------|--------------------------|
| 定義方法 | プラグインが macro_env を通じて注入 | マクロエンジンにハードコード | ユーザーが setvar で設定 |
| 値の出所 | プラグインが実行時に計算 | システム状態（ユーザー名など） | macroMemory に保存 |
| 拡張性 | 任意に拡張可能 | 固定セット | 任意のキー名 |
| 永続性 | プラグインのライフサイクル内で有効 | 常に有効 | プリセットに永続化 |
| 適用場面 | プラグインが AI にデータを公開 | 基本情報のプレースホルダー | 会話状態の追跡 |

## 注意事項

- env マクロはバックエンドの置換段階でのみ機能し、フロントエンドでは処理されません
- 複数のプラグインが同名のマクロを注入した場合、後から注入されたものが先のものを上書きします
- env マクロの値は文字列、または文字列に変換される値が使用できます
- プラグインのアンインストールまたは無効化後、そのプラグインが注入した env マクロは使用不可となり、対応する `{{マクロ名}}` はそのまま置換されずに残ります
