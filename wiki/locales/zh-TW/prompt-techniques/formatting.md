# 格式與符號運用

提示詞的格式——標題層級、符號標記、視覺分隔——影響 AI 對內容的解讀權重。合理的格式讓重點突出、層次清晰；過度的格式則會適得其反。

## 核心原則：適度

格式符號不是越多越好。過多的加粗、標題、分隔線會形成「飽和式打擊」——當所有東西都在強調時，等於什麼都沒有強調。

```
錯誤（飽和式打擊）：
────────────────
# **重要規則**
## *寫作風格*
### ⚠️ 注意事項
- **必須** 使用 **白描**
- **必須** 保持 **節奏**
- **絕對不要** 使用 ~~比喻~~
---
## **角色設定**
### ⚡ 核心特徵
> ⚠️ **重要**：角色 **必須** 保持 **一致性**

→ 到處都是加粗、標題、符號、分隔線，
  AI 分不清什麼才是真正重要的。
```

```
正確（適度使用）：
────────────────
# 寫作風格
以白描為主，保持節奏明快。

# 角色設定
角色在不同場景中保持**核心性格**一致，
但允許情緒和表達方式隨場景變化。

→ 只有「核心性格」被加粗，
  因為這是這段話中最關鍵的概念。
```

## 標題層級

### 只用一級標題

在提示詞中，建議只使用 `#` 一級標題來劃分模組。過多的層級（`##` `###`）會讓結構變得複雜，AI 需要額外精力來解析層級關係，反而分散了對內容本身的注意力。

```
錯誤（層級過多）：
# 寫作指南
## 風格
### 敘事
#### 節奏
##### 對話節奏
段落不超過三行。

正確（扁平結構）：
# 敘事節奏
段落不超過三行，對話用口語短句。
```

如果內容確實需要細分，用段落自然分隔就夠了，不需要每一層都加標題。

## 強調標記的使用

### 引號和加粗

用 `""` 或 `**` 包裹**真正重要**的內容。什麼算真正重要？如果 AI 忽略了這個詞/這句話，整個輸出的方向就會偏——那它就值得被強調。

```
有效的強調：
角色的行為必須符合**目前情緒狀態**，而非人設的預設性格。

→ 「目前情緒狀態」是這句話的關鍵區分點，
   不強調的話 AI 可能預設用人設性格來驅動行為。
```

```
無效的強調：
**角色**的**行為**必須**符合**目前**情緒狀態**。

→ 什麼都加粗 = 什麼都沒加粗。
```

### 使用建議

| 符號 | 用途 | 頻率 |
|------|------|------|
| `#` | 模組分隔 | 每個主題模組一個 |
| `**加粗**` | 關鍵概念強調 | 一段話最多 1-2 處 |
| `""引號` | 專有名詞或特定表述 | 需要精確引用時 |
| `---` 分隔線 | 大模組之間的視覺分隔 | 偶爾使用 |
| `> 引用區塊` | 補充說明或注意事項 | 偶爾使用 |

## 常見格式問題

### 清單濫用

不是所有內容都需要清單化。當內容之間有邏輯關係（先後、因果）時，用自然語言段落更好。

```
不合適的清單：
- 先分析角色目前的情緒
- 然後考慮角色會做什麼反應
- 最後寫出角色的動作和對話

更好的寫法：
從角色目前的情緒出發，推演角色的反應，
再透過動作和對話表現出來。
```

清單適合並列的、獨立的條目，比如：
- 多個角色的特徵分別列出
- 幾條互不相關的注意事項
- 清單式的格式要求

### 過度巢狀

```
錯誤：
- 角色特徵
  - 性格
    - 核心性格
      - 沉穩
    - 次要性格
      - 偶爾幽默
  - 說話方式
    - 口癖
      - 「嘛」
    - 句式
      - 短句為主

正確：
角色性格沉穩，偶爾流露幽默。
說話時帶「嘛」作為口癖，以短句為主。
```

深度巢狀的清單在提示詞中幾乎沒有正面作用。AI 不會因為你的結構更「完整」就表現更好——它需要的是清晰的資訊，不是精美的大綱。

## 小結

- **少即是多**：符號和格式只在真正需要強調時使用
- **扁平優於層級**：一級標題分模組，段落分細節，不需要層層巢狀
- **強調要精準**：一段話中只強調最關鍵的 1-2 個概念
- **自然語言優先**：有邏輯關係的內容用段落表達，並列獨立的條目才用清單
