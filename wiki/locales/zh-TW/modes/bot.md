# Bot 模式

管理 AI 角色在多個外部平台（Discord、Telegram、LINE 等）上的自動執行和訊息回覆。

## 進入方式

透過輔助功能表進入 Bot 管理檢視。

## 介面佈局

### 活動欄按鈕（3 個）

| 按鈕 | 名稱 | 開啟的面板 |
|------|------|-----------|
| list | Bot 列表 | 所有 Bot 實例的設定與管理 |
| log | 日誌 | Bot 執行日誌 |
| monitor | 監控 | Bot 執行狀態即時監控 |

## 核心功能

### 多平台設定

Bot 列表面板頂部有 10 個平台 Tab，點擊切換到對應平台的設定區：

| 平台 | 需要填寫的憑證欄位 |
|------|-------------------|
| Discord | Bot Token、Application ID |
| Telegram | Bot Token |
| Slack | Bot Token、App Token、Signing Secret |
| LINE | Channel Access Token、Channel Secret |
| X (Twitter) | API Key、API Secret、Access Token、Access Secret、Bearer Token |
| 飛書 | App ID、App Secret |
| 釘釘 | App Key、App Secret |
| 企微 | Corp ID、Agent ID、Secret |
| 微信 | App ID、App Secret |

每個平台填寫對應憑證後即可上線執行。

**操作按鈕**：
- 儲存 —— 儲存目前平台的憑證設定
- 啟動 —— 啟動 Bot 開始監聽訊息
- 停止 —— 停止 Bot 執行
- 查看監控 —— 跳轉到 monitor 面板查看執行狀態

### C6 觸發規則

設定 Bot 對誰的訊息做出回覆：

| 選項 | 說明 |
|------|------|
| 所有人 | 任何人傳送的訊息都觸發回覆 |
| 僅主使用者 | 只回應主使用者的訊息 |
| 主使用者 + 白名單 | 回應主使用者和白名單中指定使用者的訊息 |

### 權限分檔（L0 - L3）

| 等級 | 說明 |
|------|------|
| L0 | 最低權限，僅基礎對話 |
| L1 | 基礎權限，可使用部分功能 |
| L2 | 進階權限，可使用大部分功能 |
| L3 | 最高權限，完整功能存取 |

不同使用者/角色可分配不同權限等級，控制其可觸發的 Bot 能力範圍。

### 角色卡兩層管理

Bot 模式對角色卡採用兩層結構：

**外層 —— 視窗模式分類**：角色卡按 always-accompany 的視窗模式分組展示：
- chat —— 聊天模式的角色卡
- code —— 程式碼模式的角色卡
- work —— 工作模式的角色卡

**內層 —— 角色卡實例**：每個角色卡實例包含：
- 永久連結 —— Bot 與角色卡的綁定關係持久化，重啟後自動恢復
- 對話列表 —— 該角色卡下的所有對話
- 任務清單 —— 該角色卡關聯的任務

為不同平台/頻道綁定不同角色卡，每個角色保持獨立的人格設定和對話上下文。

## 後端模式值

Bot 管理檢視的前端 Tab 為 `bot`，對應後端模式值 `chat`（複用聊天模式的後端邏輯）。

## 使用建議

- **單平台起步**：先設定一個平台驗證效果，再擴展到多平台
- **權限控制**：正式環境中建議設定觸發白名單和權限分檔，避免濫用
- **角色差異化**：為不同平台/情境設定不同角色卡，讓 AI 表現符合該平台的風格
