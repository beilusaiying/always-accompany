# インターフェースレイアウト

## 3 カラム構成

| エリア | 内容 |
|------|------|
| 左カラム | キャラクター情報 / プリセット選択 / ワールドブック / モデルパラメータ（モードにより内容が異なる） |
| 中央 | 会話メッセージフロー |
| 右カラム | ランタイムスイッチ / タスクボード（折りたたみ可） |
| 上部 | モードセレクタ（4 つのメインモード） |
| 下部 | 入力欄 |

左右カラムはドラッグで幅を調整でき、折りたたんで非表示にすることも可能です。IDE / ワークモードではレイアウトがアクティビティバー + サイドバー形式に変わります。

## モード切り替え

上部の 4 つのボタン（Ctrl+1~4）でメインモードを切り替えます。「···」をクリックすると補助ビュー（Bot 管理 / ゲームコンパニオン / 記憶管理 / ST 互換）に入ります。

## よく使う操作

| 操作 | 方法 |
|------|------|
| メッセージ送信 | Enter |
| 改行（送信しない） | Shift + Enter |
| 再生成 | メッセージ下のボタン |
| メッセージ編集 | メッセージ内容をクリック |
| メッセージ削除 | 右クリック → 削除 |
| 新しい会話 | 拡張メニュー → 新しい会話 |
| キャラクター切り替え | 左サイドバーで別のキャラクターカードをクリック |
