# スクリーン感知 (beilu-eye)

beilu-eye は 2 つの独立した機能を提供します：

1. **デスクトップスクリーンショット感知**：自動的に画面内容をキャプチャし、AI があなたが何をしているかを「見る」ことができます
2. **Electron デスクトップペット**：デスクトップ上に AI キャラクターの仮想イメージを表示します

## デスクトップスクリーンショット感知

### 動作原理

beilu-eye はバックグラウンドで Python スクリプトを使って定期的にデスクトップ画面をキャプチャします：

```
Python スクリプトが画面をキャプチャ
    ↓
HTTP POST で always-accompany バックエンドにスクリーンショットを送信
    ↓
バックエンドが一時インジェクション状態（injection_state）に保存
    ↓
フロントエンドがポーリングで新しいスクリーンショットを検出
    ↓
ファイル添付としてメッセージと一緒に AI に送信
    ↓
AI がスクリーンショットを見てフィードバックを提供
    ↓
スクリーンショットは自動的にクリアされ、後続のコンテキストには残らない
```

### 特徴

- **ワンショットインジェクション**：スクリーンショットは AI が一度見た後に自動クリアされ、後続の会話のコンテキストスペースを占有しません
- **オンデマンドトリガー**：スクリーンショットは毎ターン送信されるのではなく、新しいスクリーンショットがある時のみインジェクションされます
- **トークン認証**：Python スクリプトとバックエンド間は pet-token トークンで認証し、未認可のインジェクションを防止します

### 使用シーン

| シーン | 説明 |
|------|------|
| プログラミング支援 | AI が IDE の画面を見て、現在のコードコンテキストを把握 |
| ゲームコンパニオン | AI がゲーム画面を見て、リアルタイムの攻略アドバイスを提供 |
| 学習指導 | AI が操作画面を見て、適時に修正やガイダンスを提供 |
| 業務アシスト | AI が処理中のドキュメント/表計算を確認 |

## Electron デスクトップペット

### 機能

デスクトップペットはデスクトップ上にフローティング表示される AI キャラクターの仮想イメージウィンドウです。ブラウザとは独立して動作し、常にデスクトップに表示されます。

### 有効化方法

設定センターでデスクトップペットオプションを見つけ、有効化をクリックします。always-accompany が自動的に Electron デスクトップペットプロセスを起動します。

### プロセス管理

デスクトップペットプロセスは always-accompany バックエンドが一括管理します：

- **4 秒照合周期**：4 秒ごとにデスクトップペットのプロセス状態をチェック（reconcile）
- **自動再起動**：デスクトップペットプロセスが予期せず終了した場合、自動的に再起動
- **グレースフルデグラデーション**：Electron バイナリが存在しない場合（未インストール）、クラッシュせずにインストールを促すメッセージを表示

### 前提条件

デスクトップペット機能には Electron 依存関係のインストールが必要です。`desktop-eye` ディレクトリで `npm install` を実行してください。

## セキュリティメカニズム

### pet-token トークンゲート

Python スクリーンショットスクリプトがバックエンドにデータを送信する際、有効な pet-token を携帯する必要があります。このトークンはデスクトップペット/スクリーンショットプロセス起動時にバックエンドが生成し、プロセス終了時に取り消されます。未認可のリクエストはブロックされます。

### ブラック/ホワイトリスト

ウィンドウのブラック/ホワイトリストを設定して、AI がどのアプリケーションのスクリーンショットを見られるか、見られないかを制御できます。

## 設定項目

| 設定 | 説明 | デフォルト |
|------|------|------|
| スクリーンショット間隔 | Python スクリプトのスクリーンショット取得間隔 | 3 秒 |
| デスクトップペットスイッチ | Electron デスクトップペットを有効にするかどうか | オフ |
| ウィンドウブラックリスト | キャプチャしないウィンドウのリスト | - |
| ウィンドウホワイトリスト | キャプチャ対象のウィンドウのみのリスト | - |
