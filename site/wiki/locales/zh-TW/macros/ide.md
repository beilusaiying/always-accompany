# IDE/程式碼巨集

[程式碼模式（IDE）](beilu:mode/files)下的專用巨集，為 AI 提供子模式資訊、程式碼檔案內容、工具描述和執行結果等程式碼上下文。在預設集引擎建構提示詞條目時替換。

## 模式資訊巨集

| 巨集 | 說明 | 範例輸出 |
|----|------|----------|
| `{{sub_mode}}` | 目前子模式的名稱 | `code_review` |
| `{{sub_mode_desc}}` | 目前子模式的描述 | `程式碼審查模式：分析程式碼品質...` |

程式碼模式下有多個[子模式](beilu:wiki/modes/submodes.md)（程式碼編寫、審查、偵錯等）。這兩個巨集告訴 AI 目前處於哪個子模式及其行為描述。

## 記憶與檔案巨集

| 巨集 | 說明 |
|----|------|
| `{{codeHotLayer}}` | 程式碼熱層記憶 |
| `{{code_file:檔名}}` | 引用指定的 md 檔案內容 |
| `{{code_files_list}}` | 目前活躍檔案列表 |

### {{codeHotLayer}}

程式碼模式專屬的熱層記憶，類似 `{{hotMemory}}`（見[記憶系統巨集](beilu:wiki/macros/memory.md)），專門儲存程式碼上下文（專案結構、技術棧、編碼規範等）。

### {{code_file:檔名}}

直接將指定的 markdown 檔案內容嵌入到提示詞中。用於向 AI 提供特定的參考文件、程式碼規範、專案說明等。

範例：
```
{{code_file:coding_guidelines}}
```
會讀取對應的 `coding_guidelines.md` 檔案內容並替換到此位置。

### {{code_files_list}}

列出目前程式碼會話中活躍的檔案清單。讓 AI 知道使用者正在處理哪些檔案。

## 工具與環境巨集

| 巨集 | 說明 |
|----|------|
| `{{client_env}}` | 用戶端環境資訊 |
| `{{ide_workspace}}` | IDE 工作區資訊 |

> 已退役：`{{ide_tools}}`（工具指令不再由程式碼產生——全部工具說明放在可編輯的注入條目裡，如 INJ-2 / INJ-2-code，可在記憶預設集面板直接編輯）；`{{ide_tool_results}}`（工具執行結果作為真實訊息進入對話尾部，不走巨集通道）。條目裡殘留的這兩個巨集會被替換為空。

### {{client_env}}

注入用戶端的環境資訊，如作業系統類型、瀏覽器資訊等。幫助 AI 給出與使用者環境相符的建議（如 Windows vs macOS 的路徑差異）。

### {{ide_workspace}}

注入目前 IDE 工作區的資訊，讓 AI 瞭解自己所處的工作區上下文。

## 執行鏈路

IDE 巨集在預設集引擎建構提示詞時被替換：

```
使用者在程式碼模式下傳送訊息
  -> 預設集引擎（PresetEngine）建構提示詞條目
  -> 讀取目前子模式設定
  -> 收集活躍檔案、環境資訊
  -> 替換 {{sub_mode}}、{{code_file:x}}、{{ide_workspace}} 等巨集
  -> 組裝完成的提示詞傳給 AI
```

## 注意事項

- IDE 巨集僅在程式碼模式下生效，在普通對話模式下這些巨集沒有資料來源
- `{{code_file:檔名}}` 引用的檔案需要在專案的指定目錄中存在
- IDE 巨集由預設集引擎在建構條目時替換，屬於後端巨集替換的一部分
- 工具指令與工具結果不走巨集：工具說明在可編輯注入條目（INJ-2 / INJ-2-code）中維護，執行結果作為真實訊息進入對話
