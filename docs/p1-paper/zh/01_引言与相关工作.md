# P1: 一种 LLM-Free 的认知前置发散召回引擎

# 第一章 引言

> 本章界定"认知前置发散"问题——LLM 架构层面缺乏生成前的多维探索能力——并说明现有方案（RAG、纯 LLM 发散、向量搜索）为何都无法填补这一空白。在此基础上给出 P1 的系统定位、CDC 三段处理骨架与本文的五项核心贡献，为后续章节的技术细节铺垫问题背景。

## 1.1 问题定义

当前大语言模型（Large Language Model, LLM）在对话系统中的典型工作流程是：接收用户输入后，直接进入自回归生成过程，逐 token 产出回复。

这一过程的核心机制——自注意力（Self-Attention）——本质上是竞争性归一化：softmax 函数将注意力分数压缩为概率分布，使模型倾向于聚焦已有上下文中最显著的信号，逐步收敛至高概率输出序列。

换言之，LLM 的注意力机制在架构层面持续向高概率输出收敛，缺乏在生成前主动探索多维可能性空间的能力。

这一缺陷在实际对话中表现为：当用户发送一条包含多重情感层次、跨领域暗示或模糊意图的消息时，LLM 倾向于锁定最显著的单一解读方向并直接回应，而非先在心理学、社会学、语言学等多个维度上发散性地探索该消息可能触及的知识领域，再据此生成更具深度和广度的回复。

针对这一缺陷，系统设计确立了一个与主流扩展路线（更长上下文、多模态）正交的问题定位：当前 LLM 研究着力扩大注意力的覆盖范围，却未触及注意力的发散能力问题。P1 的设计选择是职责拆分——将"从数万至数十万 token 的全局上下文收拢至一个焦点"的注意力模式，转变为"从一个语义点出发进行受控发散"的局部探索模式。这一将发散过程从生成过程中显式分离、外置为独立环节的立场，与 LLM 创造力研究中以外部脚手架分离发散与收敛的思路（Scaffolding Creativity, arXiv:2510.26490）以及发散能力与模型通用智能不相关的实证发现（Orwig, 2025）相互印证。

本文将这一尚未被系统性解决的问题定义为**认知前置发散**（Pre-Cognitive Divergence）：在 LLM 生成回复之前，以低延迟（设计验收标准 ≤3s；当前实现热调用实测 300-500ms，冷加载约 9s）、零 token 消耗的方式，完成对用户输入的多维度语义发散探索，并将发散结果以"方向词"（Direction Words，涵盖专业术语、作品/桥段引用与片段词三类，见 1.3 节）的形式注入 LLM 的上下文，使其在生成前即获得一组候选认知方向，而非在没有任何方向信息的条件下开始生成。

## 1.2 现有方案的局限性

### 1.2.1 检索增强生成（RAG）只做检索不做发散

RAG（Retrieval-Augmented Generation）(Lewis et al., 2020) 的核心范式是"检索-拼接-生成"：根据用户查询从外部语料库中检索相关段落，将其拼接入 LLM 上下文后生成回复。这一范式解决的是 LLM 知识截止和事实准确性问题，其检索目标是**精确匹配**——找到与查询语义最近的文档片段。

然而，认知前置发散所需的不是精确匹配，而是**有控制的语义偏移**：从用户输入出发，沿多条学科轴（心理学、信息学、社会学、逻辑学、语言学）向中等语义距离处探索，发现用户未明说但可能相关的概念关联。

RAG 的向量检索追求 cosine similarity 最大化，而 P1 追求的是一个最优语义距离区间（对应 Mednick 远距联想理论文献中的 Goldilocks 效应，见 2.13 节）——既非同义冗余（距离过近），亦非随机噪声（距离过远）的倒 U 型最优区间。二者目标函数根本不同。

此外，RAG 在检索阶段不产生新的语义关联——它只能找到语料库中已存在的段落，不能通过联想网络和跨域类比生成语料库中未显式存在的概念连接。

P1 的核心价值恰恰在于这种**涌现性的语义桥接**：通过 SWOW 联想词网的扩散激活、词林类比的跨域结构映射、以及 Numberbatch 向量空间中的方向性移动，产出用户原文中不存在、LLM 裸读也难以自行推出的跨学科方向词。

### 1.2.2 纯 LLM 方案无法实现 LLM-Free 的认知前置

另一类方案试图通过 LLM 自身来实现发散思维，例如 Chain-of-Thought (Wei et al., 2022)、Tree-of-Thoughts (Yao et al., 2023)、以及各种创造力增强提示技术 (CreativeDC, arXiv:2512.23601; Scaffolding Creativity, arXiv:2510.26490)。这些方案的共同局限在于：

**成本问题**：每次发散均消耗 LLM 的 token 预算。对于需要实时响应的对话系统，在用户每条消息前额外调用一次 LLM 进行发散探索，意味着延迟翻倍和 API 成本的线性增长。研究表明，LLM 的发散能力与其通用智能分数并不相关 (Orwig, 2025)——投入更多算力并不能解决发散问题。

**黑盒问题**：LLM 内部的发散过程不可观测、不可调试、不可分步干预。当输出方向偏移时，无法定位是哪个环节出错。P1 采用全白盒设计，每个节点的输入、处理、输出均可在线观测。

**可控性问题**：LLM 的发散结果不可预测——同一输入在不同温度采样下可能产出完全不同的方向，且无法保证覆盖预设的多学科维度。P1 通过六轴面发散的确定性框架，保证每次运行对心理学、信息学、社会学、逻辑学、语言学等维度均有系统性覆盖。

### 1.2.3 向量搜索无法实现多维度空间投票

基于词嵌入的语义搜索（如 Word2Vec 余弦相似度检索）虽然可以找到语义相近的词汇，但它在单一向量空间中操作，无法实现 P1 所需的**多源多轴空间投票**机制。

P1 的空间相加投票（Spatial Additive Voting）将来自 SWOW 联想、Numberbatch 向量邻居、词林类比、ConceptNet 因果链等多条异质路径的候选词汇汇入同一空间，以反距离加权（Inverse Distance Weighting, IDW）进行加性累加投票。

这种机制的核心洞见是：当多个独立信息源（如心理学轴、社会学轴、语言学轴）同时指向同一候选词时，该词大概率具有跨学科共振价值——这正是 Condorcet 陪审团定理（多个独立投票者的正确率随投票者数量指数增长）在语义发散领域的应用。单一向量空间的 KNN 搜索无法实现这种多源投票机制。

## 1.3 P1 的定位

P1 是一个**认知前置发散引擎**（Pre-Cognitive Divergence Engine），其当前生产线路（线路 1）为 **LLM-Free 基线**。它不是 RAG（不做精确检索，做有控制的语义发散）、不是 LLM Agent（线路 1 不调用大语言模型，全程零 token）、不是检索增强（不拼接外部文档，输出的是方向词种子）。其系统定位是：P1 承担主模型生成前的"感知前端"职能——如同视觉系统为下游认知提供已完成初步组织的场景表征，P1 为主 LLM 提供一张已标注候选认知方向的语义地图，使生成从"具备方向先验的探索"而非"零方向的白纸状态"开始。这一定位在认知科学上对应特征整合理论中先于注意、并行完成的预处理阶段（Treisman & Gelade, 1980），在提示工程上与方向性刺激提示的实证结果一致——生成前注入方向性信号可显著改变并提升 LLM 输出质量（DSP, NeurIPS 2023）。

在三层职责分工中，P1 负责生成前的语义定位与发散——提取输入的语义特征、产出多维关联方向；主 LLM 负责基于 P1 提供的方向词进行推理与回复生成；协作分身负责执行具体的搜索和验证任务。P1 的核心价值不在于替代 LLM 的理解能力，而在于弥补 LLM 在架构层面的收拢偏差——通过外置的发散节点，为 LLM 注入它自身难以主动激活的跨学科认知方向。

P1 本身是**双引擎设计**：自驱动 P1（主力，前置运行，免费且快速，负责回收与发散）与 AIP1（可选保底，由用户自选 LLM 在自驱动结果基础上接续深化，一般使用 gemini2.5flash）。设计者对二者关系的定义是：自驱动引擎负责内容发现，AIP1 在其结果基础上接续深化而非替换。本文的技术描述聚焦自驱动 P1。

需要说明的是，LLM-Free 是当前生产线路的特性，而非设计终态。设计中的 LLM 标注层作为规划组件包括：H5 QKV LoRA（LLM 仅负责 QKV 理解与方向标注，不输出任何创造性内容，H1-H4 仍由系统层承担）、Qwen3.5:2B 前置定位（以小模型替代部分词表判断）、双 LoRA 200 case 对比实验，以及三线路架构——线路 1 无 LLM（本文描述的生产基线，完整度约 90%）、线路 2 LLM 位于 SWOW 前、线路 3 LLM 位于 SWOW 后、线路 C 双位置。线路 2/3/C 已在 lab 完整实装，尚未合入主线。设计原则是：系统组件与 AI 的分工组合为最优解，而非以 AI 替代系统组件。

P1 的总体处理骨架为**收拢-发散-收拢**（Contraction-Divergence-Contraction, CDC）三段机制：

1. **收拢一（Phase A）**：从用户输入和历史对话中提取语义坐标，通过记忆召回构建发散锚点（其中数据层记忆召回目前默认关闭待验证，生产环境默认仅开启上下文召回）；
2. **发散（Phase B）**：以锚点为基础，通过 SWOW 联想网络、Numberbatch 向量空间、词林类比、ConceptNet 因果链等多条路径进行并行发散；
3. **收拢二（Phase T）**：通过 BLQ（Beilu Linqing Quality）多因子投票排序，将数百个发散候选分层收拢——核心层 4-5 个高质量方向词（对应工作记忆容量论证，见 2.12 节）与擦边层 top15 候选（对应低门槛大面积语义触达设计，见 2.12 节）——注入主 LLM 上下文。方向词在类型上分为三类：专业术语（chat/work 模式主力）、作品/桥段引用（airp 模式主力）与片段词，对应设计对收拢二的职能定义：提取词汇性质并转换为专业术语、作品引用或片段词。

整个过程的设计验收标准为 ≤3s（热调用实测 300-500ms，冷加载约 9s），消耗零 LLM token，输出完全可观测。

## 1.4 核心贡献

本文的主要贡献如下：

1. **提出认知前置发散问题并给出系统性解决方案（当前生产线路为 LLM-Free 基线）**。我们指出 LLM 在架构层面缺乏生成前的发散探索能力，并设计了一个零 token 消耗（线路 1）、低延迟（设计验收标准 ≤3s，热调用实测 300-500ms）、全白盒可观测的外置发散引擎，在不增加 LLM 调用成本的前提下显著提升对话系统的多维度认知覆盖。

2. **设计并实现了"收拢-发散-收拢"（CDC）三段式认知处理管线**。该管线融合了扩散激活理论（Collins & Loftus, 1975）、结构映射理论（Gentner, 1983）、信息瓶颈理论（Tishby, 1999）等多学科理论，将人类认知中的"先收拢锚点、再发散联想、再收拢为行动"的思维节奏形式化为可计算的十二阶段流水线。

3. **提出空间相加投票机制与 BLQ 多因子排序算法**。将 Hough 变换的多对一投票范式从计算机视觉迁移到 NLP 方向词生成，并借鉴 RRF（Reciprocal Rank Fusion）、侧抑制（Lateral Inhibition）、MMR（Maximal Marginal Relevance）等经典信息检索技术的设计思想（各机制的落地状态见第二章逐项标注），实现了从数百个发散候选到"核心层 4-5 个 + 擦边层 top15"方向词的分层鲁棒收拢。

4. **建立了方向词质量的形式化评估框架**。提出"废词"（主模型裸读原文即可推出的词，价值为零）、"万金油"（在 80%+ 场景中均被激活的泛化词）等原创质量判据，并设计了五维度评分体系（上下文联系、方向与路线区分、方向词质量、多头捕捉、类比发散）用于系统性评估发散输出质量。

5. **开源了完整系统实现和 55GB 多语言认知资源库**。包括 SWOW-ZH24（10,024 cue 词）、ConceptNet Numberbatch（294,716 中文词 + 344K 英文词，300 维）、ConceptNet 倒排索引（260,236 词，453,956 边）、NRC-VAD v2（54,801 词）、DomainWordsDict（561,000 词 69 域）等 14 个已接入资源和 42+ 个可接入资源。

# 第二章 相关工作

> 本章横跨认知科学、自然语言处理与信息检索三大领域，逐节回顾扩散激活、RAG、记忆增强 LLM、认知架构、词嵌入等 14 个与 P1 密切相关的研究方向。这些工作共同构成 P1 设计选择的理论参照——理解它们的边界，才能理解 P1"认知前置发散"这一定位为何尚未被现有研究覆盖。各节遵循相近的结构：先介绍相关理论/方法，再说明 P1 与其的联系与区别。

P1 系统的设计横跨认知科学、自然语言处理与信息检索多个领域。本章按相关性从高到低的顺序，回顾与 P1 最密切相关的研究方向，并阐明 P1 与各方向的联系与区别。

## 2.1 扩散激活理论

Collins 与 Loftus (1975) 提出的扩散激活理论（Spreading Activation Theory）是 P1 发散机制的首要理论基础。该理论认为人类语义记忆以网络形式组织：概念作为节点、语义关系作为边，当某个概念被激活时，激活信号沿连接边向相邻概念传播，且随传播距离指数衰减。

这一理论解释了语义启动效应（Semantic Priming Effect）——先呈现"医生"会加速对"护士"的识别（Meyer & Schvaneveldt, 1971）。

P1 的核心发散机制直接基于扩散激活模型：以分词后的有意义词为种子节点，在 SWOW 联想网络中进行激活扩散，激活强度按距离递减（distance=0 原词 1.0 / distance=1 直接联想 0.6 / distance=2 间接联想 0.3），每次扩散产出约 120-150 个激活节点。然而，P1 在三个方面超越了经典的扩散激活模型：

**第一，P1 采用信息池发散而非逐词发散。** 经典扩散激活从单个种子节点出发，P1 则将所有种子词的激活结果汇入同一信息池，在池的整体语义空间中寻找共振点。这一设计源自一条设计红线：禁止逐词独立发散后再对发散结果简单求和——该操作会产生大量万金油词（在多数场景中均被激活的泛化词），其机理与扇出效应（Fan Effect, Anderson, 1974）同源：高连接度联想节点被多个种子词重复激活，泛化词因此在求和中系统性胜出。

**第二，P1 在扩散激活之上叠加了多轴空间投票。** 扩散激活产出的散词池被投射到六条学科轴（心理学、信息学、社会学、逻辑学、语言学、认知学）上，各轴独立评分后汇入空间相加投票，使得最终方向词的选取基于多个独立维度的交叉验证而非单一联想链。

**第三，P1 引入了两次发散架构。** 第一次发散（SWOW 联想网络）产出散词池，经空间投票收窄后，进行第二次发散（跨域关联、归因链、类比映射等路径）产出信息词，最后通过 Hough 式多对一投票收拢为方向词。这种异质两跳结构在扩散激活文献中未有先例。

近年来，扩散激活理论在 NLP 中的应用重新受到关注。SYNAPSE (arXiv:2601.02744, 2025) 将扩散激活与侧抑制结合用于知识图谱检索。SA-RAG (Pavlovic et al., arXiv:2512.15922, 2025) 将 SWOW 联想数据作为 RAG 系统的扩散层，采用加性累积机制。

P1 与这些工作共享扩散激活的理论基础，但在系统定位上根本不同：SYNAPSE 和 SA-RAG 仍服务于精确检索目标，而 P1 的目标是有控制的语义发散——找到超出直接联想范围、且每一步关联均有可追溯依据的跨域方向词。

## 2.2 检索增强生成（RAG）

检索增强生成（Retrieval-Augmented Generation）自 Lewis et al. (2020) 提出以来，已成为缓解 LLM 幻觉和知识截止问题的主流范式。标准 RAG 流程包含：查询编码、向量检索、段落拼接、生成回复。

后续工作在检索质量 (Gao et al., 2023 HyDE; Gutierrez et al., 2024 HippoRAG)、上下文压缩 (LLMLingua-2, ICLR 2025)、多跳推理 (GRF, Ji et al., EMNLP 2020) 等方面持续改进。

P1 与 RAG 在系统目标、检索策略和输出形式三个层面存在根本差异：

**系统目标**：RAG 的目标是为 LLM 提供事实性知识（"这个问题的答案是什么"），P1 的目标是为 LLM 提供认知方向（"这个问题可以从哪些角度思考"）。前者追求精确匹配，后者追求有控制的语义偏移。

**检索策略**：RAG 采用高门槛精确召回（cosine similarity 排序取 Top-K），P1 采用低门槛大量擦边召回（"宁滥勿缺"）。P1 的记忆召回不追求高精度，而是为下游发散提供尽可能广泛的锚点。这与 HippoRAG (Gutierrez et al., NeurIPS 2024) 的 Personalized PageRank 随机游走检索有概念层面的相似性，但 HippoRAG 的 PPR 仍服务于精确检索目标。

**输出形式**：RAG 输出的是自然语言段落（供 LLM 直接参考的外部知识），P1 输出的是极简方向词（核心层 4-5 个 + 擦边层 top15，以少量词项为主 LLM 激活更大范围的相关知识模块；类型涵盖专业术语、作品/桥段引用与片段词三类，见 1.3 节）。Cognitive Priming in LLMs (arXiv:2409.16022) 的实验表明，LLM 确实受语义启动效应影响——这为 P1 方向词对主 LLM 的 prime 效果提供了机制层面的间接支持（P1 自身的注入对照实验尚未开展）。

值得特别提及的是 Cog-RAG (AAAI, 2026) 和 EcphoryRAG (arXiv:2510.08958, 2025)。前者引入认知双超图进行两阶段检索，后者借鉴记忆的 ecphory 机制实现线索驱动的多跳关联搜索。这些工作开始将认知科学理论引入检索系统设计，与 P1 借鉴认知科学机制的设计思路有交叉之处，但它们仍定位于检索增强而非认知发散。

## 2.3 记忆增强大语言模型

MemGPT (Packer et al., 2023) 开创了为 LLM 添加显式记忆管理的方向，通过虚拟分页机制使 LLM 能在有限上下文窗口内管理无限量的历史信息。后续工作如 ReadAgent (Lee et al., 2024)、MemoryBank (Zhong et al., 2024) 等进一步发展了长期记忆的存储、索引和召回策略。

P1 所依附的 beilu 记忆体系采用热/温/冷三层架构（Hot/Warm/Cold Three-Layer Memory）：热层存放永久记忆和用户画像，每轮全量注入（工作记忆）；温层覆盖近一月的对话总结，按需召回（近期情节记忆）；冷层存放超月的老记忆，仅关键词触发（长期语义记忆）。衰减公式 `score = weight * 1/(1+days*0.1)` 模拟遗忘曲线，复习强化机制（被真实注入命中的条目刷新触发时间）实现间隔重复。该记忆体系属于 beilu 本体侧，而非 P1 的子系统——P1 仅通过擦边发散线消费其中的擦边召回。

该记忆体系与 MemGPT 等方案的核心区别在于：MemGPT 的记忆管理服务于上下文窗口的高效利用（让 LLM 能"记住"更多），而 P1 消费记忆召回的目的是发散锚点的构建（让发散有"起点"）。beilu 记忆体系设计了双线召回机制（Dual-Line Recall）：本体精确线以四维加性打分（语义、字面、时近、重要）服务于精确注入，擦边发散线以一词命中即擦边的极低门槛服务于 P1 的发散锚点。二者物理隔离，互不干扰。

## 2.4 认知架构

如果说 2.3 节讨论的是 P1 如何组织"记什么"，那么本节关注的是更上游的问题——P1 的处理节奏本身借鉴了哪些通用认知模型。ACT-R (Anderson, 1983; Anderson et al., 2004) 和 SOAR (Laird, 2012) 是两个最具影响力的通用认知架构。ACT-R 的声明性记忆模块采用激活值模型：每个记忆块（chunk）的激活值由基础水平激活（与使用频率和近因效应相关）和扩散激活（与当前关注焦点的关联强度相关）两部分组成。SOAR 则采用基于产生式规则的问题空间搜索，通过 chunking 机制将成功的搜索路径编译为直接触发的规则。

P1 在多个层面借鉴了认知架构的思想：

- **ACT-R 的频率衰减**：P1 的 BLQ 算法中的 actrDecay 因子直接采用 ACT-R 的频率累积衰减模型，高频出现的候选词（对应 ACT-R 中高激活值的记忆块）被适度降权，以避免"扇出效应"（Fan Effect, Anderson, 1974）导致的泛化输出。

- **ACT-R 的子目标激活**：P1 的两次发散架构——第一次发散产出散词池（对应 ACT-R 的检索阶段），空间投票产出锚点（对应 ACT-R 的模式匹配），第二次发散产出信息词（对应 ACT-R 的子目标设定）——与 ACT-R 的检索-匹配-执行循环有结构层面的同构性 (arXiv:2408.09176)。

- **Kahneman 双系统理论的扩展**：P1 在设计中参考了 Kahneman (2011) 的快慢思维理论，并将其扩展为三系统模型：系统 0（感知层，对应 P1 的分词和初始特征提取）、系统 1（直觉层，对应 P1 的扩散激活和快速联想）、系统 2（深思层，对应主 LLM 的生成过程）。

然而，P1 与 ACT-R/SOAR 的根本区别在于定位：认知架构追求的是构建通用认知模型，P1 追求的是在特定环节（LLM 生成前的发散探索）以最小代价实现最大认知补偿。P1 不试图模拟完整的认知过程，而是精确定位 LLM 的收拢偏差，并以外置组件的方式对其进行架构层补偿。

## 2.5 词嵌入空间

2.4 节讨论的是流程层面的借鉴，本节则转向表征层面：P1 用什么样的向量空间承载这些流程中的语义计算。Word2Vec (Mikolov et al., 2013) 开创了分布式词向量表示的时代，揭示了词向量空间中的线性结构：`vec("king") - vec("man") + vec("woman") ≈ vec("queen")`。GloVe (Pennington et al., 2014) 通过全局共现矩阵分解改进了词向量质量。

ConceptNet Numberbatch (Speer et al., 2017) 在此基础上融合了知识图谱信息，通过 retrofitting 将 Word2Vec/GloVe 向量与 ConceptNet 知识图谱对齐，产出兼具分布式统计特征和结构化常识知识的多语言词向量空间。

P1 将 ConceptNet Numberbatch（300 维，294,716 中文词 + 344K 英文词）作为核心向量资源。其应用覆盖以下三个环节（各环节落地状态不同，逐项标注）：

- **向量空间发散**（设计规划，Phase B2，当前处于代码注释态，未在现行 12 阶段生产管线中运行）：在 Numberbatch 空间中，从输入词的加权质心出发，沿情绪方向向量移动，在目标点附近搜索候选术语。这是 P1 从离散查表检索向连续向量空间搜索演进的规划步骤。

- **类比推理**（设计参考，未作为落地机制运行）：Mikolov 的向量类比公式 A:B::C:? 为结构类比发散提供了理论参照；现行生产管线中的类比实现为词林大类码距离 4-5 的跨域扩展加 NB cosine 最优语义距离区间筛选（见 2.9 节），而非平行四边形运算。

- **侧抑制**（设计规划，列于 P1 级未落地清单，未在现行生产管线中运行）：当两个候选方向词的 cosine 相似度超过 0.7 时，激活值较弱的一方被抑制（乘以 0.3），保证输出多样性。

P1 与纯词嵌入方法的区别在于：词嵌入提供的是静态的语义距离度量，P1 在此之上构建了动态的多轴空间投票机制——词嵌入只是 P1 多条发散路径中的一条，其结果需要与 SWOW 联想、词林类比、ConceptNet 因果链等异质信号源进行加性投票后才产出最终方向词。

## 2.6 概念空间理论

Gardenfors (2000, 2004, 2025) 的概念空间理论（Conceptual Spaces Theory）提出：概念是高维空间中的凸区域（convex regions），语义关系可以用几何属性（距离、角度、区域包含）来描述。这一理论为 P1 的多轴坐标系统提供了理论锚定。

P1 的 BLQ-Coord 多轴词坐标系统直接对应概念空间理论的核心主张：每个词被表示为结构化稀疏向量，六个学科轴（心理学、信息学、社会学、逻辑学、语言学、认知学）是同一坐标空间的不同投影方式。

层级架构包括：Layer 1 多轴词坐标（静态轴 + 动态轴 + embedding 轴），Layer 2 锚点多轴查询（并行纯查表），Layer 3 跨轴投票（多个学科均判定为相关 = 跨学科共振 converging evidence）。

P1 对概念空间理论的独特应用在于"面"的概念：每条学科轴的输出不是单一分数（"线"），而是一组丰富的关联信息词（"面"）。这一"吐面不吐线"的设计铁律确保了发散输出保留多维度的语义结构，而非被压缩为不可解释的标量。

## 2.7 Small World of Words（SWOW）

SWOW (De Deyne et al., 2019) 是一个基于大规模人类自由联想实验的词汇网络数据集。在实验中，参与者看到一个提示词（cue word），被要求快速报告首先联想到的三个词。

SWOW 因此捕获了人类语义记忆中最自然的联想关系——不同于知识图谱中由专家标注的逻辑关系（IsA / PartOf），也不同于词嵌入中由语料共现统计推断的分布式关系，SWOW 反映的是人类在无约束条件下的自发联想模式。

P1 使用 SWOW-ZH24 官方版（10,024 cue 词）作为核心发散引擎数据源。系统设计将 P1 与 SWOW 的关系确立为"发散核心 + 转接器"的两段分工：SWOW 联想网络承担核心发散职能，BLQ 承担转接职能——将原始联想输出转换为具学科指向性的方向词。设计者在系统迭代中进一步确立了一项关键工程判断：系统的质量瓶颈在定位而非发散——SWOW 联想扩散本身保持语义主题不偏移（与 SWOW 数据忠实反映人类自发联想模式的性质一致，De Deyne et al., 2019），语义偏移集中发生在联想词向方向词转换的转接环节。

这一定位意味着 P1 不试图改进 SWOW 的联想数据本身，而是在 SWOW 提供的高质量联想基础上，通过下游的多轴定位和空间投票机制（BLQ 为转接器的算法框架），将原始联想词转化为有学科指向性的方向词。

P1 在使用 SWOW 时遵循一条经实验验证的红线：**同义/反义词典类资源禁止进入扩散（spread）端，只允许留在打分（score）端作参考**。实测表明，将同义词纳入扩散端会导致召回质量灾难性下降（beilu recall 从 0.684 降至 0.162，lccc recall 降低 55%）。SWOW 联想扩散本身在 distance=1-2（直接联想/间接联想）运行；另一个易混淆的参数"距离 4-5"是词林大类码距离，属于类比发散的跨域参数（见 2.9 节），与 SWOW 联想跳数无关。

SWOW-ZH (Behavior Research Methods, 2025) 提供了中文自由联想网络的规范化数据，P1 的中文联想发散直接基于此数据集。此外，P1 还整合了 JWSAN（日文）和 SWOW-DE（德文）数据，为多语言发散提供数据基础。

## 2.8 ConceptNet 与常识推理

ConceptNet (Speer et al., 2017) 是一个大规模多语言常识知识图谱，包含 14 种核心语义关系（IsA, Causes, HasProperty, PartOf, CapableOf, UsedFor 等）。P1 使用 ConceptNet 的倒排简化版本（260,236 起点词，453,956 总边），主要用于以下两个环节：

- **归因发散（Causal Divergence）**：通过 ConceptNet 的因果类关系（Causes、HasProperty、CapableOf、MotivatedByGoal 等），从输入概念追溯其可能的因果链，发散至因果相关但语义距离较远的概念。

- **抽象种子提取**：从主轴 concepts 通过 IsA/Causes 关系向上抽象一步，获取上位概念作为第二次发散的种子。

P1 当前对 ConceptNet 采用 12 种关系加权利用方案，权重按因果强度形成梯度（从 Causes 0.9 递减至 Antonym 0.01），六度路径则使用 ConceptNet 全关系遍历。IsA 的倒排索引（用于语义上位扩展的专用索引结构）仍被列为高优先级待接入资源。

YARN (2026) 提出了类比推理的四步框架——分解、抽象、映射、推理——P1 的跨框架类比机制与这一框架高度对应：先在联想空间中分解输入结构，再通过 ConceptNet 进行一步抽象，然后在不同领域间寻找结构同构映射。Fauconnier 与 Turner 的概念融合理论（Conceptual Blending Theory）则为 P1 的跨轴交叉机制提供了理论支撑——两个输入空间的双向合并可以产生涌现结构。

## 2.9 结构映射与类比推理

Gentner (1983) 的结构映射理论（Structure Mapping Theory, SMT）是 P1 类比发散的直接理论来源。SMT 的核心主张是：类比的本质是关系结构的映射，而非属性的相似——"类比 = 找相似关系，不是找相似对象"。FAME (EMNLP, 2023) 将自动类比映射的准确率提升至 81.2%；Relation Embedding Chains (EMNLP, 2023) 通过关系嵌入链解决了困难类比问题。

P1 的类比发散机制（词林类比扩展 analogyExpand）基于 SMT 设计：在词林（同义词词典）中，寻找大类码距离为 4-5 的词汇——这些词在语义上属于完全不同的领域，但在词林的分类层级结构中处于同构位置。

三类发散价值的排序——类比发散（跨域结构同构，最高）> 同性发散（同域内扩展，中等）> 字面联想（语义邻居，最低）——直接反映了 SMT 对关系映射优于属性相似的强调。

P1 定义了类比发散的三个满足条件：(1) 可以进行映射（关系结构对应）；(2) 可以理论融合（A 域理论套到 B 域）；(3) 基于性质框架（共享某个抽象性质）。这与 Holyoak 与 Thagard (1989) 的四约束理论（结构、语义、语用、实用约束）有部分对应关系。

## 2.10 信息检索

2.9 节关注的是候选词从何而来（类比映射如何产生跨域关联），本节转向候选词产生之后的问题：数百个候选如何被排序、融合、收窄为最终输出。P1 的排序和融合机制大量借鉴了经典信息检索技术：

**CombSUM (Fox & Shaw, 1994)**：P1 的 BLQ 算法采用加权线性求和（CombSUM）作为多因子融合策略，而非乘积融合。设计论据是"加性即或门"——加性打分允许一个维度的弱表现被其他维度的强表现补偿，避免了乘积融合中"任一因子趋零则整体趋零"的 AND 门效应。

**RRF (Cormack et al., 2009)**：BLQ 的多因子融合采用 Reciprocal Rank Fusion 公式 `RRF_score(term) = Sum_over_factors(weight_f / (k + rank_f(term)))`（k=60），各因子独立排序后按排名位置融合，对异质信号源的尺度差异具有天然鲁棒性。

**MMR (Carbonell & Goldstein, 1998)**：MMR 曾在 P1 的旧巨石管线（Phase E）中作为多样性保证机制：`MMR(d) = lambda * Sim(d, Q) - (1-lambda) * max(Sim(d, d_selected))`，lambda 取 0.7（固定）或自适应调节。该机制属旧管线设计，未在现行 12 阶段生产管线中运行。

**BM25 (Robertson et al., 1995)**：P1 在记忆召回的评分中使用了 BM25 的 TF 饱和思想——术语频率的边际贡献递减，防止高频词主导排序。

**IDF (Sparck Jones, 1972)**：P1 的 v14 版本引入 IDF 加权，用于记忆召回阶段的词项区分度评估。

P1 将这些经典技术组合为一个统一的排序框架，但其目标函数与传统信息检索根本不同：信息检索追求的是"找到与查询最相关的文档"（relevance maximization），P1 追求的是"找到与输入保持受控语义距离的方向词"（controlled semantic divergence）。

这一目标函数的差异决定了 P1 在使用这些经典技术时进行了系统性的改造——例如，将 IDW（反距离加权）与温度画圆结合，形成"太近排除（废词）、太远衰减（噪声）、中间区间最优"的距离带控制策略。

## 2.11 认知启动与 LLM 行为

P1 的最终产物——方向词——通过注入 LLM 上下文对其生成过程施加影响，这一机制的理论基础是认知启动效应（Cognitive Priming）。经典心理学中，语义启动效应已被大量实验验证 (Meyer & Schvaneveldt, 1971; Neely, 1977)。近年的研究将这一效应扩展到 LLM 领域：

- **Cognitive Priming in LLMs** (arXiv:2409.16022)：实验证明 LLM 确实受启动效应影响——在上下文中呈现特定概念会显著改变 LLM 后续生成的语义方向。该实验的对象是 LLM 的一般性启动效应，为 P1 方向词对主 LLM 的 prime 效果提供了机制层面的间接支持（P1 自身的注入对照实验尚未开展）。

- **Serial Position Effect in LLMs** (ICLR, 2026; arXiv:2604.10027)：LLM 对上下文中不同位置信息的注意力呈 U 型分布——首部和尾部信息获得更多注意力（首因效应和近因效应），中部信息注意力最弱。P1 据此设计了 U 型注入策略：最强方向词置于首位（首因效应），次强方向词置于末位（近因效应），最弱方向词置于中间。

- **Creativity and Associative Thinking** (Nature npj, 2025)：联想能力解释了 50% 的发散思维方差，为 P1 以联想网络驱动发散的设计提供了认知科学层面的支持。

- **Concise Paths 2-3 Hops Sufficient** (2025)：简洁的 2-3 跳路径足以进行稳健推理，验证了 P1 将六度分隔简化为 2-3 步的设计选择。

- **DSP (Directional Stimulus Prompting)** (NeurIPS, 2023)：方向性提示可将 LLM 性能提升 41.4%，从提示工程的角度支持了 P1"给方向不给路线"的输出策略。

## 2.12 工作记忆容量与信息瓶颈

Miller (1956) 的 7+/-2 魔力数字和 Cowan (2001) 修正后的 4+/-1 工作记忆容量限制，为 P1 的方向词输出量设定了认知科学依据：P1 的核心层方向词控制在 4-5 个，恰好落在人类工作记忆的最佳容量范围内。过多的方向词会导致注意力稀释，过少则无法提供足够的多维度覆盖。与核心层并存的是擦边层输出（top15 候选），遵循的设计意图是容忍低价值候选、以低门槛换取大面积语义触达——核心层进入注意力焦点，擦边层提供大面积语义触达，两层各司其职、并不矛盾。

Tishby 与 Zaslavsky (1999) 的信息瓶颈理论（Information Bottleneck Theory）为 P1 的压缩-保留权衡提供了形式化框架：P1 的发散过程产出数百个候选，最终压缩为核心层 4-5 个方向词——这一压缩过程的目标是最大化方向词与 LLM 最终输出质量之间的互信息，同时最小化方向词与原始输入之间的冗余信息。

P1 的 BLQ 算法中的 ibApprox（信息瓶颈近似）因子直接对应这一理论目标。

Sims (2018, 2023) 将 Rate-Distortion 理论应用于人脑工作记忆的形式化建模，发现人类工作记忆的容量限制可以用信息论的速率-失真权衡来解释。P1 的目标函数与这一形式化模型存在同构关系：方向词是对输入语义空间的有损压缩，压缩目标是保留对主 LLM 回复质量最有贡献的维度。

## 2.13 弱连接理论与 Serendipity

Granovetter (1973) 的弱连接理论（Strength of Weak Ties）指出：在社交网络中，弱连接（不常联系的熟人）比强连接（亲密好友）更可能传递新信息，因为弱连接桥接了不同的社交圈子。

P1 的六度分隔奖励机制直接基于这一理论：跨域发散路径（经过多个不同学科领域的连接）获得递增的奖励系数（跨 2 域 1.2x / 跨 3 域 1.4x / 跨 4 域 1.6x），鼓励系统发现跨领域的"弱连接"——这些连接虽然在单一领域内看似不相关，但可能为 LLM 提供全新的思考维度。

这一设计与 Mednick (1962) 的远距联想理论（Remote Associates Test, RAT）相呼应：创造性思维的核心是在语义上远距离的概念之间建立连接。P1 的最优语义距离区间设计（以 cosine 相似度为口径，分为两个参数：召回 Goldilocks 区间 cos [0.25, 0.70]，类比发散区间 cos [0.2, 0.7]）和倒 U 型价值函数（太近同义冗余、太远随机噪声、中间最有价值）正是这一理论的计算化实现。

Orwig (2025) 的实验进一步证实：语义距离与创造性之间的关系确实呈非线性的倒 U 型。

## 2.14 其他相关工作

**Hough 变换与投票机制**：P1 的多对一投票机制借鉴了 Hough (1962) 在计算机视觉中提出的 Hough 变换——多个证据点对同一假设独立投票，票数最高的假设被选取。VoteNet (ICCV, 2019) 将 Hough 投票扩展到 3D 目标检测。P1 将这一范式进一步迁移到 NLP 方向词生成：多个信息词对同一候选方向词投票，得票最高者被选为最终输出。这一迁移在公开文献中未有先例。

**Halliday 系统功能语言学（SFL）**：Halliday (1994) 的三大元功能（概念功能、人际功能、语篇功能）影响了 P1 在语言学轴上的子方向设计——词义解析对应概念功能，传递方式对应语篇功能，语用分析对应人际功能。

**FIT 特征整合理论**：Treisman (1980) 的特征整合理论区分了前注意阶段（各维度特征并行独立处理）和注意阶段（特征绑定为统一对象）。P1 的六轴面发散（各轴并行独立运行）对应前注意阶段，空间相加投票（多轴结果汇入同一空间）对应注意阶段的特征绑定。

**温度参数与玻尔兹曼分布**：P1 的温度参数设计参照了玻尔兹曼分布 `exp(-E/kT)`——温度值控制候选搜索范围的大小，高温对应更大的搜索范围（发散），低温对应更小的搜索范围（收拢）。P1 的轴衰减公式 `exp(-rank * beta)` 同样采用指数衰减形式，beta=0.5 为经实验校准的定档值。

**投票理论**：P1 的多对一投票机制隐含地利用了 Condorcet 陪审团定理——当 N 个独立投票者的个体正确率大于 0.5 时，集体正确率随 N 指数增长。3 票时正确率 >87.5%，5 票 >96.9%，这为 P1 的"方向词需要多个独立信息源同时指向"提供了概率论层面的保证。
