# 高级宏

随机选择、掷骰子、文本处理、时间计算等。大多需要参数，用双冒号 `::` 分隔。

## 随机与选择

### {{random::选项列表}}

从逗号分隔的选项中**随机**选一个。每次替换结果可能不同。

```
{{random::晴天,阴天,雨天,雪天}}
```

可能输出：`雨天`

**用途**：为对话增加随机性和变化感。

示例——角色的随机开场情绪：
```
{{char}}今天的心情是{{random::开心,平静,忧郁,兴奋,慵懒}}的。
```

### {{pick::选项列表}}

从逗号分隔的选项中**确定性**地选一个。相同的输入在相同的上下文中总是返回相同的结果。

```
{{pick::春,夏,秋,冬}}
```

输出：`秋`（同一上下文下每次都是这个结果）

**与 random 的区别**：`random` 每次都可能不同，`pick` 在同一上下文下结果固定。需要稳定性时用 `pick`，需要变化时用 `random`。

## 掷骰子

### {{roll:NdM}} / {{roll:NdM+K}}

模拟掷骰子。`N` 是骰子数量，`M` 是骰子面数，`K` 是可选的加减修正值。

| 写法 | 含义 | 结果范围 |
|------|------|----------|
| `{{roll:1d6}}` | 掷 1 个 6 面骰 | 1~6 |
| `{{roll:2d10}}` | 掷 2 个 10 面骰，求和 | 2~20 |
| `{{roll:1d20+5}}` | 掷 1 个 20 面骰，加 5 | 6~25 |
| `{{roll:3d6-2}}` | 掷 3 个 6 面骰，减 2 | 1~16 |

### 使用示例

角色扮演中的技能检定：
```
{{user}}尝试开锁，掷出了 {{roll:1d20+3}} 点（DC 15）。
```
可能输出：
```
小明尝试开锁，掷出了 18 点（DC 15）。
```

战斗伤害计算：
```
{{char}}挥剑攻击！造成 {{roll:2d6+4}} 点伤害。
```

## 文本处理

### {{reverse::文本}}

将文本反转输出。

```
{{reverse::Hello World}}
```
输出：`dlroW olleH`

```
{{reverse::你好世界}}
```
输出：`界世好你`

## 时间计算

### {{timediff::时间1::时间2}}

计算两个时间点之间的差值，返回人类可读的时间差描述。

```
{{timediff::2026-01-01::2026-07-14}}
```
输出：时间差的人类可读表示

**用途**：在提示词中表达"距某事件过了多久"或"还有多久到某个时间点"。

## 时区与格式化

### {{time_utc+N}}

获取指定时区偏移的当前时间。`N` 为 UTC 偏移量。

| 写法 | 含义 |
|------|------|
| `{{time_utc+8}}` | UTC+8 时间（东八区） |
| `{{time_utc+9}}` | UTC+9 时间（东九区） |
| `{{time_utc-5}}` | UTC-5 时间（美东标准时） |
| `{{time_utc+0}}` | UTC 时间 |

示例：
```
东京时间：{{time_utc+9}}
```

### {{datetimeformat FORMAT}}

使用自定义格式字符串输出当前日期时间。格式遵循标准的日期时间格式化语法。

```
{{datetimeformat YYYY年MM月DD日 HH:mm}}
```
可能输出：`2026年07月14日 14:30`

```
{{datetimeformat MM/DD/YYYY}}
```
可能输出：`07/14/2026`

## 特殊用途宏

### {{banned "词语"}}

标记一个违禁词。用于在提示词中告知 AI 某些词不应使用。

```
{{banned "某个词"}}
```

### {{//注释内容}}

注释宏。内容会被完全移除，不会出现在最终的提示词中。适合在预设模板中写备注。

```
{{//这段是给预设编辑者看的注释，AI不会看到}}
正式的提示词内容在这里。
```
