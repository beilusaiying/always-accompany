# 界面布局

这一页是整个界面的"地图"。第一次打开觉得按钮多不要紧——日常聊天真正会碰的就是左栏、输入框和顶部那几个按钮，其余的等用到再认识。

## 大结构：三栏 + 顶底

| 区域 | 放着什么 |
|------|------|
| 左栏 | 角色列表 / 预设选择器 / 采样参数（不同模式下内容不同） |
| 中央 | 对话消息流 |
| 右栏 | 运行时开关 / 任务看板（可折叠） |
| 顶部 | 模式选择器 + 辅助菜单 + 设置入口 |
| 底部 | 输入框和它的工具条 |

左右栏都可以拖边缘调宽，也可以点顶部两端的图标整个收起来。IDE / 工作模式下布局会变成"活动栏 + 侧边栏"的编辑器样式，不用慌，聊天模式的东西都还在。

## 顶部一条线，从左到右

- **左端**：左栏开关；**角色名按钮**（点它快速切换角色卡）；当前预设名。
- **中间**：**模式选择器**——显示当前模式（默认「AIRP」）的下拉按钮，点开可选四个主模式，每项都带一句用途说明；旁边的「**···**」是辅助菜单，里面是五个辅助视图：记忆 / Bot / 陪伴 / ST适配 / 额外插件。辅助视图只是"打开另一块面板看看"，**不会打断你当前的对话**。
- **右端**：Token 用量圆点（点开看上下文占用）；通知中心；设置（齿轮）；编辑；右栏开关。

## 快捷键

| 快捷键 | 干什么 |
|--------|------|
| Ctrl+1~4 或 Alt+1~4 | 切四个主模式（全智能 / AIRP / IDE / 工作） |
| Ctrl+. | 打开「···」辅助菜单 |
| Ctrl+, | 打开设置 |
| Ctrl+E 或 Alt+E | 打开编辑界面 |
| Ctrl+T 或 Alt+T | 打开 Token 用量面板 |

**浏览器里请用 Alt 系**：Chrome 等浏览器会把 Ctrl+数字抢去切浏览器标签页，页面拦不住；桌面客户端里 Ctrl 正常可用。输入框里打字时快捷键自动失效，不会误触。

## 消息怎么发、怎么改

**发送是 `Ctrl + Enter`；Enter 是换行。** 写多长都不怕手滑。

每条消息的气泡角上有两个小按钮：

- **铅笔**：就地编辑这条消息的内容；
- **更多（列表图标）**：展开一个菜单，里面有——隐藏（这条不再发给 AI，但你还看得见）/ 删除 / **回档到此**（先预览，再协调处理这条之后的消息、可用的表格快照与 IDE 文件检查点；是否完整完成以结果中的 `success / applied / partial / indeterminate` 为准，详见[备份与恢复](beilu:wiki/backup/recovery.md)）/ **从此分叉**（以这条消息为起点开一条平行对话，原对话不动）/ 复制（Markdown・纯文本・HTML）/ 下载 HTML / 限时分享链接。

按住 Shift 时按钮会变成"下载 + 删除"的快捷对，顺手清消息用。

输入框左侧的 **≡ 菜单**管对话级操作：新建对话 / 管理对话 / 重新生成（让 AI 重写最后一条回复）/ 批量删除。

| 常用操作速查 | 方法 |
|------|------|
| 发消息 | Ctrl + Enter |
| 换行 | Enter |
| 重新生成 | ≡ 菜单 → 重新生成 |
| 编辑某条消息 | 气泡角铅笔按钮 |
| 删除某条消息 | 气泡角更多菜单 → 删除 |
| 新建对话 | ≡ 菜单 → 新建对话 |
| 切角色 | 左栏点其他角色卡，或顶部角色名按钮 |

## 设置面板：一个可拖动的浮窗

点齿轮（或 `Ctrl + ,`）打开。它是个浮动窗口，可以拖着走、拉右下角调大小。左侧一列图标是分区导航，共 14 个分区，日常常用的就前三个：

| 分区 | 一句话说明 |
|------|-----------|
| 语言 | 界面语言切换（简中 / 繁中 / 英 / 日） |
| 界面设置 | 深浅色、配色方案、字体大小、聊天背景、消息密度等一切"长相"问题 |
| [AI服务源](beilu:wiki/ai-service/api-config.md) | 添加和管理 AI 源（见 [配置 AI 服务源](install.md)） |
| [安全中心](beilu:wiki/security/overview.md) | 一键安全检查、内容过滤、iframe 安全等级 |
| 备份与同步 | 对话备份恢复、文件版本历史、GitHub 同步 |
| 导入导出 | 角色卡 / 世界书 / 预设 / 正则 / 记忆包 / 主题的进出通道 |
| 使用手册 | 你现在看的这份 Wiki |
| 用户账号 | 多用户切换、改密码、安全问题 |
| [插件管理](beilu:wiki/plugins/overview.md) | 内置插件的开关和配置 |
| 远程访问 | 局域网地址、二维码分享、外部应用 API Key |
| 后台监控 | 运行日志和错误追踪——**AI 不回复时来这里找原因** |
| 请求预览 | 看"实际发给 AI 的完整内容长什么样"，调预设的利器 |
| 教程开发 | 制作交互式教程用的开发工具（一般用不到） |
| 关于 | 版本号和作者信息 |

## 常见坑 FAQ

**问：说好的"顶部四个模式按钮"呢？**
答：老版本是四个平铺按钮，现在合并成了一个模式选择器下拉——就是顶部中间显示当前模式名的那个按钮。

**问：按 Ctrl+1 没反应？**
答：浏览器把这个键抢走了，用 Alt+1；或者直接点模式选择器。

**问：左栏 / 右栏不见了？**
答：被收起来了。点顶部最左 / 最右的侧栏图标就回来了。

**问：误删了消息 / 想回到之前的某个节点？**
答：删除的对话可以在设置 → 备份与同步里找回；想"时光倒流"用消息菜单里的「回档到此」，想"两条线都保留"用「从此分叉」。
