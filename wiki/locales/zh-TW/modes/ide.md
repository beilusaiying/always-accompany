# 程式碼模式 (Code / IDE)

## 進入程式碼模式

| 方式 | 操作 |
|------|------|
| 頂部模式選擇器 | 點擊「Code」標籤 |
| 鍵盤快捷鍵 | `Ctrl+3` 或 `Alt+3` |

## 連接你的編輯器

1. 點擊活動欄的 **connections** 按鈕，開啟 IDE 介面面板
2. 安裝 YonBan 擴充功能（面板內有指南按鈕）
3. 點擊「連接」按鈕連接 VSCode 或 Cursor
4. 連接成功後狀態燈變綠，顯示編輯器版本號和 WebSocket 位址

連接後 AI 可以直接操作你的編輯器。斷線後可點擊「重連」。

## 你想做什麼

| 想做什麼 | 用哪個面板 | 活動欄按鈕 |
|---------|-----------|-----------|
| 瀏覽/編輯專案檔案 | 檔案管理器 | explorer |
| 和 AI 對話 | AI 對話 | ai-chat |
| 調整權限/自動化設定 | 控制面板 | control |
| 連接 MCP 服務 | MCP | mcp |
| 切換歷史對話 | 對話歷史 | conversations |
| 回退 AI 操作 | 操作時間軸 | timeline |
| 連接 VSCode/Cursor | IDE 介面 | connections |
| Git 操作 | Git 管理 | git |
| 切換子模式 | 子模式 | submodes |

點擊活動欄按鈕切換對應側邊欄面板，再次點擊同一按鈕可摺疊側邊欄。

## 控制面板

點擊活動欄的 control 按鈕開啟。集中管理程式碼模式的執行參數：

| 控制項 | 類型 | 說明 |
|------|------|------|
| 權限等級 | 下拉功能表 | L0 ~ L4，控制 AI 可執行的操作範圍 |
| 清理模式 | 下拉功能表 | 選擇程式碼清理策略 |
| 手動清理 | 按鈕 | 立即執行一次清理 |
| 自動儲存 | 開關 | 開啟後檔案修改自動儲存 |
| 自動繼續 | 開關 + 延遲設定 | AI 完成一步後自動繼續下一步，可設定等待延遲 |
| 完成提示音 | 開關 | AI 完成任務時播放提示音 |

## 檔案瀏覽器

點擊活動欄的 explorer 按鈕開啟。

- **開啟資料夾** — 選擇本機目錄作為工作區
- **開啟檔案** — 直接開啟單個檔案
- **目錄樹** — 樹狀展示專案檔案結構，右鍵功能表提供新建/重新命名/刪除
- **多分頁編輯器** — 開啟的檔案以分頁形式排列，支援 `Ctrl+S` 儲存
- **AI 審批佇列** — AI 請求修改檔案時進入審批佇列，可逐條允許或拒絕

## Git 面板

點擊活動欄的 git 按鈕開啟。

- **分支欄** — 目前分支、ahead/behind 計數、新建/切換/合併/stash 操作
- **提交區** — 提交訊息輸入框 + 提交按鈕
- **變更列表** — 已暫存/未暫存/未追蹤檔案，點擊查看 Diff 預覽
- **提交歷史** — 瀏覽歷史提交記錄和變更內容

## 操作時間軸

點擊活動欄的 timeline 按鈕開啟。

- 記錄 AI 執行的所有工具呼叫和程式碼狀態快照
- 可查看每次操作的輸入參數和回傳結果
- 支援回退到任意歷史節點，防止 AI 修改導致的意外破壞

## 子模式（11 個）

程式碼模式內建 11 個子模式，涵蓋軟體開發全流程：

| 子模式 | 用途 |
|--------|------|
| 任務確認師 | 理解需求，聯網查類似方案 |
| 前置設計師 | 讀取具體程式碼進行設計，精確到程式碼行 |
| 框架審查員 | 以程式碼框架和整體流程審查合理性 |
| 深度思考師 | 演算法設計、框架邏輯、線路邏輯，實驗驗證 |
| 程式碼專家 | 專注於程式碼實作 |
| 前置錯誤產生師 | 檢查語法、HTML 標籤錯誤，審查流程 |
| 測試專家 | 透過腳本工具和瀏覽器後台實際測試 |
| 糾錯專家 | 查看整體再專注單體，快速排查修復 |
| 任務交接員 | 做成 md 檔案並與人類確認 |
| 大專案協調 | scope 鎖定、依賴鏈排序、多分身編排 |
| 前端美化 | 前端設計與美化 |

每個子模式可獨立綁定預設集、API 源、模型和採樣參數，切換子模式時自動載入對應設定。詳見 [子模式與切換](beilu:wiki/modes/submodes.md)。

## 介面佈局

程式碼模式採用類 IDE 佈局：

- **活動欄**（最左側）：圖示按鈕，切換側邊欄面板
- **側邊欄**：對應面板內容
- **主區域**：AI 對話區 + 程式碼/Diff 檢視區

與聊天模式的佈局差異：

| 聊天模式 | 程式碼模式 |
|---------|---------|
| 三欄對稱佈局 | IDE 樣式非對稱佈局 |
| 左右欄可摺疊 | 活動欄常駐 + 側邊欄可切換 |
| 以對話為中心 | 以檔案和工具操作為中心 |

## 其他說明

- 進入程式碼模式時，INJ-2 注入規則自動啟用（程式碼情境專用上下文），無需手動設定
- 程式碼模式對應後端模式值 `code`，前端 Tab 為 `files`
