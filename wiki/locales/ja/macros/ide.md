# IDE/コーディングマクロ

[コードモード（IDE）](beilu:mode/files)専用のマクロで、AI にサブモード情報、コードファイルの内容、ツール説明、実行結果などのコーディングコンテキストを提供します。プリセットエンジンがプロンプト条目を構築する際に置換されます。

## モード情報マクロ

| マクロ | 説明 | 出力例 |
|----|------|----------|
| `{{sub_mode}}` | 現在のサブモードの名前 | `code_review` |
| `{{sub_mode_desc}}` | 現在のサブモードの説明 | `コードレビューモード：コード品質を分析...` |

コードモードには複数の[サブモード](beilu:wiki/modes/submodes.md)（コード作成、レビュー、デバッグなど）があります。これら2つのマクロは、AI に現在どのサブモードにいるか、およびその動作説明を伝えます。

## 記憶とファイルマクロ

| マクロ | 説明 |
|----|------|
| `{{codeHotLayer}}` | コーディング用ホットレイヤー記憶 |
| `{{code_file:ファイル名}}` | 指定した md ファイルの内容を参照 |
| `{{code_files_list}}` | 現在のアクティブファイルリスト |

### {{codeHotLayer}}

コードモード専用のホットレイヤー記憶で、`{{hotMemory}}`（[記憶システムマクロ](beilu:wiki/macros/memory.md)を参照）と同様に、コーディングコンテキスト（プロジェクト構造、技術スタック、コーディング規約など）を専門に保存します。

### {{code_file:ファイル名}}

指定した markdown ファイルの内容をプロンプトに直接埋め込みます。AI に特定の参考ドキュメント、コーディング規約、プロジェクト説明などを提供するために使用します。

例：
```
{{code_file:coding_guidelines}}
```
対応する `coding_guidelines.md` ファイルの内容を読み取り、この位置に置換します。

### {{code_files_list}}

現在のコーディングセッションでアクティブなファイルの一覧を表示します。AI にユーザーがどのファイルを操作しているかを知らせます。

## ツールと環境マクロ

| マクロ | 説明 |
|----|------|
| `{{client_env}}` | クライアント環境情報 |
| `{{ide_workspace}}` | IDE ワークスペース情報 |

> 廃止済み：`{{ide_tools}}`（ツール指示はコードから生成されなくなりました——すべてのツール説明は編集可能な注入条目（INJ-2 / INJ-2-code など、記憶プリセットパネルで直接編集可能）に置かれます）；`{{ide_tool_results}}`（ツール実行結果はマクロ経由ではなく、実メッセージとして会話に入ります）。条目に残っているこれら 2 つのマクロは空文字列に置換されます。

### {{client_env}}

クライアントの環境情報（OS の種類、ブラウザ情報など）を注入します。AI がユーザーの環境に合った提案（Windows vs macOS のパスの違いなど）を行えるようにします。

### {{ide_workspace}}

現在の IDE ワークスペースの情報を注入し、AI が自身のワークスペースコンテキストを把握できるようにします。

## 実行リンク

IDE マクロはプリセットエンジンがプロンプトを構築する際に置換されます：

```
ユーザーがコードモードでメッセージを送信
  -> プリセットエンジン（PresetEngine）がプロンプト条目を構築
  -> 現在のサブモード設定を読み取り
  -> アクティブファイル、環境情報を収集
  -> {{sub_mode}}、{{code_file:x}}、{{ide_workspace}} などのマクロを置換
  -> 組み立て完了したプロンプトを AI に送信
```

## 注意事項

- IDE マクロはコードモードでのみ機能し、通常の会話モードではこれらのマクロにはデータソースがありません
- `{{code_file:ファイル名}}` で参照するファイルは、プロジェクトの指定ディレクトリに存在する必要があります
- IDE マクロはプリセットエンジンが条目を構築する際に置換され、バックエンドマクロ置換の一部です
- ツール指示とツール結果はマクロを経由しません：ツール説明は編集可能な注入条目（INJ-2 / INJ-2-code）で管理され、実行結果は実メッセージとして会話に入ります
