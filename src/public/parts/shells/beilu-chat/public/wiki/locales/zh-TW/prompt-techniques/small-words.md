# 小詞彙大作用

一個精準的專業術語，可能比一整段描述更有效。這是因為 AI 的訓練資料中，專業術語關聯著大量的專業知識——你用一個詞，就能「觸發」AI 對應的整個知識網路。

## 原理

AI 的語言模型中，每個詞都不是孤立的，它和大量相關概念形成了網路。普通詞彙的關聯網路較小，專業術語的關聯網路則豐富得多。

```
普通詞彙：「情感」
  → AI 關聯到：開心、難過、生氣......（籠統）

專業術語：「普拉特克情緒模型」
  → AI 關聯到：8 種基本情緒、情緒輪、
    情緒的強度層級、混合情緒的組合方式......（精準且豐富）
```

一個專業術語就像一把鑰匙，能打開 AI 知識庫中對應的那扇門。

## 實際範例

### 寫作情境

| 長段描述（效果一般） | 小詞彙（效果更好） |
|-------------------|------------------|
| 「角色的情感應該有多個層次，不只是單一的開心或難過，要展現複雜的、混合的情緒狀態」 | 「角色情感參照普拉特克情緒模型，展現複合情緒」 |
| 「論述時先提出一個大前提，再提出一個小前提，最後得出結論」 | 「使用三段論結構」 |
| 「不要讓角色用太專業的方式解釋簡單概念，要像普通人那樣自然地聊天」 | 「注意知識遮蔽效應，角色用日常視角表達」 |

### 開發者情境

| 長段描述 | 小詞彙 |
|---------|--------|
| 「程式碼裡每個函式只做一件事，不要把多個功能塞在一個函式裡」 | 「遵循單一職責原則」 |
| 「寫錯誤處理時考慮所有可能出錯的情況，並且出錯後系統應該能繼續執行」 | 「防禦式程式設計，確保優雅降級」 |
| 「設計介面時讓使用者不容易用錯」 | 「遵循最小驚訝原則」 |

## 使用技巧

### 1. 選對術語

不是隨便丟一個專業名詞就有效。術語必須是 AI 訓練資料中有充分覆蓋的——也就是說，是學術界或行業裡真正廣泛使用的概念。

```
有效術語（AI 知識庫中有充分覆蓋）：
- 普拉特克情緒模型（心理學）
- 三段論（邏輯學）
- 知識遮蔽 / 知識的詛咒（認知心理學）
- 英雄之旅（敘事學）
- 冰山理論（寫作技法）
- 契訶夫之槍（戲劇理論）

效果存疑的術語（太小眾或太新）：
- 某個小圈子的自造術語
- 未被廣泛採用的新理論
```

### 2. 不要堆砌

小詞彙的價值在於精準觸發，堆砌反而會造成訊號衝突。

```
錯誤：
使用三段論、蘇格拉底反詰法、歸謬法、
黑格爾辯證法來組織角色的對話邏輯。

正確：
角色的論述使用三段論結構，必要時以反問推進。
```

一兩個精準的術語就夠了。太多術語，AI 會試圖同時滿足所有，結果哪個都做不好。

### 3. 可以附帶簡要說明

如果你不確定 AI 是否能準確理解某個術語在目前語境下的含義，可以加一句簡要說明：

```
角色情感參照普拉特克情緒模型——同一場景中可能
同時感受到幾種不同的情緒，而非只有單一情感反應。
```

這樣既觸發了術語的知識網路，又限定了你想要的那個方面。

### 4. 搭配具體指引

小詞彙負責「調出知識」，具體指引負責「應用知識」。兩者配合效果最好。

```
只有小詞彙（方向對但不夠精確）：
使用冰山理論。

小詞彙 + 具體指引（精準）：
使用冰山理論：角色的真實想法透過動作和細節暗示，
不透過內心獨白直接說出。對話的潛台詞比字面意思更重要。
```

## 常用小詞彙速查

| 領域 | 術語 | 觸發的知識 |
|------|------|-----------|
| 情感描寫 | 普拉特克情緒模型 | 8 種基本情緒、複合情緒、強度層級 |
| 邏輯表達 | 三段論 | 大前提 → 小前提 → 結論的論證結構 |
| 角色對話 | 知識遮蔽(知識的詛咒) | 角色不會用超出自身認知的方式說話 |
| 敘事結構 | 英雄之旅 | 日常→召喚→考驗→蛻變→回歸 |
| 寫作技法 | 冰山理論 | 表面只露一角，深層含義靠暗示 |
| 戲劇張力 | 契訶夫之槍 | 出現的細節都有敘事用途 |
| 懸念節奏 | 延遲滿足 | 不急著揭示答案，逐步釋放資訊 |
| 程式碼設計 | 單一職責原則 | 一個模組只做一件事 |
| 介面設計 | 最小驚訝原則 | 行為符合使用者的直覺預期 |

## 小結

- 精準的專業術語能觸發 AI 的知識網路，效果遠超長段描述
- 選擇 AI 訓練資料中覆蓋充分的術語
- 不要堆砌，一兩個精準的就夠
- 搭配具體指引使用，既觸發知識又限定方向
